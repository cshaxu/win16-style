# Product Package

每个产品 S 通过该 S 验收后发布的包仅包含：run16s.exe (x64)、ntw16s32.dll (x86)、
ntw16s64.dll (x64)、demo.exe (x64)。本文件是包说明，不是第五个产品。

当前没有已推送的二进制发布。每个后续产品 S 均须发布同批四文件，不能仅推
源码；遵循[执行规则](../../docs/rules/EXECUTION.md)记录源码快照、工具链、测试、
哈希及架构证据，并显式加入已经验证的四文件。各 S 的包通过对应 Git 提交
取回，不在此目录累积版本子目录。开发包注明阶段，M0 最终通过另行验收。
包从自身目录定位 DLL，不安装到 Windows 系统目录。
