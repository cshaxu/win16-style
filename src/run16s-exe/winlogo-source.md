# Tray icon provenance

`winlogo.ico` contains the unchanged image resource bytes from icon group 40
(zero-based ExtractIconEx index 39) of Microsoft Windows `shell32.dll` version
4.00.950, SHA-256 `c7d234025511318f3f1a7002989e43ab0a1976c9bacd1022fc6436989d73edd7`.
Its ICO directory was reconstructed to package the two original images. This
is a Microsoft Windows graphical resource, not project-authored artwork; the
project's MIT license does not make a separate claim about the image. The
original DLL is not required for building or running the project.
