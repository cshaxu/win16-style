# Product UI

run16s.exe 是启动器，基本命令为 `run16s.exe <application> [arguments]`。
默认启用 Win16 外观及后代传播；不要求重复源项目的 --win16-style-all。
启动器保持Console子系统，让交互式cmd自然等待。Console目标默认等待并返回目标
退出码，GUI目标默认异步返回0；--wait对两者都等待。无需start包装；不切换GUI
子系统来隐藏启动器。从资源管理器启动时遵循Console程序的控制台行为。
缺失目标、目标不支持、DLL 缺失/位宽不符、注入失败须返回可辨别的非零状态
并输出明确诊断。参数引用、等待选项和退出码细节由启动器导入 S 明确，
不得先宣称已实现 CLI。运行不修改系统全局颜色、主题或 DPI 设置。

demo.exe 展示标题、菜单、常见标准控件及窗口操作。直接运行保持系统原生外观，
不根据自身参数或环境变量切换成自绘样式；通过启动器注入才出现样式。
demo 不包含自动截图、故障注入、测试计数或专门验收开关。

T17 demo的Controls菜单提供八个独立原生样例页，保持原主窗的Apply/Reset/About。
页面涵盖按钮状态、编辑/列表、只读目录/滚动、容器/应用绘图、公共列表/工具条、
范围/日期、富文本/原生属性页及MDI。目录与数据仅为本地演示，不提供真实VB绑定。
这是64位原生对应项，32位VB/OCX实测另列；未适配公共控件仍显示原生外观，不在
demo内伪造renderer。每页拥有其字体/图像列表/计时器，关闭后释放；应用绘图保留。

外观应保留窗口标题、应用消息语义、控件数据、焦点、键盘、鼠标、捕获及销毁
行为。初期只承诺源实现经过本项目复验的支持面；不能把历史截图或旧测试数字
当作任意应用、任意 DPI 或全部 Win16 像素保真承诺。不支持面须明确记录。
验证时同一 demo 比较直接启动和注入启动；自动截图与真实桌面交互分开报告。

滚动条使用标准17逻辑像素厚度；原图形表保持逐字节相同。应用指定非标准厚度时，
端钮及固定滑块按实际横截面保持正方形，绘制和命中测试共用几何；极短滚动条仍
按可用长度收缩。用户当前指定通过原生探针自行验收，不使用computer-use；报告
消息、焦点、捕获、实际DPI和资源状态，不把探针称为物理鼠标/键盘操作。

鼠标打开或切换菜单后，Esc、外部点击、同项二次点击及失活应退出菜单模式，
取消后悬停不自动打开。键盘Alt/F10模式保留层级：根popup的Esc先回菜单栏，
第二次Esc归还原焦点；子菜单Esc先回父级。菜单栏空闲选择时点击空白也取消。

弹出菜单使用四边细黑框和浅色留白，不保留右/下额外厚黑投影。USER的SysShadow
是独立窗口：仅在当前样式菜单scope内，按同GUI线程、紧邻z序及相同原点/扩展
边界关联到已替换popup后，局部抑制其显示。生命周期结束解除适配，不改共享
#32768类、全局SPI、菜单内容/大小或追踪语义；不能关联的宿主辅助窗口保持原样。
菜单打印保留原生完整WM_PRINT标志与客户区坐标偏移，随后覆盖自定义细框，避免
清掉PRF_NONCLIENT后客户区未对齐而在右/下留下未绘制黑条；正常重绘也保持细框。


字体按职责区分：标题保持已确认的10pt粗体MS Sans Serif及原绘制逻辑。
标准控件与菜单使用宿主System位图字形；菜单以System16原比例按窗口DPI缩放，
不借用8pt MS Sans Serif字高或字符宽度。popup按整组标签/快捷键最大宽度对齐列，
勾选区18逻辑像素、快捷键间隔8、箭头区12（无子菜单4），行高适配字高和原勾选图。控件
保留应用字高与CP1252字符advance，不移动或放大控件。System原生字体与NULL
默认字体直接保留；其他受支持字体用私有FNT字形适配原度量。后续WM_SETFONT
重新适配，卸载恢复最新应用HFONT。按窗口DPI转换一次，legacy虚拟化不叠加。
变体由GUI线程引用计数拥有，刷新/卸载/销毁在原生调用结束后释放；应用HFONT
保持借用。变体限1..64像素字高、128像素字宽和FNT v2容量；生成失败保留应用
字体，不能据此宣称任意字号或字符集均已System化。非CP1252文字不在位图承诺内。
显式公开font_acquire/release的20像素兼容API保留，实际renderer不再默认使用。
程序自绘文字保持应用责任；用户原资源五头及声明保持原字节，原声明中的历史
字体描述不是当前默认字体配置。自动度量/原生探针通过后仍等待本次用户外观验收。

USER对ownerdraw宽度另加宿主菜单字体的两个平均字符格；WM_MEASUREITEM只扣除
这份原生留量一次，避免与本层勾选/箭头区重复。宿主字体仅用于原生布局补偿，
不参与System字形宽高生成。实际popup矩形另用System自然宽度探针核对；查询失败
保守保留多余留量，不压缩或裁切文字。不更改HMENU样式、共享类或系统全局设置。

公开row measure没有submenu参数，保守预留12逻辑像素箭头区；实际HMENU适配器
按全组submenu状态决定12或4，独立measure/draw(submenu)亦不会压到文字。

启动器遇真实740时按需请求系统UAC提升自身，再执行样式注入；取消1223。
跨UAC使用系统提升环境及独立控制台，不保留调用者标准句柄；绝对目标/原始参数尾/
工作目录/等待策略明确交接。DLL子孙CreateProcess不自动弹UAC，普通路径不变。

旧MZ/NE首次校验193、退出4；启动入口快照控制台连接：共享、显式隐藏或无窗口控制台时
只向stderr输出一次；有窗口且非显式隐藏的独占控制台（进程列表仅自身）时释放自身控制台，将同一
绝对目标及原参数尾交Windows Shell，使用其原生错误UI，不再输出应用诊断或
自制弹窗。校验尚未启动目标，只有一次实际Shell请求；取消不覆盖原退出4。
查询/脱离失败保留stderr。不是按父进程名猜Win+R；父shell提前退出留下可见
独占控制台也走系统UI。无窗口/显式隐藏控制台重定向保留输出，显式可见新控制台即使
重定向仍走UI；Console子系统创建瞬间仍可能短暂出现。不宣称消除任何控制台
闪现或全Windows错误透明代理。普通PE及其他错误不走Shell裸运行，真实740的
既有UAC分支保持。

VB6适配只识别MSVBVM60注册的ThunderRT6CommandButton、ThunderRT6TextBox、
ThunderRT6Frame，顶层ThunderRT6FormDC沿用既有标题。按钮复用绘制器，文本框
保留原生编辑/客户区和client-edge分配，仅覆盖边框；分组先调用VB原始绘制，
再叠加经典边框/标题，不吞掉无窗口标签。PictureBox画布保留原始绘制。

VB自身拥有字体属性，不能假设WM_SETFONT生效。VB客户区文字接入限本次注入
进程、已附着VB容器的同步paint/print作用域、VB运行库或USER原生文字调用者；
其他附着窗口构成嵌套打印屏障，非VB应用自绘信息栏不参与。DC字体只临时替换，
返回前恢复；按HWND缓存最多32个源字体租约，最后活动调用后卸载释放。
VB专用FNT保持应用字高和advance，缩小时保留黑色细笔画；既有标题、菜单及
标准控件的字体采样策略不变。TrueType glyph-index仅对可逆CP1252字形转换，
保留dx/clip，复杂/未知或RTL索引整段保留原始绘制；不承诺任意语言/OCX。


原生系统超类按RealGetWindowClass确认BUTTON/EDIT/STATIC/COMBOBOX/LISTBOX/SCROLLBAR协议，
不依赖VCL类前缀或应用名。既有owner-draw等拒绝仍生效；非原生自绘控件不因此接管。
未知新子窗口在WM_NCCREATE前仅暂存主题请求，不装子类；原生初始化完成后再提交，避免框架
重设InitWndProc导致“记录存在、绘制失效”。取消/终结/未完成创建scope回收暂存节点。
本机DoubleKiller的按钮/复选/原生编辑/下拉已验证；分页适配范围见下文。
自绘列表、标签、动画/进度和自定义微调按钮保留原应用绘制，后续状态由CURRENT管理。
标题及已确认菜单、滚动条、VB6策略不变。

应用自绘菜单栏在同GUI线程的真实owner下沿用WM_MEASUREITEM/WM_DRAWITEM，保留itemID、
itemData、原文字/图标和命令；不把应用绘制强制改成System字体。已确认的普通字符串菜单、
标题算法不变。回调后重新确认窗口/菜单和项目身份，销毁或替换数据后不再使用旧快照。
控件内部瞬时重绘抑制只从原WS_VISIBLE控件开始，嵌套调用共享该抑制；不对原本隐藏的
按钮、下拉、列表、多行编辑额外发送WM_SETREDRAW(TRUE)，避免将其显示。应用明确的
WM_SETREDRAW及原字体/绘制策略保持；隐藏祖先和自身可见标志分别验证。

旧框架TButton/TComboBox仅在本次新建窗口WM_CREATE完成后，确认同GUI线程、主映像注册、
准确类名及初始化后的公开协议，才登记私有窗口角色。按钮需DLGC_BUTTON、有效
BCM_GETIDEALSIZE、合法状态/勾选和足够的原生类附加字节；下拉需有效GetComboBoxInfo的
自身/子编辑/列表关系及项目数/选择。未知类不按T前缀接管，不探查框架私有对象。
角色由附着节点拥有，窗口属性仅作代际校验，查询不发送消息；卸载/销毁在绘制器退出后
回收。已确认复合下拉接管内部编辑的样式所有权，避免重复字体租约。

标准图标/位图push按钮借用当前BM_GETIMAGE图像，保留原尺寸并按对齐、禁用和按下状态
绘制，不替换或删除应用图像；PushLike使用原生勾选/按下状态绘制按钮面。业务通知、
键盘及自动勾选仍由原BUTTON处理。普通client-edge EDIT保持原生客户区、编辑、撤销及
字体策略，只覆盖既有非客户区边框。框架已验证角色沿用相同字体租约和现有renderer；
标准控件、标题及菜单字体算法不变。应用自绘/未知类及其他公共控件不因此承诺支持。

普通顶部SysTabControl32及已验证TPageControl在WM_CREATE完成后核对注册模块、附加字节、
项目数/选择、外部命中和ADJUSTRECT往返公开协议。注册公共类的hInstance可能为空，
以其原生过程所属模块核对，不按DLL文件名或类名前缀猜测。按钮、ownerdraw、底部/侧面、
反向滚动和固定图标/标签对齐等特殊模式保留原生绘制。普通/多行标签借用当前项目文字、
状态及图像列表，沿用原生项目/页面矩形，保留原字体供原生布局和命中使用；绘制才使用
现有System字形租约，绘制边界核对框架绕过WM_SETFONT后的实际字体。页面内部及可见子窗
像素不覆盖，数据、原生通知/取消、键盘、焦点和页面切换继续由原控件处理。不请求
TCIF_PARAM，避免覆盖应用用TCM_SETITEMEXTRA扩展的数据缓冲区。图像和应用字体均不删除。
回调变更代际或销毁时放弃旧绘制快照；角色租约按原节点引用计数释放，取消创建附着只
移除该事务自己的绘制节点，保留独立所有者，并在原生字体setter返回后恢复有效应用字体。

普通SysHeader32在初始化后核对原生注册过程的模块、附加字节、项目数、外部命中及
HDM_LAYOUT结果，才登记私有角色。文字表头使用原生列矩形和顺序，不改列宽/数据，
字体留给原生布局，绘制仅借用现有System租约；框架绕过WM_SETFONT的更新在绘制边界
核对。输入、拖动和原生变更/取消通知继续交原控件处理。绘制前完整获取并验证文字/
格式快照；回调中改布局/字体、移除或销毁后放弃旧快照，恢复借用DC且释放临时内存。
筛选栏、全选复选框、溢出/隐藏表头和含图片/位图/排序标记/ownerdraw的特殊列保留原生
绘制，不将这类原生保留算作文字列已换肤。EXE注册的同名伪控件不继承原生角色。
列表附着的既有边框不能当作行内容绘制支持；普通报告行范围见下文，ownerdata等保持原生。


普通报告列表仅对本次创建链已拥有的SysListView32或已验证TListView，在初始化后核对
报告视图、原生模块/附加字节、项目数/选择及同线程表头关系。框架稍后设置视图时，可在
该已拥有节点的绘制入口补做同样确认，不扫描其他窗口。原生custom-draw通知只观察
其DC，不增加阶段、不修改返回值/颜色/项目数据；应用跳过默认绘制时保留原绘制。
现有文字钩子仅在同步paint/print及该通知给出的准确DC中，临时借用现有保留缩小细笔画的System字形
租约，保留应用HFONT、字高/advance、原生列宽/行布局/图像与数据。测量调用不换字体。
仅承诺可逆CP1252文字；未知/复杂或RTL字形整段保留原生，非报告、ownerdata、ownerdraw
及分组视图不参与。嵌套附着窗口构成绘制屏障，移除后立即停用、最后活动调用后释放
字体；父通知观察器按精确子窗口节点移除。跨父窗口重挂、编辑子控件及其他视图不扩张
为已支持；标题、菜单、标准控件/VB字体和原图形表不变。

普通树仅对新建且已拥有的SysTreeView32或已验证TTreeView/TShellTreeView，在初始化后
确认原生注册过程模块、附加字节、节点数/根、缩进/行高、命中及同线程父窗关系。
复用报告文字的准确原生custom-draw DC作用域与现有保细笔画System租约，不改变应用
HFONT、节点/不透明数据、图像列表、行高、缩进、展开/选择及原通知返回。客户边框和
非客户滚动条复用现有renderer，原生图标、连接线和展开器保留；不宣称整棵树像素复刻。
RTL树及未验证协议保留原生。仅承诺可逆CP1252字形；IME/辅助技术/标签编辑、特殊树
样式和跨父窗重挂未覆盖。同步绘制回调内移除样式有效；COMCTL v6原生树本身不支持
在该回调内立即销毁HWND，测试单列原生访问冲突，正常生命周期使用回调后投递销毁。
早显frame安装在发布子类前获得事务身份，并持有直到激活返回；取消只移除精确所属
frame及滚动条节点，重入安装的独立公共所有者保持，标题绘制与字体算法不变。

普通v6进度条仅对初始化后验证的msctls_progress32或主EXE精确TProgressBar，核对原生
类过程模块/附加字节、DllGetVersion>=6及合法公开范围/位置/状态。以原生值绘制平面
边框和横/纵向连续或分段填充，不改变范围/位置/步长、尺寸、应用颜色或字体属性；
正常尊重显式颜色，默认用现有palette，错误/暂停保留红/黄提示，禁用用原阴影色。
绘制无字体/堆租约；查询时取消/销毁或变更代际则弃用旧快照，所有DC借用恢复。
v5状态/颜色getter不可用，保留原生，不猜颜色或读私有对象。跑马灯、RTL、额外边框/
客户边缘及未知样式保留原生，运行期转入这些模式也停止自绘；附着不代表已采用自绘。
不宣称Win3.1本身拥有该公共控件或任意应用进度绘制均可替换。HD Tune真实提权UI默认
skip，当前包只承诺自包含探针的有限覆盖。原标题/字体/菜单/滚动条及资源保持。

普通滑块仅对初始化后验证的msctls_trackbar32或主EXE精确TTrackBar，核对原生类过程
模块/附加字节、公开范围/位置和滑块/通道矩形。原生输入、刻度、焦点、范围、步长、
布局及字体不变；通道/滑块沿用现有palette和边框原语，不宣称Win3.1曾有该公共控件。
父窗返回CDRF_DODEFAULT时，私有观察器才请求部件阶段；仅消费本层额外请求的阶段，
使用原生DC、实际部件矩形及CDIS_SELECTED按下状态。应用自己请求的阶段、返回值、
自绘像素和其他业务通知保持原路；不把鼠标捕获推测为实际按下状态。
本次新控件安装/移除及样式变化时用该HWND的WM_SYSCOLORCHANGE使原生绘图缓存失效，
不修改系统颜色/主题。v5/v6普通横纵、刻度布局和固定滑块长度有限覆盖；选择范围、
反向/RTL、提示等未准入样式保持原生，跨父窗重挂解除绘制通知观察并恢复原生缓存。
普通微调仅对初始化后验证的msctls_updown32或主EXE精确TUpDown，核对原生模块、附加
字节、公开范围/base及同线程父窗。无custom-draw，MSAA状态不能证明pressed；有限适配
直接使用原生COMCTL调用DrawFrameControl/DrawThemeBackground给出的方向和状态。仅
准确已拥有HWND、同步打印DC或该原生调用者创建的兼容DC参与；主题句柄共享，不作
