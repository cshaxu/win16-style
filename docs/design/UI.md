# Product UI

run16s.exe 是启动器，基本命令为 `run16s.exe <application> [arguments]`。
默认启用 Win16 外观及后代传播；不要求重复源项目的 --win16-style-all。
启动器保持Console子系统，让交互式cmd自然等待。Console目标默认等待并返回目标
退出码，GUI目标默认异步返回0；--wait对两者都等待。无需start包装；不切换GUI
子系统来隐藏启动器。从资源管理器启动时遵循Console程序的控制台行为。
缺失目标、目标不支持、DLL 缺失/位宽不符、注入失败须返回可辨别的非零状态
并输出明确诊断。参数引用、等待选项和退出码细节由启动器导入 S 明确，
不得先宣称已实现 CLI。运行不修改系统全局颜色、主题或 DPI 设置。

demo.exe 展示标题、菜单、常见标准控件及窗口操作。直接运行保持系统原生外观，
不根据自身参数或环境变量切换成自绘样式；通过启动器注入才出现样式。
demo 不包含自动截图、故障注入、测试计数或专门验收开关。

外观应保留窗口标题、应用消息语义、控件数据、焦点、键盘、鼠标、捕获及销毁
行为。初期只承诺源实现经过本项目复验的支持面；不能把历史截图或旧测试数字
当作任意应用、任意 DPI 或全部 Win16 像素保真承诺。不支持面须明确记录。
验证时同一 demo 比较直接启动和注入启动；自动截图与真实桌面交互分开报告。

滚动条使用标准17逻辑像素厚度；原图形表保持逐字节相同。应用指定非标准厚度时，
端钮及固定滑块按实际横截面保持正方形，绘制和命中测试共用几何；极短滚动条仍
按可用长度收缩。用户当前指定通过原生探针自行验收，不使用computer-use；报告
消息、焦点、捕获、实际DPI和资源状态，不把探针称为物理鼠标/键盘操作。
