# M0 Roadmap

本项目永久只有 milestone0（M0），不创建 M1 或后续 milestone。
候选没有 T 号；此处描述依赖顺序，CURRENT 才能准入。

| 阶段 | 结果与退出条件 |
| --- | --- |
| 治理与准备 | 权威拓扑、MTSP、产品契约、静态门禁、固定来源文件指纹、导入方案可审查并推送 |
| 来源冻结 | 对照固定提交，逐文件来源/资源处置，审查依赖、ABI 与验证矩阵后才复制 |
| 样式核心 | 本地双位宽 DLL 可构建，核心绘制/附着/清理复验，无外部运行依赖 |
| 启动与传播 | x64 启动器注入两种目标，DLL 自行传播；原生语义和失败回滚有证明 |
| demo 与交付 | x64 原生 demo 裸启动/注入启动对照，四文件独立包完成全矩阵 |

M0 产品完成必须同时证明：三个组件四个且仅四个产品文件、正确 PE 位宽、
无需源仓库/服务即可构建运行、x64 启动器支持 x86/x64、后代四种位宽边、
悬挂及失败语义、DLL 线程/窗口资源清理、demo 双行为、来源声明及资源处置、
包内完整性和用户当前指定的交互验收。每个未支持面必须有明确范围与处置，不得用构建
成功替代任务级审计。治理完成不等于产品完成。
