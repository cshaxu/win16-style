# M0 T21 S23：公共对话框库

本 S 将可分离的对话框适配实现移入 `src/lib/win16-dialog` 静态库。DLL 保留原有入口、线程作用域、异常展开与接入协调；`global_*` 没有改动。公共库不新增运行时文件，普通和全局调用仍使用既有 DLL 路径。公开 ABI、原图形资源及来源声明保持不变。

迁移范围包括旧式文件和文件夹对话框、Shell 目录树、COM 文件对话框代理及事件、显式现代对话框、传统和扩展打印参数、字体与颜色模板识别。原路径中需保持所有权、入口或异常清理的薄适配保留；`print_extended`、`print_ranges` 旧头为兼容转发，不保留第二份实现。实验事件和隐藏文件选项完成双位宽语法检查，运行时未覆盖；不声称全部参数组合通过。COM 多选仍按既有规则回退原生界面。旧自制文件夹辅助入口没有当前产品调用者，现行文件夹选择使用系统 Shell 树；旧探针期待该辅助入口而失败，不能当作现行路径成功或失败的依据。
