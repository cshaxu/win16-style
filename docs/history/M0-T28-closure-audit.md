# M0 T28 总验收与收口

用户批准收口 T28。验收范围为 UWP 与 WinUI 顶层外框以及 Windows 2000 公共对话框。P45 是任务级收口的发布基线。历史各批测试对应各自的摘要，当前文件的摘要一致不能替代未运行的整包矩阵。

| 子任务 | 证据与结论 | 已记录边界 |
| --- | --- | --- |
| S1 UWP 外框与风格切换 | 普通会话的真实托盘对照覆盖计算器与 Scan 两种风格切换和停用恢复；S2 正式包复验两个应用的普通、最大化按钮及默认 Win16 计算器。 | 早期 S1 包的广播有七条超时或失败；DPI 不感知窗口和合成表面的严格屏幕像素对照未建立。 |
| S2 WinUI 外框 | 记事本及 Paint；记事本的输入命中、标签、菜单与样式移除，Win32 双宽直接及协调器移除。适用原生用例 33/33。 | 受限工作区使用可容纳的夹具，保留原几何断言。完整传统矩阵、物理输入及共享 Explorer 宿主不计入已验证项。 |
| S3 公共对话框 | 普通与自有全局接收路径的双宽发布验证，Win16 回归以及按用户确认的托盘生产接线与单元测试验收。P45 三处同摘要包各 140 项，另有核心 10/10；P46–P48 增补实测。 | 用户批准跳过有效自定义打印页显示和真实域打印机回写。两项留在 TODO。 |
