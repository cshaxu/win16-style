# M0 T18 S64: data-list sample acquisition

The existing extracted X-DBData sample sources were searched for instantiated `TDBListBox`, `TDBLookupListBox`, `TDirectoryListBox` and `TFileListBox` form objects. None were found in those sources. Strings naming a class in the linked executable do not prove a live instance; this search does not cover other sources or applications.

A self-owned DelphiVCL4Python 1.0.7 x64 form tested its public `CreateComponent` binding under the P163 launcher on an isolated desktop. `CreateComponent('TButton', owner)` and `CreateComponent('TForm', owner)` created real objects and were destroyed. The same call with `TFrame`, `TDBListBox`, `TDBLookupListBox`, or `TDirectoryListBox` returned `Invalid class`; the target exited zero. This is a positive control for the factory in this binding, not evidence that these classes are unavailable in Delphi generally. An initial attempt mistakenly called the Python ClassName property as a method after successful TButton creation; the corrected run is the reported result. No product code or binary changed.

The [TDbf author page](https://tdbf.sourceforge.net/) lists demo source and mentions an old recompiled demo, but the exact matching binary and instantiated target controls have not been established. Continue seeking a licensed, runnable actual sample or a documented compatible way to build one; do not treat this search as proof that the control is impossible or as a product dependency. Scratch is registered under `build/t18-s64-vb-mask-survey/component-factory*`. M0/T18/S64 remain open.
