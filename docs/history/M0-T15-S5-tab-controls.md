## Diagnosis and finite implementation

Real DoubleKiller TPageControl and HD Tune SysTabControl32 expose initialized tab
protocols, but the previous renderer has no tab painter. Exact class/module and
public protocol evidence are required after WM_CREATE; a class name alone is not
sufficient. Global common-control class hInstance may be NULL: resolve the image
containing its registered native procedure instead. No private VCL object or
procedure address is decoded and no external implementation is copied.

Ordinary top horizontal and multiline tabs use native item and page rectangles.
The application HFONT remains installed for native geometry, hit testing and
selection. The existing System lease is selected only in the paint DC. The first
real DoubleKiller prototype clipped labels: VCL had updated its native font through
a saved procedure, bypassing WM_SETFONT subclasses. The final paint boundary
refreshes the current source-font lease; the real four-page capture shows complete
labels without changing page coordinates. The exact late-update path is also a
self-contained native test, independently of DoubleKiller.

Text, states and current image lists are borrowed through fixed public fields;
TCIF_PARAM is deliberately not requested because TCM_SETITEMEXTRA can enlarge
its buffer contract. Application page interiors and visible child windows keep
their pixels. Original native selection, cancellation, notifications, keyboard,
focus and page handling remain in COMCTL/application procedures. No synthetic
TCN_SELCHANGE is added to TCM_SETCURSEL.

Buttons/ownerdraw/bottom/vertical/force-alignment modes preserve native drawing.
Native v6 vertical tabs return an internally rotated HFONT; the tests compare
native geometry and pixels rather than incorrectly demanding the input handle.
FORCEICONLEFT is tested with its documented FIXEDWIDTH prerequisite.

The native callback audit also reproduced a distinct installation transaction
defect: removing the coordinator inside WM_GETFONT/WM_SETFONT left a leaf whose
installation had not returned. A private exact owner token now lets cancellation
remove only that transaction's node, preserving independent owners. Merely
removing the leaf was insufficient: the original font setter could finish later
and overwrite the restored font with a retired variant. Final settlement after
the native call restores a valid borrowed application font. Protocol nodes use
explicit private references until all dependent leaves have retired. No public
ABI, detour, frame/title, font generator, menu or scrollbar implementation changes.
