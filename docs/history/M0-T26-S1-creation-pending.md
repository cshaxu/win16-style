# T26 S1 创建期待处理窗口记录

`lib-win32/style/creation_pending.h` 管理单个创建作用域内待处理窗口的分配、插入、按窗口查找及摘取；记录初始窗口样式及创建状态。`ntw16s-dll/attachment.c` 的 CBT/返回消息路径直接使用公共实现，删除了本地 `take_pending` 和重复查找循环。嵌套作用域选择、消息观察、主题阶段、是否附着、失败回滚和结束时的主题清理仍由产品控制；该机制本身不负责挂钩或应用样式。

双位宽增量构建及公共测试通过，覆盖嵌套作用域、列表顺序、窗口身份、状态保留和摘取。自建启动器和两种位宽目标在原始及新建 GUI 线程验证了八个普通对话框、六个消息框入口以及窗口控件附着；探针捕获均记录完成。宿主安装测试同时新增刷新回调同步脱离的失败回滚验证，两位宽通过。这些是增量结果，尚未发布；未证明 Win2000 创建事务已接入此组件，也未证明真实 UWP/WinUI。

重入时的记录身份复核现也由公共组件提供：记录从作用域摘除或属于其他作用域时不得更新。双位宽公共测试通过；另外对两种位宽的自建目标直接加载对应增量 DLL，验证窗口在创建回调内替换窗口过程后仍成功附着、作用域正常结束且无失败。本项尚未发布。

补充自建双位宽真实 DLL 测试：嵌套作用域分别创建窗口；尝试先结束外层返回 `ERROR_INVALID_STATE`，随后内层、外层按序结束，安装计数分别为 1、2，窗口附着保持。
