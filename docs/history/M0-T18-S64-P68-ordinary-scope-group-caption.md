# M0 T18 S64 P68: ordinary-control scope and Delphi group caption

The owner narrowed ongoing work to ordinary visible VB5/VB6 and Delphi controls. Nonvisual controls and application-authored drawing are excluded from further styling work. Default rendering supplied by a framework for an ordinary visible control is still in scope; merely using framework painting does not make it application-authored. The previously deferred 23 VB units remain deferred. The historical 148-unit VB and 74-family Delphi ledgers have not yet been reclassified against the new scope and are not a count of remaining implementations.

For the ordinary Delphi `TGroupBox`, the previous S61 observation showed a theme background frame, but the caption boundary was unknown. A test-only in-process IAT observer in two self-owned DelphiVCL4Python 1.0.7 samples traced the runtime and its loaded UxTheme module during one group redraw, then restored all modified slots. In each x86 and x64 run at 144 DPI, the runtime-owned `TGroupBox` was not attached by the published package. UxTheme called `DrawTextExW` on the group window DC with caption `GroupBox` and rectangle `(8,0)-(87,25)`. `DrawTextW`, `DrawTextExW` and `ExtTextOutW` imports in the runtime and UxTheme were observed where present; the runtime lacked the `TextOutW` import. The owned application was closed and the observer returned successfully.

This identifies a caption rectangle for these two samples but does not yet establish the relative order of the theme frame and text, general clipping, alignment, empty or changed captions, repaint/reentrancy or other runtime versions. No group-box styling has been implemented. An initial x86 observer build failed because the stdcall export was decorated; the corrected build ran. Product source, original resources and binaries were not changed. M0/T18/S64 remain open.
