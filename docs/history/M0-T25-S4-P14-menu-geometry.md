# M0 T25 S4 P14：普通菜单窗口几何

普通非 RTL 菜单窗口在 96 DPI 使用 19 像素标题，菜单绘制和命中一起上移，避免客户区重叠。常规菜单提供点击、切换、F10 和嵌套菜单操作；包含特殊顶层项目的菜单保留系统几何和处理。标题配色仍采用用户参考网图的采样，来源及方案未经确认，见 [审计](M0-T25-S4-window-audit.md)。

纯 C17、MinGW GCC、Ninja、ccache 双位宽干净构建；同一包 58 项重点测试通过，无跳过，并非完整集成矩阵。单独启动的 32 位旧版记事本在自建私有桌面观察到 19 像素标题、菜单命中及打开；实测机路径只用于该次验证，不是构建依赖。候选增量包的 x86/x64 可见私有桌面物理鼠标悬停切换、再次点击关闭各通过一次；先前曾出现失败，未因此抹去。正式包物理鼠标复测四次均因系统拒绝切换私有桌面（error 5）未执行，不能计为通过。用户视觉验收尚待完成。

系统 `GetMenuBarInfo`、`GetMenuItemRect` 仍返回原坐标，产品绘制与命中使用偏移坐标；依赖这些 API 的辅助工具可能看到位置偏差。特殊或 RTL 菜单保留原生布局，弹出菜单内部仍是原生绘制；完整无障碍、全部 DPI 和应用特殊菜单尚未验证。
