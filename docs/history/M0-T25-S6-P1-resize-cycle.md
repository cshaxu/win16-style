# M0 T25 S6 P1：连续尺寸变化基线

对 [S5 P9](M0-T25-S5-P9-caption-command-order.md) 发布版，当前桌面自有窗口以 `SetWindowPos` 连续改变位置与尺寸 24 次，并逐次检查外框几何、标题颜色采样、客户区和菜单边缘各一点及左边框命中。x86/x64、DPI 不感知（窗口 96 DPI）和 DPI 感知（当前显示器 144 DPI）四项均为 `geometry=24 caption=24 client=24 menu=24 hit=24`。这是程序控制的位置变化和有限像素采样，不证明真实拖拽、整幅画面无残影或闪烁、跨屏和其他 DPI。

S6 首轮还复核双位宽固定/可缩放窗口、带/不带菜单组合、工具窗口及 144 DPI 几何，共十二项直接测试通过。新增四个连续尺寸测试入口；双位宽增量编译、来源清单与治理检查通过。没有使用隔离桌面或发送真实键鼠，未运行完整包矩阵；产品二进制未变，assets 与 `O:/winnt` 保持 S5 P9 同批文件。S6、T25 保持开放，无临时构建副本。
