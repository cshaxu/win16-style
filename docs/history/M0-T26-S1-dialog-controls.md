# T26 S1 传统对话框控件适配

传统文件及字体对话框的系统模板识别、控件发现和服务调用从
`win16-dialog/chrome` 迁入 `lib-style/common/classic_dialog_controls`。
具体控件接入、滚动和撤销实现仍由调用方注入；文件和字体对话框的所有者
标记由 Win16 产品调用方分别持有。原 Win16 组件继续负责颜色对话框的
专属画面处理。旧函数和类型已删除。

双位宽 MinGW 增量构建通过，现有原生对话框控件测试在 x86、x64 通过，
覆盖模板识别、符合条件的列表和组合框、接入失败回滚及调用方各自的所有者
标记。该测试未覆盖交互式系统对话框，Win2000 尚未接入公共控件适配。
来源清单和 diff 格式检查通过。改动尚未干净打包、发布或提交；UWP 分发
和 Win2000 DWM 恢复失败仍未解决。
