# M0 T25 S3：Win2000 窗口外框审计（进行中）

范围为普通 Win32 顶层窗口，按用户要求不以 Win16、UWP、WinUI、控件内部或公共对话框布局推定完成。用户指定 `O:/repos.external/Win2000SRC` 仅作只读参考，不引入源码、资源或构建依赖；来源与文件摘要见 [T25 方案](../proposals/windows-2000-classic.md)。参考的 `caption.c` 显示活动与非活动标题及渐变系统色需要分别处理；不能把现代 Windows 系统颜色或默认非客户区等同 Win2000 原版。

现有 `ntw2ks-dll/controls.c` 只处理 `WS_CHILD` 控件的主题，普通窗口外框尚未接入。`ntw16s-dll/injection/window_titles.c` 的创建作用域及 `win16-window` 的非客户区消息路径已处理嵌套创建、窗口所有者、重绘、命中测试与恢复；绘制、几何和样式状态与 Win16 耦合，不可直接复用为 Win2000 外观。`ntwshk` 承担现有启动和传播机制，不增加主题名称。

已创建独立 `lib-win32/win2k-window/caption` 绘制基础，调用方传入字体和色彩；纯色、渐变、文字、无效输入的绘制测试在 x86/x64 增量构建通过。测试颜色仅是辨识输入，不是经证实的 Win2000 精确调色板；此组件尚未链接至产品、没有实际窗口接入，因此不能说标题栏或外框已经实现。后续须完成窗口创建时机、系统菜单和按钮、非客户区绘制/几何与系统输入协作，并进行真实窗口和发布包测试。


## 首版真实窗口接入

`ntw2ks-dll/controls.c` 在普通顶层窗口创建后调用 `win2k-window/frame`；该候选禁用目标窗口的 DWM 非客户区绘制，保留系统默认几何、命中测试及系统命令，并在非客户区绘制渐变标题和部分经典按钮。仅通过 `--2k` 启动的创建路径使用，尚无通用移除接口。颜色和字体为待对照的候选值，不声称与 Windows 2000 精确一致。

2026-11-10 自有私有桌面上分别运行 `run16s --2k --wait ntw2ks-frame-target` 的 x86、x64 目标，均观测到附着、真实窗口标题区渐变像素差异及 HTCAPTION，并验证系统最大化、还原和关闭命令；两位宽 caption 单元、载荷、暂存和 Win16 ABI 各通过。不是物理鼠标验证，不覆盖按下、系统菜单、DPI、持续重绘或既有窗口。测试产物位于本任务自建的 `build/s3-owned-probe`，记录后清理。
