# M0 T25 S4 P13：动态菜单与系统预览对照

用发布版 P12 的自建窗口验证动态添加和移除菜单：x86/x64 的标题高度分别从 19 变为 23、再恢复到 19，菜单没有与客户区重叠；将该检查纳入包测试。还对自建窗口研究了 Windows 2000 中的私有菜单预览接口；当前系统上的有限测试未能让菜单项上移，因此没有接入产品。数据、对照及限制见 [S4 审计](M0-T25-S4-window-audit.md)。

本 P 仅修改测试和记录，产品源码及发布二进制不变，摘要沿用 [P12](M0-T25-S4-P12-bare-caption.md)；没有生成临时包或复制源码树。带菜单窗口的原版高度、菜单布局、命中和交互仍未完成，S4 和 T25 保持开放。
