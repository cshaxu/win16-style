# M0 T25 S4 P22：系统菜单边框与命令探针

只读参考 Windows 2000 `private/ntos/w32/ntuser/kernel/menu.c`（SHA-256 `6cb9469ddfe6ed4629ffec5f506155b6ab1810d70b051fbf0ee43e2287c6b48d`），原版创建普通菜单窗口时使用 `WS_POPUP | WS_BORDER` 及 `WS_EX_TOOLWINDOW | WS_EX_DLGMODALFRAME | WS_EX_WINDOWEDGE`。原版 `mndraw.c` 的自绘非客户区代码专用于可滚动菜单，普通菜单路径交由默认窗口过程，不能直接把该实现推广到所有菜单。

以 P20 发布包在自建 x64 私有桌面测得标准系统菜单窗口样式包含上述边框相关标志，客户区四周各为 3 像素。该数据只针对本机与该自建窗口，不证明其他 DPI 或原版边框颜色与像素一致；本次没有修改产品边框。

尝试用投递的键盘消息触发系统菜单关闭时，测试程序因自身超时退出逻辑错误，各等待了外层 35 秒；修正探针后，套样式和未套样式的原生对照均未执行关闭。该方法未能模拟真实菜单输入，不能由此判定产品命令是否失效。临时测试源码已恢复并重新编译测试程序，临时目录已清理；真实鼠标、键盘与桌面合成仍待验证。

本交付仅记录审计与测试边界，不改变产品二进制；S4、T25 继续开放。
