# M0 T21 S24 P1：样式库继续抽离的阶段交付

本阶段将菜单栏命中、选择与输入决策，框架字体、非客户区命中和重绘协调，窗口客户区恢复，普通对话框颜色、滚动条几何/状态/通知及列表制表位逻辑移入 `win16-control`；颜色对话框色块识别和实验性 COM 选择捕获移入 `win16-dialog`。DLL 仍拥有窗口状态、生命周期及系统消息入口，通过借用视图与回调调用库；未更改 `global_*`、跨进程接入、公开 ABI 或图形资源。

这是阶段交付，S24 保持开放。DLL 内仍有窗口及控件消息、应用兼容处理、对话框实验分支等样式业务；Win2000 通用样式接口仅有[候选设计](../proposals/win16-libraries.md)，尚未实现或验证，不得宣称可直接接入另一主题。

`s24-stage-clean-2` 同一源码快照 x86/x64 干净全目标构建、ABI、来源及原图形校验通过；`s24-stage-focused-1` 同批四文件聚焦回归 20/20、无跳过，覆盖双宽菜单、COM/颜色对话框和窗口、列表、编辑框的水平及垂直滚动捕获/位置/释放。干净构建树的独立库、几何、DC 失败及实际列表制表位测试双宽各 5/5 通过。实际 VCL 滚动候选此前双宽验证通知、鼠标、重入移除和清理；它属于较早增量快照，不计入此次干净包的 20 项。

此前屏幕滚动条像素采样在候选及 S23 基线均返回失败 5；该错误来自探针采样分支，未记录系统错误码。新测试只验证消息和捕获，不替代屏幕外观测试。完整参数、DPI、物理输入及实验性 COM 事件运行时未覆盖。首次干净构建因测试仍引用旧私有函数失败，后续增量全目标又发现低版本声明下字体夹具编译失败；修正后重新构建，失败不计通过。普通沙箱内私有桌面错误 5 的测试，以及仅对系统 API 而非项目 DLL 的 `core/scroll-native` 对照，均不算产品通过。
