# M0 T25 S5 P14：标题按钮捕获丢失与取消

以 [P9](M0-T25-S5-P9-caption-command-order.md) 发布版及自有双位宽窗口，按下关闭按钮后把捕获转交同线程另一窗口，再向原窗口发送释放消息；两位宽均未触发关闭。再次按下后发送 `WM_CANCELMODE`，捕获被释放，后续松开也未触发关闭；再次正常点击则恰好发送一次关闭命令。覆盖捕获丢失与取消后的状态恢复；该消息驱动测试不等同真实鼠标或键盘。

双位宽增量编译和上述两项直接测试通过，新增对应包用例但未运行完整包矩阵。未使用隔离桌面；产品二进制未变，assets 与 `O:/winnt` 为 P9。S5、T25 保持开放；真实 Alt+Space/Escape、其他 DPI 和用户视觉验收仍未覆盖。没有临时构建副本。
