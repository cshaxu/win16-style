# M0 T20 S5：交付与验收交接

## 当前交付

T20 按用户要求保持开放，S5 完成后停在 T 收口前。用户可运行
`O:\winnt\run16s.exe O:\winnt\demo.exe`，在对话框页面按分类检查打开/保存、
文件夹、查找/替换、字体/颜色、打印/页面设置、消息/属性页。该页有27个按钮；
存在按钮不代表所有标志、所有控件或所有系统对话框已经兼容。

- 文件：常用 GetOpenFileName/GetSaveFileName 通过受限白名单使用旧布局；
  多选、自定义模板/hook等情况可保留原系统路径。
- 文件夹：无回调常用 Shell 请求和部分普通 COM 目录请求使用系统旧树；
  指定可输入且禁新建的受限组合保留输入。带筛选风险的应用回调由 S3 P1
  保留系统新树及其真实筛选接口，故未实现所有入口统一旧树。
- COM 多选：为防止实际出现的长名漏列和双多选并发串目录，S3 P2 保留系统
  新框。所测具体场景正确，不表示其他并发或特殊配置已全部证明安全。
- 打印：普通 Print 与受限 PrintDlgEx 常用场景使用旧布局；特殊回调、附加页
  或不支持参数保留系统路径。此前不同版本的 212 个登记打印用例有通过
  证据，并非本次最终包一次运行了全部用例；实体设备及所有驱动未穷举。
- 查找替换、字体颜色、页面设置、消息框、任务对话框及属性页：已有窗口
  创建作用域和有限标准控件处理；不能推断所有自绘、子页面或其他进程窗口
  都已接管。16位系统错误框的跨进程范围未作为全部已解决。

具体入口与证据见[S2矩阵](M0-T20-S2-dialog-audit.md)，其 P295 旧状态应结合
[S3 Shell](M0-T20-S3-shell-filter.md)、[S3 COM](M0-T20-S3-com-safety.md)
和[S4验证](M0-T20-S4-common.md)的后续更正阅读。
