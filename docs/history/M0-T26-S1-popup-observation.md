# T26 S1 弹出菜单发现消息

Win16 与 Win2000 原来分别枚举相同的四种窗口消息来识别弹出菜单窗口。
两处现均调用 `lib-style/common/menu_input.h` 的
`style_menu_popup_observation`；发现窗口之后的身份判断、嵌套所有权、
绘制和销毁处理仍由各自实现。Win16 覆盖嵌套菜单与阴影，Win2000 当前只
跟踪指定系统菜单，不能因消息相同就把生命周期直接合并。

双位宽 Win16 与 Win2000 DLL 增量构建通过；`core-style-menu-input` 双位宽
通过，包括四个纳入消息与非纳入消息。该测试不证明真实系统菜单或鼠标
交互。已知 UWP 分发和 Win2000 DWM 恢复失败仍未解决，本修改尚未完整
构建、发布或提交。
