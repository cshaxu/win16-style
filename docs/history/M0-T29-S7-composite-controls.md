# M0 T29 S7 VB／VCL 与复合控件

覆盖 [S2 台账](M0-T29-S2-theme-and-abi.md) 第 37、56 项的已有样式角色。
Win16 的 VB 图形按钮读取 `Button/PushButton` 各状态的填充和边缘。
VCL 位图按钮、微调、原位编辑和导航用该窗口实例已解析的主题调色板；
控制栏细框复用同一边缘颜色。VB 数据导航保留已有箭头位图和绘制资格，
箭头调色板也由该实例提供。应用自己绘制的图案、文字和内容按原协议保留。

## 开发候选原生对照

| 路径 | x86 与 x64 的实测 |
| --- | --- |
| VB5／VB6 图形按钮模型 | 原样式下保留应用图像的 81 个像素，验证正常、按下、禁用与选中，保持原生矩形和错误返回。只替换主题按钮边缘属性后，每宽每版本有 7 次经典边缘采用指定颜色。 |
| VCL 位图按钮模型 | 只替换 `SysMetrics/BTNFACE` 后，两宽各观察到 5,816 个新色像素。应用图案 100 像素原封不动；验证嵌套、异常展开、裁剪和运行时移除。 |
| VB 数据导航模型 | 96 和 144 DPI 的两宽均通过四个状态和输入验证。96 DPI 换色后两宽各有 533 个指定色像素，原生分支均为零；中央客户区、错误调用者与不合格窗口走原路径。 |
| VCL 原位编辑、导航、微调和控制栏 | 两宽通过原生模型的状态、裁剪、应用图案和不合格调用回退；原位编辑和微调还覆盖异常后再绘制。 |
| Win16 标准微调 | 两宽各观测 77 个被替换像素，边界外为零；核对同步重入、移除和原生矩形及错误。 |
| Win2000 既有 VB／VCL 角色 | 两宽分别以旧及 v6 公共控件清单通过普通启动入口。每组有四个有效模型和两个拒绝例。只替换 `Button/PushButton` 正常态填充后，四组 `TButton` 都读到指定面色；编辑、标签和树的原断言全部通过。 |

换色对照只修改自有临时目录里本次开发构建的 `VARIANT/NORMAL`，
生产文件和原始图形未改。双宽均通过 MinGW GCC、Ninja、ccache 增量构建，
源码清单和五份原始图形及来源校验通过。临时包和测试副本随探针退出清理。
本阶段结果来自自有宿主和生产路径模型。历史真实 VB/VCL 样本的已验证范围
沿用既有记录，本阶段没有重跑闭源宿主，也没有扩大私有控件或应用自绘的适用范围。
