# M0 T25 S4 P29：实际程序窗口单次回归

以 P28 发布包及自建私有桌面进程，分别启动旧版 32 位记事本、计算器、扫雷和本项目 64 位 demo。四者均观察到 19 像素标题、普通菜单命中和打开，并正常退出。对有最大化按钮的记事本与 demo，使用各一次最大化和还原系统命令，观察窗口状态、外框属性及标题区域可读取的经典色像素；32 位和 64 位探针分别验证同位宽及跨位宽子进程。计算器及扫雷没有最大化按钮，标记不适用，不计为通过。

观察到的记事本最大化／还原标题采样均为灰阶（RGB 131／133），demo 为灰阶（131／132）；此私有桌面测试并未证明活动标题颜色、文字与图标全部正确，也不是物理鼠标拖动、屏幕合成或原版逐像素对照。自建 x86/x64 基本窗口回归各一次通过。可选外部样本只供本机验证，不是构建或测试依赖。

本交付扩充自建探针及审计，不改变产品二进制；完整程序矩阵与用户视觉验收仍未完成，S4、T25 继续开放。
