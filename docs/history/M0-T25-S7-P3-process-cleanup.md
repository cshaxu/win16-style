# M0 T25 S7 P3：启动事务失败后的目标退出

[S7 P2](M0-T25-S7-P2-cli-rollback.md)的实际 CLI 负例证明目标入口标记未出现，但未直接持有目标进程句柄，不能单凭它断言进程已经退出。启动器生产事务 `win32_process_activate` 在准备或恢复失败时终止并等待子进程。既有原生测试在准备失败时保留观察句柄；本次为两种失败都校验观察句柄已进入终止状态且退出码与错误一致，为恢复失败也增加独立观察句柄。

双位宽测试分别通过成功启动、准备失败和恢复失败；两种失败均观察到实际子进程退出并检查退出码。测试直接编译相同的启动器事务源码，是该事务的本地模型验证，不能冒称已对 P2 每个真实 CLI 子进程直接持句柄观察。新增双位宽包用例，未运行完整包矩阵。没有使用隔离桌面；产品二进制未变，两处发布包仍为 S5 P9。S7、T25 保持开放，无临时构建副本。
