# M0 T25 S4 P69：系统对话框专用图标

原版 `ntuser/rtl/winmgr.c` 的 `_HasCaptionIcon` 区分未提供专用图标的对话框与提供专用图标的对话框。用 [P62](M0-T25-S4-P62-caption-separator.md) 发布版的自建 `#32770`、`DS_MODALFRAME` 对话框，通过 `WM_SETICON` 提供专用小图标；x86/x64 均确认样式附着、系统对话框类及图标区域有非背景像素，标题文字区域由无图标时的左偏移 2 移到 24。移除该测试设置时，双位宽探针仍确认无误画图标。该测试覆盖所用系统图标和本机 DPI，不声称覆盖所有图标。

首次测试错误地在标题文字区而非图标区取样并失败；改正探针取样后通过，不能把首次失败归因于产品。双位宽增量编译、来源清单及包用例选择器自检通过；新用例加入包测试但本次未运行完整包矩阵。产品二进制未改变，assets 与 `O:/winnt` 八文件摘要与 P62 一致；仅使用 `build/.ninja` 缓存，没有临时构建副本。S4、T25 保持开放。
