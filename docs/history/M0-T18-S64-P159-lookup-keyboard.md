# M0 T18 S64 P159: Delphi lookup Alt+Down popup

P158 scoped popup creation to the lookup's mouse-down callback. In the private XDB x86 sample, `WM_SYSKEYDOWN` with `VK_DOWN` and the Alt context bit also opens the lookup popup, but P158 did not attach it. This change adds exactly that observed message and context to the existing exception-safe creation scope. Other keys and messages still do not enter it; popup ownership, source lifecycle, original graphics and public ABI are unchanged.

The actual candidate x86 DLL `d18f3b087b9b6a1804934c49f8b698f81987e4f9b06b565ac9fcecbaceb74019` loaded into the same private demo. The focused control's Alt+Down message opened the popup and the target-thread observer reported it attached. Compared with P158 in the same stage, the 121x132 popup image differed by 502 frame pixels and 2,210 scrollbar pixels, with zero differences in the 102x130 list content. Line-scroll and queued arrow messages, subsequent selection and normal exit also ran on the candidate. Reopening with a mouse message reused the same popup HWND, remained attached, closed after selection and released capture. This is an x86 synthetic-message comparison, not physical input or a guarantee for other VCL versions.

The dual-width native model actively creates same-owner popups for wrong keys and missing Alt context, verifies those remain unstyled, and verifies Alt+Down attaches. It retains source destruction, owner change, scope isolation and unwind checks. P158 fails the new Alt+Down positive assertion on both widths. A separate x86 scratch fault that scoped all `WM_SYSKEYDOWN` messages failed the wrong-key assertion. The first clean package snapshot preceded the strengthened negative test and was discarded; the final build included the strengthened test.

The C17 GCC/Ninja/ccache clean x86/x64 build, source/resource and ABI gates passed; the actual same-snapshot four-file package passed 26 focused tests in 16.35 seconds with no skips. Both published destinations match the tested hashes and each passed both width models. Real physical keyboard, other opening keys, IME, thumb dragging, timers, cancellation, other DPI/runtime versions and full integration remain unverified. M0/T18/S64 remain open.
