# M0 T25 S4 P42：普通窗口可缩放外框几何

此前普通可缩放窗口在本机 96 DPI 使用宿主的 8 像素边框，区别于参考源码默认方案推算的 4 像素。现使用按 DPI 缩放的目标度量，协调客户区四边、标题栏与按钮矩形、系统图标、标准菜单绘制和命中。固定边框沿用原生 3 像素；最大化、RTL 和需要应用自绘或特殊布局的菜单沿用既有路径。无标题状态不调整几何。菜单底边补齐至客户区上沿，避免旧位置留下残影；图标沿用应用图标或系统回退，不导入图形资源。

P41 几何探针增加目标边框及四角命中断言；旧发布版在可缩放窗口上按预期失败。增量候选 x86/x64 的固定／可缩放、有／无菜单八种组合通过，普通菜单、动态标题、按钮及记事本与 demo 的单次最大化、还原、移动和缩放通过。候选窗口 DC 截图用于检查图标及菜单位置；早期候选有图标错位和菜单残影，修正后重新查看。截图不是实际桌面合成或用户视觉验收。
