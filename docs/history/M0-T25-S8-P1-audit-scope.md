# M0 T25 S8 P1：最终审计覆盖清单

审计单位为普通 Win32 窗口的可观察行为和交付，而不是文件数或测试数量。逐项判定为已验证（限定条件）、未验证、已知不支持或发现缺陷；每项列生产入口、原始证据、未覆盖范围和接收者。真实用户输入与程序消息、窗口附着与实际绘制、屏幕像素与窗口 DC 采样、用户视觉验收分开，不以一项代替另一项。
