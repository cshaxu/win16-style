# M0 T21 S41：全局进程公共能力抽离

S41 已收口，M0 固定，T21 保持开放。按用户要求，以重构前后结果一致为准，不继续深挖已有恢复差异。冻结清单、产品调用、保留原因、逐项验证和 ntvdm64 只读导入清单见[全局进程审计](../proposals/global-process-audit.md)。

`process-global` 负责调用方可配置的发现、身份、目标、队列、事务、工作线程、加载及回收机制；`process-hook` 负责现有启动期/晚期安装和传播；窗口、控件样式由产品调用现有 Win16 库。产品保留目标策略、DLL 和会话协议、消息及恢复策略。停用不等于物理卸载，已安装 trampoline 及固定 DLL 可能持续至进程结束。

产品提交 `fc29eaad`、清单修正 `a960e605` 已推送并复核远端源码及四产品。`s41-clean28` 同快照 GCC/Ninja/ccache 双宽干净构建及 ABI、来源、原资源与公共库依赖检查通过；干净树双宽各 8 项钩子生命周期测试通过。`s41-package28` 实际包 32 项聚焦通过、无顶层跳过；范围包括普通启动、仅样式、本地钩子、双宽管理器和 A/W 跨宽传播，不代表完整矩阵。`s41-publish24` 四文件已发布至 `assets/` 和 `O:/winnt`，两个位置摘要与测试包一致。MSVC 19.43 与 GCC 16.1 各双宽的异常展开、批处理和传播自有测试通过；未导入或验证 ntvdm64 产品。

已知边界：真实管理员 ETW 和其他 window station 子项因环境跳过；私有桌面托盘端到端创建托盘失败，不能算通过。PID/TID 出生时间失配有模拟测试，未强制观察系统真实复用。组合管理器 Button 的停止后绘制摘要与旧版同为 2875890938，原始为 343534586，不得称为完整恢复；未做屏幕截图。以上不扩大为所有程序可恢复或全局全覆盖。后续环境验证及恢复调查已记录至 TODO。
