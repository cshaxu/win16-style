# M0 T25 S7 P12：系统版本信息窗口

使用已发布的 `O:/winnt/run16s.exe --2k`，由 x86、x64 自有探针分别启动 `C:/Windows/System32/winver.exe`。两项均观察到无菜单窗口的 Win2000 外框附着、144 DPI 下的标题高度、消息驱动的活动和失活颜色，以及程序移动后的标题颜色；测试创建的窗口和进程正常退出。该窗口没有最大化或可调整尺寸样式，这些操作不适用，未计通过。Windows 文件系统重定向可能影响实际目标位宽，此处只报告探针位宽，不推断目标位宽。

当前输入桌面为 Default 且有前台窗口，但此前真实鼠标菜单探针重试仍报告没有输入和菜单进入；原因未明，不算产品测试通过。没有创建或切换隔离桌面。产品二进制未变；本项只证明该实际窗口的有限消息与像素采样，不证明真实键鼠、瞬时闪烁或其他 DPI。S7、T25 保持开放。
