# M0 T25 S4 P36：实际窗口活动与失焦标题

对 P34 发布包，在自建私有桌面使用 x86、x64 探针分别启动本机 32 位旧版记事本和项目 64 位 demo；每个目标依次发送活动及失焦 `WM_NCACTIVATE`，从窗口 DC 读取标题内一个像素。四次测试均观察到活动蓝色及失焦灰色，窗口菜单、最大化、还原及一次位置和尺寸变化亦通过。探针构建使用双位宽 MinGW GCC、Ninja 和 ccache；外部样本不是项目依赖。

通知为测试主动发送，不是系统实际焦点切换；单点颜色不证明完整渐变、文字、图标、合成屏幕效果或原版逐像素一致。没有产品二进制变更和新发布；未创建额外临时包。S4 与 T25 保持开放。
