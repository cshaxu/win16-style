# M0 T20 S9：旧框目录与筛选刷新原型

S8 只把固定两项加入旧系统文件框。本S新增独立纯C探针：从旧框目录祖先列表
读取实际目录，而非进程当前目录；按所选 `*.txt` 或 `*.log` 在该目录枚举，
补入当前系统列表尚无的普通非隐藏文件。目录双击和筛选变化后排队刷新。
仅使用自有目录、消息驱动、系统旧模板；没有修改产品或系统设置。

自有根目录与子目录在 O: 上分别创建普通、隐藏、txt及log文件。双宽 A/W、
直接和注入共8组：检查根目录一次出现目标、不显示隐藏及子目录文件；进入
子目录后检查旧目录文件不再显示；切txt→log→txt，逐次检查目标唯一且不
显示不匹配项；返回父目录再次检查，取消并恢复探针工作目录及删除自有文件。
所有组输出 `phase=5 dir=1 refresh=5 cleanup=11111111`。关闭补充逻辑的
双宽 Unicode 原生负例在本机无短名卷均停在 `phase=0`，证明观察能检出缺失。
探针未改变应用的工作目录；探针自己的进程在结束时恢复其启动目录以便清理。

本例只验证两种固定筛选及有限导航、默认隐藏语义；文件列表通知、任意通配
组合、驱动器/UNC、符号链接、异步目录变化、owner-draw项数据、键盘输入、
Unicode/ANSI编码及复杂应用hook均未全面验证。本测试以取消结束，未证明
切换目录后选择并确认的文件身份。S8 的固定两项结果转换和本S导航不是同一个
端到端闭环，不能合并宣称产品就绪。原型不保证所有Windows版本的列表行为。

最小后续方向：将真实枚举与S8结果打包结合，先证明进入子目录后选择任意
实际长名、多选与单选、取消和小缓冲；再核对原生应用钩子、生命周期、字体和
所有权。未能保持契约的配置继续原生回退，不因当前样例通过扩大支持声明。
