# M0 T18 S64: disabled Delphi group investigation

A private DelphiVCL4Python 1.0.7 TGroupBox sample was disabled through its real Enabled property before display. On both x86 and x64, at 144 DPI, the background and text theme calls used part 4 state 2; their rectangles were (0,12)-(250,120) and (8,0)-(87,25). The published path deliberately rejects a disabled group. The tracing DLL had a compiler-split DrawThemeBackground hook, so its immediate caller record was its own diagnostic DLL and cannot establish the production caller; the observed part, state and rectangles are independent of that attribution. The isolated owned processes exited normally.

A scratch prototype based on current group frame logic accepted state 2 only while IsWindowEnabled was false, retained the existing black frame and left title rendering to the framework. After removing the diagnostic hook and forcing Ninja to rebuild, both widths reported attachment; paired same-width client-DC captures each changed 633 RGB pixels, all bounded by (0,12)-(249,119), with zero changes in the title rectangle (8,0)-(87,25) and independent interior (15,30)-(235,105). This is a single real disabled state, not validation of enable/disable transitions, text/background state consistency, reentrant changes, clipped paint, RTL, empty caption, other DPI or accessibility. No disabled Win3.1 screenshot comparison was performed; the prototype reuses the existing black frame rather than asserting historical color fidelity.

The first x64 diagnostic attempt failed before the window because its Python module path was missing; the fixed task-local PYTHONPATH produced the reported x64 result. An earlier trace-instrumented prototype failed the attachment check, consistent with the known diagnostic caller-splitting issue; it is not counted as a successful draw. The first source copy retained an old timestamp and Ninja did not rebuild; after touching the scratch source both targets rebuilt. These mixed diagnostic/prototype DLLs are not release packages. No product source or binary changed.
