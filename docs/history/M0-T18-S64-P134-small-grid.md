# M0 T18 S64 P134: grids without visible scrollbars

The [VCL grid documentation](https://docwiki.embarcadero.com/Libraries/Athens/en/Vcl.Grids.TCustomGrid.ScrollBars) states that an axis scrollbar can disappear when its cells fit. With self-owned DelphiVCL4Python 1.0.7 x86/x64 samples at 144 DPI, populated 3×3 `TStringGrid` and `TDrawGrid` windows had no visible scrollbars and P133 did not attach either class. Their public native scrollbar information had already been initialized and returned valid ranges. This differs from a synthetic window with no initialized scrollbar information.

The existing exact-class grid identity no longer requires a visible scrollbar. Same-thread window and original parent, class owner, client edge, non-RTL role and the existing first-paint public `GetScrollInfo` range/position check remain in force. The existing nonclient renderer preserves the application-owned client and data. A missing native scroll-info contract falls back; other classes and application client painting are unchanged. No new ABI, product file or graphics were introduced.

The actual package was run against both real runtime widths. For each class and width, after synchronizing the first attachment's pending frame redraw, a same-window remove-and-redraw comparison showed 1,704 changed window pixels and zero changed client pixels. Two populated `TStringGrid` values were read back unchanged; the owned samples closed normally. An earlier first draw-grid comparison had zero window changes because the pending frame redraw had not run, and is not counted as a visual pass. This evidence is for the tested runtime and DPI, not physical input, grid editing or all Delphi versions.

The self-owned x86/x64 model checks both classes without scrollbars, native scroll-info absence, scrollbar appearance/disappearance, unchanged client pixels, visible border change, original parent retirement, removal and cleanup. P133 fails the new positive assertion at both widths. A clean C17 MinGW GCC/Ninja/ccache build and both ABI checks passed. The same-snapshot actual four-file package passed 24 focused cases in 20.20 seconds with zero skips, including old grid, editor/list, startup, VB and menu paths. Original graphic and source-provenance self-tests passed. Both publication locations matched the tested package and each passed both installed-width models. Physical input, other actual versions/DPI and full integration remain unverified.

The production change adds one and removes one line; the project-authored model and fixture add 13 and remove one, and package markers add two and remove two. Search `rg -n "grid_identity|grid_candidate|ntw16s_native_get_scroll_info|ntw16s_grid_valid" src/ntw16s-dll/attachment.c` identifies the preserved admission, witness and lifetime checks. The optional runtime and temporary probes remain in registered `build/t18-s31-static-text`, `build/t18-s64-vcl-value-survey`, and `build/t18-package/s64-smallgrid-*`; they are not build or runtime dependencies. M0, T18 and S64 remain open.
