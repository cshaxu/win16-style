# T26 S1 外框和控件离屏缓冲

将 Win16 外框与公共控件呈现中重复的兼容 DC、位图、背景复制、坐标设置、
提交及释放归入 `lib-style/common/present` 的缓冲接口。两处实际调用同一
实现；外框裁剪、控件分组背景、绘制回调、失效检查和直接绘制回退保持在
各自调用方。Win2000 尚未接入该缓冲接口。

双位宽 MinGW 增量 DLL 构建及 `core-style-present`、
`core-style-present-fault`、`core-style-present-print`、
`core-win16-control-link` 全部通过，覆盖缓冲呈现、资源创建失败回退、
分组保存失败、打印顺序及控件链接；不代表所有真实应用或标题栏绘制已
验证。来源清单及 diff 格式检查通过。未创建额外临时构建。

本变更尚未干净打包、发布或提交；UWP 分发和 Win2000 DWM 恢复失败仍
未解决。

后续将 Win16 系统弹出菜单的离屏缓冲也接入同一生命周期接口；保留原有
菜单行绘制和缓冲失败时直接绘制。双位宽增量 DLL 构建、公共呈现及失败
回退、菜单快照和控件链接测试通过。菜单快照测试没有调用该 Win16 弹出
菜单绘制路径，真实菜单交互、闪烁及视觉效果仍未验证。Win2000 绘制可能
覆盖调整后的客户区，整窗缓冲及其裁剪不能直接推断为安全，尚未接入。

之后增加 `system-menu-visual native-string`：自有进程自动打开系统菜单，
使项目保留原生字符串状态，触发实际弹出窗口重绘并读取所选行的现场
像素。使用增量构建的 Win16 DLL，x86、x64 均得到预期浅蓝色并正常退出；
项目初始和结束状态检查通过。x86 使用的临时同批探针目录已删除。
这是特定选中行的程序化观察，不证明真实鼠标、所有重绘状态或无闪烁。
该对照已加入 `tools/Test-Package.ps1` 的双位宽用例，使用 `--direct` 而不
创建私有桌面；其中 x64 驱动入口已单独运行通过，完整发布包测试尚未运行。
# 滚动条使用公共呈现缓冲

公共缓冲增加由调用者选择是否预拷贝目标像素；原有窗口、菜单使用者保持预拷贝，Win16 滚动条完整覆盖画面，使用不预拷贝模式。滚动条旧的临时 DC、位图与提交代码已删除，保留棋盘画刷相位、绘制失败不提交和缓冲创建失败时直接绘制。Win16 控件库显式链接公共呈现库。

双位宽增量构建、公共缓冲/失败回退及自建 Win16 滚动控件和 Win2000 外框回归通过。普通桌面 `--scroll-only` 探针在两个位宽验证 SaveDC 和图案画刷失败时目标像素不变、GDI 对象释放，以及非零坐标滚动条经缓冲和直接绘制的逐像素一致。测试没有创建或切换桌面；这不是 Win2000 滚动条支持或完整视觉验收。本次改动尚未发布。

自建 Win2000 系统菜单在两个位宽也通过菜单项状态、选中及蓝色绘制采样，验证原预拷贝调用路径没有因接口调整而失效。
