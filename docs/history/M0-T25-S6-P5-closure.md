# M0 T25 S6 P5：窗口尺寸与交互有限技术收口

[S6 P1](M0-T25-S6-P1-resize-cycle.md)和[P4](M0-T25-S6-P4-natural-resize.md)分别验证强制重绘及自然消息循环下双位宽、96/144 DPI 的 24 次程序尺寸变化，检查几何、有限标题/客户区/菜单采样及左边框命中；[P2](M0-T25-S6-P2-zoom-cycle.md)验证双位宽同两种 DPI 的重复最大化、还原、原矩形和编辑框内容。S6 首轮亦检查了固定、可缩放、菜单和工具窗口的双位宽几何。[S5 P12](M0-T25-S5-P12-real-app-dpi.md)在实际 Solitaire、旧版记事本及 demo 检查有限窗口变化。

本 S 只按上述技术范围收口。真实鼠标连续拖动与缩放、瞬时闪烁和整幅画面残影、跨屏及其他 DPI 均未证明；[P3](M0-T25-S6-P3-activation-foreground.md)的前台条件不满足项为 skip，不计通过。S5 系统菜单真实 Alt+Space/Escape 仍未解决；完整包矩阵含用户禁止的隔离桌面，没有运行。上述问题及用户视觉验收转交 T25 后续真实程序回归和最终审计，不由有限测试推断通过。

S6 仅变更测试与文档，产品二进制未变；当前八文件仍为 [S5 P9](M0-T25-S5-P9-caption-command-order.md)同批发布包。T25 保持开放，按已授权序列准入 S7；下一 T 的样式库重组保留队列，尚未准入。
