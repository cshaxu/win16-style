# M0 T29 S18 现代外框迁移

## 共享几何与命中

直接 UWP 的 Win16 外框把主题边框度量传给 Win32 共用的布局函数。Win2000 外框
用同一份主题度量计算正常窗口边宽、标题高度和标题下方预留线，兼容未声明边框度量
的旧主题。两种适配器保留宿主原有的客户区透明孔。Win2000 固定宽度使用主题的固定窗
度量。原始主题的固定窗值为 3，旧配置回退为 4。

现代外框与 Win32 共用标题按钮角色命中和窗口命令映射，单击、双击和右键由共享函数
解析。原生应用图标、关闭按钮可用性、焦点和窗口菜单继续由各宿主提供。WinUI 的
Win2000 路径继续使用 Win32 的外框呈现，Win16 的合成路径使用同一个布局与绘制模型。

## 主题装入与产品路径

直接 UWP 先验证并打开所选主题，再将同一个映射交给对应外框。映射在绘制所需数据复制完
后释放。目标主题缺失或无效时，已应用的外框保留。旧主题适配仍有现有兼容入口。

双宽自有产品请求通过命名混搭主题：选用 Win2000 适配、Win16 索引图和独立的 30 单位
右侧间距。窗口加载对应配置，移动后的关闭按钮发出原生命令，最后成功移除外框。该样本
关闭与 UWP 无关的三项宿主接入声明，符合既有目录资格检查。独立绘制夹具同时证明原图
像素一致，释放映射后能重新绘制。混搭样本及临时包已清理。

真实 WinUI 记事本 Win2000 候选在 144 DPI 取得标题带 140 个窗口 DC 采样点，
含 33 种颜色和 16 个符合蓝色渐变通道顺序的点，内容桥和外框标记仍在。系统释放先前
自有实例后，Win16 新实例也确认附着和内容桥保留，窗口 DC 的 139 个采样点呈单色，
未能用该路径确认可见合成标题的蓝色像素。真实 Scan 同样在附着前超时，
自有实例已关闭，未获得外框。
