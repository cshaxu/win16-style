# M0 T21 S4: real applications and host failure

S3 failed to notice loss of the x86 system host. A private-desktop negative probe terminated only its own host and showed the controller remained active after three seconds; the probe failed (`manager_wait_or_exit=99`). The controller now waits for its stop event and host process together. Unexpected host termination triggers orderly global shutdown and reports error 1114 / launcher exit 10; the same probe now passes, with the existing target still alive. Normal stop, duplicate startup (system error 183 / exit 10) and controller termination (owned-process exit 77; x86 host exits; new target stays native) were also exercised. Crash leftovers are permitted; arbitrary host crashes and in-flight races are not exhaustively proven.

The expanded private-desktop integration probe covered x86/x64 ordinary run16s instances in both startup orders: after global stop all four retained style, and four newly created windows and four child processes retained ordinary propagation. Four plain x86/x64 windows restored, and a new plain process remained native. A separately compiled x64 fixture with `WS_VISIBLE` in CreateWindow also passed the same chain. All instances belonged to the test job.

The final package was used with an owned 64-bit demo and the locally available 32-bit O:/windows/notepad.exe, each before and after global startup. Native `PrintWindow` images show styled frames and controls, and target process module snapshots reported the matching candidate DLL paths. Demo title-area fingerprints were before `97d3b2f3738825b4`, styled `245b026ae779c6a6`, restored `9fe1d64aafdbaf84`; notepad before `a0c2d6f51c2e5aa0`, styled `b4af603e580351d4`, restored `4035abf45e3b3ded`. Screenshots are not physical input or proof of pixel-perfect recovery; their remaining differences were not attributed to a single cause. The optional notepad probe is not a project build or test dependency. The final notepad run reported three timeout/failed initial window notifications even though its targeted windows were styled; the sweep counts do not identify which windows failed.
