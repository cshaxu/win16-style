# M0 T25 S1 P17：WinUI ProgressBar 阶段包

为默认来源的 WinUI ProgressBar 增加 Win16 风格数值进度、动态不确定
进度及暂停/错误状态，保留应用已有本地样式。S1/T25 保持开放。

GCC、Ninja、ccache 双位宽干净构建及来源、资源、ABI、包检查通过；同批
四文件13项聚焦实包回归通过。自有 x64 WinUI 对象验证数值填充、两种
进度模式、暂停/错误颜色、本地样式保护和恢复；回调结束后的异步采样
观察到不确定动画位移及暂停/错误切换后的恢复。系统默认动画对照也观察
到位移。标准启动自有记事本验证动态进度条自动接入和会话清理。

一次同批对象测试未在限时触发回调，实包回归结束后重试通过；此前短等待
下的动画采样亦有超时。实际屏幕像素、不同 DPI、其他运行时和 x86 WinUI
尚未验证，不视为用户验收。
