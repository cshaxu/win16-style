# M0 T25 S4 P71：实际 Solitaire 模态对话框

用户原版截图展示 Solitaire 的 About 前台对话框及后方失活菜单。为核对 [P70](M0-T25-S4-P70-inactive-menu.md) 修复，现有原生测试程序增加接收外部程序路径的 `--real-about` 对照：启动自有目标，通过最后一个帮助菜单项打开对话框，观察真实对话框及其 owner，有限等待后关闭自建实例。该入口只接受调用者传入路径，产品、构建和包测试不依赖该程序。

在可见私有桌面，对 `O:/winnt/run16s.exe --2k` 启动的实际 `D:/programs/misc/sol.exe` 分别由 x86 与 x64 测试程序启动：两次均找到并附着 About 对话框，确认主窗口被禁用、首个菜单项得到测量，均观察 `black=0 gray=28`，且目标正常退出。使用程序发送命令而非鼠标点击；该结果不证明 About 内部控件样式或所有应用的模态窗口行为。

本次只修改测试与其来源摘要，增量编译双位宽测试程序、来源清单自检和治理检查通过；未运行完整包矩阵。产品二进制未变，assets 与 `O:/winnt` 八文件摘要仍与 P70 一致。仅使用保留的 `build/.ninja`，没有临时构建副本。S4、T25 保持开放。
