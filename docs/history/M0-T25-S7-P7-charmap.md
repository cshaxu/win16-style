# M0 T25 S7 P7：64 位无菜单实际程序

使用 [S5 P9](M0-T25-S5-P9-caption-command-order.md) 发布版，在受限环境外以自有 x86/x64 探针分别启动系统字符映射表 `C:/Windows/System32/charmap.exe`；PE 头显示目标为 AMD64，窗口为 144 DPI。两次均观察到 Win2000 外框附着、标题度量、程序消息驱动的活动/失活采样，以及窗口移动后标题采样，测试实例正常退出。该窗口没有菜单、不支持最大化或调整尺寸；这些操作不适用，不计通过。

原实际程序探针要求有菜单，因此首次两项虽观察到标题和移动，仍按测试契约返回 4，不计通过。现增加显式无菜单模式，要求真实 `GetMenu` 为空并核实附着；有菜单的 Solitaire 作负对照，按预期拒绝。双位宽增量编译，字符映射表双位宽探针及原有 Solitaire 双位宽路径通过。无需改变产品源码；外部程序是本机可选样本，不作为项目构建依赖。

未使用隔离桌面或真实键鼠，消息驱动与有限采样不代表整幅画面一致、真实交互或其他 DPI 均通过。产品二进制未改，两处发布包仍为 P9；完整包矩阵、实时样式恢复与用户视觉验收仍未完成。S7、T25 保持开放，无临时构建副本。
