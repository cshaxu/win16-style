# T26 S1 同线程对话框观察

`lib-style/common/dialog_observer.h` 提供同线程 `WH_CALLWNDPROCRET`
观察钩子的安装与释放。Win16 字体、颜色对话框和 Win2000 对话框、消息框及
公共对话框入口使用该公共机制；观察回调、样式接入、错误和异常作用域仍由
各自产品持有。原来的安装参数和释放条件保持一致。

双位宽 MinGW 增量 DLL 构建通过。独立原生测试在当前线程创建自有窗口，
确认安装后收到消息、释放后不再收到；x86 和 x64 均通过。这不证明跨线程
或跨进程 UWP 分发，也不代替交互式对话框测试。来源清单和 diff 格式检查
通过，未创建额外临时构建。

补充对照：同线程 `WH_CALLWNDPROC` 使用当前 EXE 回调时，不带模块和带 EXE
模块句柄均在双位宽通过。这与 DLL 回调分发不同，不能用于替代后者验证。
