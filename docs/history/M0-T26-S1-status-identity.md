# T26 S1 状态栏身份核验

第十五批之后，标准状态栏消息对字体缓存和内容快照的失效判定也从 Win16 移入公共 `control_status`，Win16 原调用点直接使用公共接口，消息集合保持不变。双位宽增量公共 v5/v6 测试验证无关消息、文字、主题与字体变化；自建启动器和增量 DLL 的 VCL 状态栏测试验证绘制、裁剪、重入移除及资源清理。测试副本已清理；此项尚未发布，也不表示 Win2000 已接入。

同一批随后将标准状态栏分栏与文本快照采集移入 `control_status`；调用方仍提供身份核验、生命周期和存储，公共接口声明 64 分栏、513 字符缓冲及同步借用契约，保留原消息查询、重入与失败行为。x86/x64 的 v5/v6 测试覆盖分栏、无边框与脱离，实际 Win16 VCL 目标覆盖绘制、裁剪、查询重入和销毁。增量构建与测试通过，尚未发布；Win2000 未使用此快照。
