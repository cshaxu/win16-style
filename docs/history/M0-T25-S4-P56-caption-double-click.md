# M0 T25 S4 P56：标题按钮快速再次点击

真实鼠标探针中，按下最大化按钮、拖离后松开，再快速点击同一按钮时，Windows 可能将第二次按下投递为 `WM_NCLBUTTONDBLCLK`；原实现只处理普通按下，因此没有最大化。标题按钮现在也处理双击按下，沿用已有捕获、拖离取消和命令路径。双位宽消息级回归显式覆盖该序列。

按用户新要求，纯 C17、MinGW GCC、Ninja、ccache 双位宽干净构建后先将八文件发布到 assets 根目录和 `O:/winnt`，再从实际发布路径进行双位宽真实鼠标验证，并用 `O:/winnt` 同摘要副本运行 28 项重点包回归，全部通过、无跳过。构建期间先前已启动的一组回归也通过，但不作为发布后测试的替代。源码快照清单 SHA-256 `bae964aa3f4bea1c1513f37733b25cb77c4474c005848a3c3ef3b50765415917`。

真实鼠标中，64 位直接通过；32 位首次运行探针的第一次按下未命中，单独复测通过。两位宽通过的运行均观察到双击消息，以及按下、拖离取消、再次点击最大化和还原。首次未命中的原因未确定，不能据此宣称全部物理输入稳定。其余 DPI 和用户手动验收未覆盖；S4 和 T25 保持开放。

同时按用户授权修订执行规则及构建说明，规定编译、发布、测试、提交、推送；发布工具新增干净构建结果入口，发布前验证包身份，测试状态记为待发布后验证。对该入口运行匹配包只读正例及不匹配包拒绝负例，也验证原有测试结果入口仍可用。
