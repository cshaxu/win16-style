# T26 S1 Win2000 系统菜单复用公共缓冲

Win16 已通过 `style_present_buffer_begin/end` 组合菜单绘制；Win2000 原先直接向屏幕逐项绘制。现由 `win2k-window` 在屏幕绘制路径使用同一公共缓冲组件，完成绘制且作用域仍有效才提交；缓冲准备、绘制或提交失败时沿用直接绘制。提供目标 DC 的打印路径保持原行为。主题颜色、字体、菜单项和 Win2000 的菜单跟踪逻辑仍由其风格组件决定。

MinGW x86/x64 增量构建通过；使用同一增量构建的 run16s、DLL 与自建窗口，在普通桌面分别测试两个位宽的系统菜单显示、选中项切换、鼠标悬停，共六项通过，菜单项类型及数据保持。两个位宽的公共缓冲呈现测试通过，来源清单、边界自检和 `git diff --check` 通过。测试临时副本已删除。

这些测试不证明所有应用、DPI 或菜单定制的视觉效果，也不代表发布包已更新；仍需干净构建、发布后回归与用户验收。
