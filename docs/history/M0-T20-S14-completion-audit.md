# M0 T20 S14：公共对话框任务级审计

## 冻结范围与交付

覆盖单位为公开入口和常见调用契约，而不是所有标志位的笛卡尔积；完整入口
历史矩阵见 [S2](M0-T20-S2-dialog-audit.md)，现行状态须结合其后 S3–S13。
下表不将窗口附着等同所有内部绘制已验证。

| 类型 | 目前交付 | 明确边界 |
| --- | --- | --- |
| 文件打开/保存 | 受限普通单选 Win32 请求桥接系统旧布局；demo 可分别触发旧、新 API 及显式现代入口 | 多选、自定义 hook/模板及不受支持标志可能回退原系统布局；多选长名旧框原型未进入产品 |
| 文件夹 | 受支持的 Shell 与普通 COM 请求使用系统 Shell 旧树 | 带筛选风险的回调保留新树，COM 特殊标志/虚拟目录等受限制；不存在声称 Win3.1 原生提供文件夹选择 API |
| 打印 | 普通 PrintDlg 和受限 PrintDlgEx 转旧布局；常用 Print/Apply、选项和页范围有历史证据 | 特殊回调、附加页、驱动和设备并非全部转接；实体打印和所有 DPI 未穷举 |
| 查找/替换、字体、颜色、页面设置 | 原系统 API 的创建作用域及受支持标准控件处理；demo 有入口 | 应用自绘、特殊模板和所有子控件状态未全面认证 |
| 消息、任务对话框、属性页、普通 Dialog | 进程内受控创建路径有样式作用域 | 共享宿主、系统代建错误框、驱动私有页及未审计的其他系统 UI 不视为全部接管 |

COM 多选遇长名和并发串目录风险时保留系统新框；普通 Win32 多选因旧框长名
缺口保留 Explorer 系统路径。Shell 筛选回调保留系统新树，以保留真实筛选与
PIDL 语义。这些是安全回退，不是完成旧布局适配。未来恢复条件见
[TODO](../states/TODO.md)，COM 长尾按用户要求降级。

S4 对重建包的 40 项常用对话框与滚动探针通过，S5 对同批次工具与实际部署包
18 项通过；两者不能合计当成一次全矩阵。S13 32 项针对错误交接原型的包测试
通过，其中刻意的负例检出了单一状态和未覆盖入口的问题；该原型未进入产品。
用户已确认此前菜单切换闪烁修复，不能将有限自动测试扩张为全部物理交互、
应用、驱动、语言或 DPI 已验收。

单独运行，`wait=0 codes=0,0 paths=1,1 cleanup=1 cwd_ok=1`，退出 0；
不因此宣称首次超时的根因已查明。
