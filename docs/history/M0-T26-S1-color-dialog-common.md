# T26 S1 颜色对话框公共控件识别

系统颜色对话框模板识别、色块区域定位和调用方指定静态控件遍历合并入 `lib-style/common/classic_dialog_controls`。Win16 产品入口保留要移除的控件 ID、去除边缘的绘制策略和回调；没有改变其他风格或对话框的外观。原 `win16-dialog/chrome.c/h` 与只包含它的 `win16-dialog` 构建目标删除，对应测试迁入公共测试目录，产品直接链接现有公共对话框库。

两位宽增量构建、公共对话框测试及公共库全量对象独立链接通过；使用自建启动器和 Win16 增量 DLL，ANSI/Wide 颜色对话框在两位宽分别验证展开、键盘选择、色块和自定义色块边缘。初次构建因文件夹对话框保留无用旧头引用失败，删除该引用后通过；独立链接测试首次缺少 WIN16STYLE_CAPTURE_DIR 返回 41，设置自有测试目录后重跑通过。未创建或切换隔离桌面，未使用 computer-use；测试副本已清理。本次为未发布的增量结果，未声称 Win2000 已采用颜色对话框绘制。

发布状态更新：上述增量代码已纳入[第十一批候选](M0-T26-S1-shared-candidate-11.md)，发布和后续测试范围以该记录为准。
