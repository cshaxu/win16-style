# M0 T30 S1 Luna 原版主题与变体证据

样本来自用户指定的 Windows XP Professional SP3 x86 VL 安装镜像。
ISO9660 卷名 GRTMPVOL_EN，大小 617,754,624 字节。ISO SHA-256 为
fd8c8d42c1581e8767217fe800bfc0d5649c0ad20d754c927d6c763e446d1927。
直接读取 ISO9660 的 I386 目录，用 Windows expand.exe 解包，无需挂载。

两份解包原件已原字节放在本地 assets/Luna，供用户测试。同一 .msstyles
提供蓝、银灰、橄榄绿，按用户确认不增加配色目录。原始配色保留
NormalColor。使用者可在描述的 VisualStyles 节选择 ColorStyle，
三个资源名分别为 NormalColor、Metallic、HomeStead。字号 Size 的原值为
NormalSize，另外支持 LargeFonts、ExtraLargeFonts。解析时把原版的
资源目录路径限定为同目录的文件名，不展开系统目录环境变量。

资源映射实测 PACKTHEM_VERSION 为 3。COLORNAMES、SIZENAMES 和
FILERESNAMES 合成九个组合，每项指向 TEXTFILE 的一个 UTF-16 属性块。
另有 THEMES_INI 和 558 条 RT_BITMAP。共享 v3 读取入口借用数据映射，
根据源码字段返回 INI 和位图视图。原版 .theme 的间接显示名依照
既有规则留给目录名回退。未解析壁纸、声音和图标设置。

MinGW GCC、Ninja、ccache 双位宽增量验证 6/6。每个位宽读取原版九个
变体共 18 个标题／按钮位图引用，核对资源名和 66×58 标题图块尺寸。
每个位宽用只改 ColorStyle 的临时描述对照蓝、银灰、橄榄绿，实际选中
三个对应的 NORMAL 文本资源，原版两件摘要前后相同。拒绝错误配色、字号、
路径穿越及把 v4 交给 v3。v4 读取与自有描述回归继续通过。

## Win32 开发验证

标准 run16s Launcher 验证的主题文件通过共享 v3／v4 分派打开。按
XP 属性表读取标题尺寸、颜色、字体、按钮分组及原版图像。共享绘制器消费
有界的数据位图和九宫切片，窗口、按钮实例各自持有借用视图的模块映射。
同目录主题身份、窗口操作和恢复使用原有入口。未声明的控件角色保留原生。

Windows 2000 现有主题声明 19 个逻辑像素。XP SP3 Luna 的三个字号
对应的窗口标题按 CaptionBarHeight 读取。对照的 NormalSize 为 25。
已观察到原窗口适配只会缩短非客户区。位图路径现在允许按声明增加标题高度，
菜单栏与客户区同步预留。144 DPI 原生自有窗口的 Win2000 和 Luna 分别为
29／38 屏幕像素，两宽一致。三配色通过完整普通启动，核对实际标题、关闭
按钮和普通按钮像素、关闭按钮命中、按下状态、撤销和未接管的复选框。
两宽的每种画面摘要一致，三配色的标题及普通按钮摘要各自不同，恢复摘要一致。

## 正式发布与实包验收

使用冻结的 T29 基线与 T30 变更构造源码快照，双位宽使用 C17、MinGW GCC、
Ninja 和同一个 ccache。x86 首次构建后继续原工作树完成 x64。
正式包检查发现两个问题并在同一快照内修正、增量重链。产品数字与字符串版本
均为 T30；DIB 读入和 GDI 绘制分属链接单元，启动器保留原导入集合。
双位宽 ABI、公共样式和进程归档依赖、原版资源身份、独立 Win16／Win2000 读回
和正式七件身份通过。源码快照 SHA-256 为 `0a8487c5d6b9ea603a58acba7f2f65a4453e461b9e0da120aa2c47a239fb926c`。

先发布至 `assets` 和 `O:/winnt`，再验证实际发布文件。七件摘要在两处与测试包
逐一相同。可选 Luna 目录的原版文件分别放在两处，正式七件和仓库提交均保留
原有交付契约。[发布清单](../etc/release.json)记录 PE 架构、导入和摘要。

| 证据 | 结果 |
| --- | --- |
| 直接在两处用发布版启动 | x86／x64 分别测 Win2000、Luna，共 8 次通过。 |
| 同版运行文件，Luna 单目录 | 三配色 × 三字号 × 双位宽，共 18 次通过。标题、关闭按钮和普通按钮像素能区分配色。 |
| 原生度量 | Win2000 为 19 个逻辑像素，Luna 为 25／29／35。144 DPI 实测 29 和 38／44／53。 |
| 交互及撤销 | 关闭按钮命中，普通按钮按下像素改变，标题和按钮可撤销，复选框保持原生。 |
| 读取 | 两宽原版读回各 9 个组合和错误配色、字号、文件版本负例，v3/v4 与描述单元共 6/6。 |
| 正式包聚焦 | 14/14，覆盖启动、等待、错误、经典绘制、对话框策略以及双宽兼容回归。 |

WinUI／UWP 的 Luna 外框、真实托盘换肤、最大化标题的平铺语义和其他 XP 控件
没有纳入本次实包验证。超出已识别的普通按钮等部件按现有原生边界处理。
本批保留两对原主题、其来源图形和附带许可。见 [Luna 使用方法](../design/UI.md)。
