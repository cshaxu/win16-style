# T26 S1 滚动条原生状态共享

`style_scroll_disabled` 位于 `lib-style/common/scroll_state.h`，读取系统滚动条
左右或上下箭头的禁用状态。Win16 的滚动输入路径实际调用该接口；旧的
`win16_scroll_disabled` 已删除。它不持有 Win16 滑块几何、鼠标跟踪、定时
或绘制状态，Win2000 和其他风格可独立使用；目前尚无其他风格调用。

双位宽增量构建及 `core-geometry` 通过，包含空窗口和实际禁用控件的状态
对照；其余滚动几何与跟踪检查也通过。未验证实际 Win2000 滚动条或所有
原生状态组合。修改尚未干净构建、发布或提交；继续保留 UWP 分发及
Win2000 DWM 恢复失败记录。

## 滑块位置映射

`style_scroll_position` 接受风格提供的滑块起点、可移动距离及有效数值范围，
将滑块像素位置按原有舍入和边界限制映射为数值；不决定滑块形状、尺寸、
计时、捕获或取消策略。Win16 跟踪现直接使用该公共函数，旧的
`win16_scroll_position` 已删除。Win2000 的比例滑块将来可以提供自身几何，
但目前没有 Win2000 滚动条消费者，不能据此声称已实现其绘制或交互。

双位宽增量构建、公共状态测试及 Win16 几何和跟踪测试通过；各位宽的
几何测试报告 791878 次检查，覆盖原始向量、单调映射及原生整型边界。
原始项目源码来源和 blob 保留，修改文件的登记由保留改为适配。尚未
对本次变更做干净构建、发布或发布包测试。

## 列表和编辑控件的原生滚动协议

将原 `win16_scroll_horizontal_thumb_messages`、`win16_scroll_list_axis_owned` 和 `win16_scroll_edit_thumb_messages` 的实现移至公共 `scroll_state.h`，分别由 Win16 滚动输入和产品适配直接调用，旧实现及声明已删除。这些判断描述原生列表、编辑控件的消息范围和轴限制，不含 Win16 的滑块几何、计时或画笔；调用者仍可决定回退到原生处理。

双位宽增量构建及公共测试通过，覆盖 65535/65536、页大小、负范围、多列列表轴和原生编辑控件；Win16 几何测试各通过 791878 次检查。自建启动器加载增量 DLL 的真实列表和编辑控件分别完成双轴拖动、位置改变和捕获释放。测试发窗口消息，未验证物理鼠标；Win2000 尚未调用这一接口。该次改动尚未干净构建或发布。
