# M0 T25 S5 P6：不使用隔离桌面的加载回归

针对 [P5](M0-T25-S5-P5-disabled-close-command.md) 发布版，直接从 `O:/winnt` 使用现有双位宽自有启动测试程序：x86/x64 测试启动器到 x86/x64 目标四种载荷组合均报告 `selected=win2k win16_absent=1`；x86/x64 目标各自创建 x86/x64 子进程的四种传播组合均报告 `propagated=1`。两个已发布 Win16 DLL 的 x86/x64 ABI 检查均通过。这些是进程加载和接口结果，不证明视觉、真实输入或全部应用兼容性。

首次传入 `O:/winnt` 时四项因目录格式校验返回错误 13，换为标准 Windows 格式 `O:\winnt` 后四项均通过；前者是测试调用参数不符合组件路径契约，保留此失败而不计通过。测试程序直接运行自有目标、不创建隔离桌面；使用既有 `build/.ninja`，没有临时构建副本。没有产品源码或二进制变化，assets 和 `O:/winnt` 与 P5 摘要一致。完整包测试、真实 Alt+Space/Escape、用户视觉验收仍未完成；S5、T25 保持开放。
