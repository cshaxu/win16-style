# M0 T25 S4 P50：实际旧版窗口回归

对 P45 发布包，以 x64 自建私有桌面探针分别启动本机 32 位旧版计算器、录音机及扫雷。三者均观察到 19 像素标题、菜单命中和打开、模拟活动及失焦标题颜色，以及一次程序位置变化后仍有经典标题。三个样本均没有最大化按钮或可调整尺寸边框，相应操作不适用，不计通过。计算器和扫雷正常退出。

录音机在退出阶段超时，测试结束了自建实例，不能算整体通过；本次未读取其退出对话框内容，不能确定原因。此前 P21 已记录未套样式和套样式的该样本均出现带 Yes／No 按钮的模态窗口及退出超时，该历史对照不证明本次原因相同。此次仅使用合成消息与一次程序位置变化，未验证真实鼠标、其他 DPI 或原版视觉。没有产品二进制变化、重新发布或额外临时包。S4 和 T25 保持开放。
