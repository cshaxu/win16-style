# M0 T25 S7 P9：跨位宽传播后的窗口附着与绘制

[S7 P1](M0-T25-S7-P1-real-apps.md)的四种父子位宽测试证明 DLL 传播，但未观察子进程窗口。本次扩展同一载荷测试的可选模式，让父、子进程分别创建自有窗口，验证仅加载所选 Win2000 DLL、窗口实际附着、标题高度、经典颜色采样与窗口销毁；输出分别标记 parent/child、位宽和各阶段。x86→x86、x86→x64、x64→x86、x64→x64 四项均通过；未加载样式的双位宽负对照按预期拒绝，原有无窗口传播四项及基础载荷两项通过。

测试从 [S5 P9](M0-T25-S5-P9-caption-command-order.md)发布包加载双位宽 DLL，均为自有窗口与有限像素采样，不能推断真实键鼠、全部应用或逐像素一致；运行时未创建或切换隔离桌面。新增四个包测试用例并使其串行，避免窗口相互遮挡；未运行包含隔离桌面的完整包矩阵。CMake 仅给测试目标增加系统 USER32/GDI32 链接，产品源码和二进制未改，assets 和 `O:/winnt` 仍为 P9。S7、T25 保持开放，无临时构建副本。

工作区已有并行方案修改，未在此工作中覆盖或提交。
