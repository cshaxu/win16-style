# M0 T29 S20 Win32 基础控件

## 首轮基线

两套生产入口分别在 `appearance/win3x/control/control_install.c` 和
`appearance/win2000/control/control.c` 打开主题。先统一按钮、复选、单选和分组，
随后接入编辑框、列表和组合框、静态文字与分隔、滚动条。保留原控件数据、通知、
捕获、DPI、启停和应用自绘契约。复合控件及专用框架能力由 S21 承接。

| 能力 | 现有共享基础 | 迁移重点 |
| --- | --- | --- |
| 按钮、复选、单选、分组 | 按钮状态快照、`classic_push_color`、`classic_choice_entry` | Win16 读主题索引图而 Win2000 使用自己的边框及字形。共用图形装入、状态、几何和绘制。 |
| 编辑 | `application/control/edit`、`edge` 和控件实例 | 对照客户区边界、只读、禁用、高 DPI 及原生文字、选择。 |
| 列表和组合 | `list_snapshot`、`combo_snapshot`、`control_native_combo` | 从主题读颜色和表面，保留父窗调色、自绘、下拉及标记。 |
| 静态文字、分隔与分组 | `application/control/basic`、按钮快照 | 共用主题可见配方，保留应用字体、内容、位图及通知。 |
| 滚动条 | `scroll_controller`、`scroll_surface`、`scroll_track` | 从主题装入共享几何和绘制，覆盖客户与非客户、长短轨、DPI、命中和恢复。 |

在既有 Ninja 树中运行双宽基础共享测试 18/18，覆盖按钮、组合与列表快照及
滚动条消息、几何、托管、跟踪、控制器和资源。另跑 Win2000 原生控件矩阵
双宽 30/30，覆盖按钮、静态、编辑的普通／DPI 感知及 Common Controls v6
组合，和滚动条布局、附着。它们均为迁移前基线。

## 复选框和单选框索引图

两种控件的索引图由 MSStyles 资源层统一解码。Win2000 路径可从所选主题
取得原本用于 Win16 路径的图形，应用对应状态的主题色，并将图形放入原有
控件矩形。含索引图的原生按钮实例持有自己的映射引用，撤销时释放。随包
Win2000 主题省略索引图，原来 Marlett 路径仍可用。

x86/x64 增量构建、原主题的按钮状态和像素对照均通过。混搭夹具将 Win16
主题的复选和单选索引图传给 Win2000 的生产绘制入口，逐像素核对资源角色、
主题色和实际绘制矩形。按钮基线的普通和 DPI 感知、普通与 Common Controls
v6 共八项复测通过。来源清单 1,190 项通过。本轮使用既有增量树，未发布。

## 静态控件分隔线

两份主题用 CLASSIC_STYLE 1.10 的可选记录 13 声明平边或凹边。两套
STATIC 绘制调用同一分隔线函数。Win2000 的矩形边沿绘制也复用同一个
边沿原语，保留右下角覆盖顺序。省略记录的旧主题沿用原样。本次保留
两套适配器的控件实例与既有非客户区处理，未扩展控件支持范围。

x86/x64 增量构建中性 DLL、兼容 DLL 及聚焦夹具。两宽分别实测七项
CTest，用例包含普通与 DPI 感知、Common Controls v6、Win16 控件和
边沿绘制。另外，两宽各独立读回两份新主题，并让 Win2000 的 STATIC
绘制入口按两份主题分别绘制平边和凹边，检查实际外边、内边和未覆盖像素。
临时捕获目录已清理。本批未发布。后续将编辑、列表和组合框按共同的
表面及边缘配方合批验证。

## 列表文字和组合框内容区

两套字符串列表改用公共窗口快照和行绘制，共用背景、选区、文字内边距及焦点框。
Win16 适配器仍提供原生制表位和 VB 字体覆盖。Win2000 适配器仍从父窗口借用
应用画刷，未选中的行保留该画刷，焦点提示遵循原有 UI 状态。

Win16 与 Win2000 组合框的内容区配色取自 MSStyles 的窗口、选区和文字属性，
按钮图形与位置沿用现有适配。Win2000 EDIT 的父窗口配色路径开始消费同一
主题的普通窗口色与控件表面色。自定义画刷仍由应用提供。两宽共 20 项
CTest 通过，覆盖编辑框、列表和组合框的普通、DPI 感知及 Common Controls
v6 形式。两宽实际绘制夹具另走两套组合框绘制入口，核对替换内容区颜色
后的像素。

## 滚动条纹理

两套滚动条和 Win2000 按钮、滑杆共用一份棋盘纹理绘制，原来的刷子坐标、
两种像素色、填充区和 Win2000 原有纯色条件继续由调用者确定。滚动条的固定
与比例滑块几何仍各自选择，未完成主题声明迁移。

二次双宽增量构建通过。滚动条、边沿及共享输入控制器 20 项 CTest 通过，
两宽主题像素对照复测通过。来源清单 1,190 项通过。本批未发布。

## 滑块几何

将固定和按页比例布局、箭头优先与短轨命中收敛到
`application/control/scroll_geometry`。两个控件适配器通过 CLASSIC_STYLE
1.11 记录 14 选择滑块模型，通过既有记录 3 选择端钮基准。Win16 的单像素
重叠、压缩箭头与短轨命中，Win2000 的页大小与最小滑块仍按各自已有规则
计算。默认主题分别明确声明固定和比例。输入计时、窗口通知和窗口各处的
坐标适配沿用原有合同。

两宽增量构建通过。共 12 项 CTest 和 6 次直接探针通过，覆盖记录 14 的
生成与独立读回、畸形值拒绝、两套默认模型、原生控件及拖动。Win16 入口
读取自有窗口的 SCROLLINFO，对照同一输入下的 17 像素固定滑块与 15 像素
比例滑块，并验证比例滑块的命中。几何夹具每个位宽通过 791,881 条断言，
包含重叠边、短轨和 32 位范围。合并后两个旧年代布局模块已移除，来源记录
迁到共享模块，通过 1,187 项本地校验。本批未发布。

## 按钮边框

CLASSIC_STYLE 1.12 记录 15 独立声明阶梯圆角或双层浮雕。两种控件入口
调用同一份 C 绘制代码，共用纯色填充、边沿及棋盘纹理。默认主题继续使用
各自的边缘和内边距。原生按钮类型、状态、标签、图像处理和焦点回调仍归
控件适配。旧主题和旧绘图 ABI 保持兼容路径。

双宽增量构建及 16 项 CTest 通过，覆盖原生按钮状态、DPI 感知、Common
Controls v6、原生 Win16 控件连接和兼容绘图 ABI。另有四次直接探针通过，
验证两份主题读回、畸形按钮记录拒绝，以及在每套原生按钮入口只更改模式后
左、右边缘按主题重画。临时捕获目录已清理，来源清单 1,188 项通过。
分组框结构、编辑框边缘几何与滚动条端钮图形仍需继续核对。本批未发布。

## 分组框与编辑框边缘

CLASSIC_STYLE 1.13 记录 16 分别声明分组框和标准编辑框的平边或凹边。
两套适配共用边沿绘制。分组框仍以原标签高度和背景定位边缘，标准 EDIT 仍
在其原客户区或非客户区绘制。RichEdit、HotKey 和列表的既有边缘行为保留。

双宽增量构建、20 项 CTest 和四次直接探针通过。直接探针分别让 Win16
和 Win2000 的实际绘制入口读取两种边缘，核对分组框底边、编辑框左边和
原编辑框客户区尺寸。来源清单 1,188 项通过，临时捕获目录已清理。S20
仍开放，滚动条端钮资源迁移与正式批次验收尚待完成。

## 滚动条端钮资源

生成器将原 Win3.1 的四方向、三状态图形按索引写入随包主题。Win2000 主题
声明系统符号字形。两套适配共享索引绘制与系统字形绘制，仍从原视图获取
端钮尺寸、方向、按下及禁用状态。省略资源的旧主题可沿用既有兼容路径。

两宽构建通过。14 项 CTest 与六次直接探针通过，覆盖主题读回、每个位宽
12 张端钮的 3,468 个源像素、两个 DPI、原生滚动条和双缓冲以及组合框系统
字形回归。原始图形来源清单 1,188 项通过。本批尚未发布。
