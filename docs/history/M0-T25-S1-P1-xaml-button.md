# M0 T25 S1 P1：WinUI Button 阶段包

此阶段包尝试在已附着的 WinUI 3 进程中通过 XAML Diagnostics 接入默认样式来源的 Button，
使用运行时模板，并在窗口移除时尽力清除本层样式。只处理单一 UI 线程；非默认样式来源、
其他标准控件、UWP 内部控件及应用自绘未完成。正确类标识请求会把 DLL 固定至进程退出。

双位宽 GCC 16.1.0、Ninja、ccache 干净构建及同批四文件结构、资源和 ABI 检查通过。
实包聚焦 11 项通过，未覆盖完整矩阵或物理键鼠。自有 x64 记事本实包一次观察到 DLL、
诊断连接及 Button 样式记录；在同一 Button 上读取来源从 Local 恢复到 Default。
最终快照的测试脚本同时适配独立包路径和 CMake 编译器缓存类型。

实包 `global-common` 在私有桌面创建托盘返回 0x80004005 而失败；既有 O:/winnt 发布版
在相同对照中同样失败，因此未证明候选回归，也不能计作通过。输入桌面查询返回错误5，
实际屏幕与真实输入未验证；按钮发现此前曾间歇失败，近期对照成功不证明普遍稳定。
