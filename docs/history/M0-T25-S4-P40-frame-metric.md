# M0 T25 S4 P40：可缩放窗口边框度量差距

P34 发布包在本机 96 DPI 的自建普通可缩放窗口，标题上缘距外框上缘为 8 像素，标题高度为 19 像素。已知参考源码 `inctlpan.c`（SHA-256 `811b46564e55365a524be50efc3a2f8d486c5b07189b6ae3dd5dc7af21c969d2`）将可缩放边框度量设为 edge 加 `(iBorderWidth + 1) * border`；`server.c`（`6abebc6729807c2bc90e6fc2a2ae925ebaf67fca5fbcbd66ba8c905b5b72196d`）将 edge 设为两个 border；辅助功能默认配置 `schemes.h`（`fffb39be68850262eef82ac5672de66989621c97c4db3a5aa3bbd8818fe95769`）设 `iBorderWidth=1`。在基础 border 为 1 像素的常见 96 DPI 情况下，由此推算原版默认可缩放边框为 4 像素；实际值可随系统度量和配置改变，用户网图也不能当作精确度量依据。

这是尚未修复的可见几何差距，不将当前配色通过解释为原版外框尺寸通过。参考 `calcclrc.c`（`f43e16685e41b6af577b26c2ae147ff335d0307dda686341086ebe3af8d17a63`）同时以窗口边框度量计算客户区和菜单。修复应统一考虑左右及底部客户区边界、标题与图标、菜单位置、按钮矩形、四边和四角缩放命中，并分别验证普通／固定边框、菜单／无菜单、最大化／还原以及 DPI；只缩减绘制区域会造成重叠或错误命中。当前没有产品修改、重新发布或额外临时构建。S4 与 T25 保持开放。
