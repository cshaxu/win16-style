# M0 T18 S64 P101: NumberBox arrow witness investigation

Self-owned DelphiVCL4Python 1.0.7 x86/x64 TNumberBox samples at actual 144 DPI were observed with compact/inline spin options, normal and explicitly disabled. In each case the runtime drew four symmetric LineTo strokes in the same memory DC before StretchBlt copied that DC into the number box. Default enabled pen was black; disabled pen was RGB 6d/6d/6d. The import observer restores its slots and target/launcher exit codes were zero, with owned job empty. The exact dimensions and colors are observations, not an API contract.

A scratch-only geometric witness required four matching symmetric strokes on the same source DC immediately before the copy. Both default buttons in both layouts and widths matched. A white 17x14 test image without strokes was rejected by the witness and did not receive the scratch frame. A deliberately constructed test image with the same four strokes passed and received the frame in all eight test configurations: a real counterexample to using only shape/sequence/size as ownership. This artificial image was drawn directly through the observer wrapper, not from an actual application callback or from the runtime module; a class-owner/caller guard would reject this exact fixture, so it does not demonstrate that such a guard fails. It does establish that geometry alone does not establish ownership. Additional caller, drawing-scope and source-lifetime evidence, and a same-owner adversarial fixture, remain needed.

Changing documented spin ButtonWidth to 25 and ArrowWidth to 3 still produced four matching symmetric lines in both widths and layouts. The scratch frame had a literal 17-pixel guard, so it did not apply to these wider real buttons: a demonstrated coverage limit, not a reason to guess dimensions. For the default explicitly disabled real samples, source strokes and the scratch witness still matched; an observer-only frame comparison changed 168 compact or 258 inline RGB pixels per width, solely within the outer two-pixel button bands, with zero changes in inner button rectangles or outside. These disabled snapshots do not test disabled input or prove historical color fidelity. Both target and launcher exits were zero and owned jobs emptied; the disabled path deliberately skipped the change-event wait.

The geometric witness is a throwaway test observer, not an implementation or generalized VCL contract. No physical input, other versions/DPI, application same-owner drawing, asynchronous state, source reuse or exceptional cleanup is claimed. No product source or binary changed; both release locations still contain the P93 package. T18/S64 stay open.
