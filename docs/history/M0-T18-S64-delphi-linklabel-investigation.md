# M0 T18 S64: Delphi LinkLabel protocol investigation

A self-owned DelphiVCL4Python 1.0.7 sample with `TLinkLabel` and `TNotebook` was run in the current P93 assets package on x86 and x64 at 144 DPI. The actual link text was `<a id="link">Open</a>`; the exact registered and RealGetWindowClass names were `TLinkLabel`, with runtime owner `DelphiVCL.pyd`. It was not attached by the current package. The window class extra size matched the initialized system SysLink class (4 bytes on x86, 8 on x64); the same-owner temporary IAT observer saw the link forward its own WM_PAINT through CallWindowProcW to the registered native SysLink procedure. `LM_GETITEM` returned success for index 0, ID `link`, state `LIS_ENABLED`. Observer imports were restored, target and launcher exit codes were zero, and owned jobs became empty. These observations are not proof for other versions, markup, link events, font layout or teardown.

The product already supports native `SysLink` by substituting its shared typography while leaving the native markup, hit testing, focus and notifications intact. A candidate may reuse that route for a newly created exact TLinkLabel only after observing same-owner forwarding of its own WM_PAINT to the system SysLink procedure and validating its initialized native protocol; names or class-extra size alone are insufficient. The candidate must test normal/disabled/visited links, markup and independent user events, font restoration, reentrant removal, wrong caller, no native witness and both widths; old package must fail a meaningful positive test. Same-snapshot clean build, actual package test, resource/ABI gates and both installation destinations remain required before release.

The ordinary `TNotebook` and its `TPage` were separate runtime-owned windows with no native superclass found and no current attachment in the tested default sample. No general claim about notebook appearance, pages, content or behavior follows from that observation. The current Python package does not expose MaskEdit, RichEdit or ScrollBox; an initial attempted sample had no controls and exited before observation, so it provides no evidence for those types. No product or binary was changed. T18/S64 remain open.
