# M0 T25 S4 P47：带滚动条窗口的外框几何

对 P45 发布包，在 x86、x64 私有桌面各创建一个同时带横向、纵向非客户区滚动条的普通可缩放窗口。两种位宽的滚动条均与客户区相邻而不重叠，且各自箭头区域命中 `HTVSCROLL`、`HTHSCROLL`；已将该场景加入包回归。探针使用 MinGW GCC、Ninja 和 ccache 双位宽增量构建。

此检查不证明滚动条内部视觉或交互与 Windows 2000 一致，不覆盖实际鼠标滚动、DPI 变化及所有应用；它只验证当前外框几何与原生滚动条的位置和命中。没有产品二进制变化、重新发布或额外临时包。S4 与 T25 保持开放。
