# M0 T25 S8 P11: 修复菜单下方重绘残影

用户截图显示 Solitaire 菜单下方的重复文字和浅色横带。实际窗口测得系统原生菜单
矩形与新客户区重叠约 13 个屏幕像素；强制非客户区重绘后，发布版 Solitaire
客户区顶部 9 行被原生菜单底色覆盖。此前中性菜单命中修复的是热跟踪，不能覆盖
这种系统重绘路径。

Windows 2000 外框处理非客户区绘制后，调用共享窗口辅助函数，仅在原生菜单与
客户区确有重叠时，要求应用重画该重叠横带以及紧邻的一行原生底线。没有应用名
特判，不在鼠标悬停时主动刷新整个窗口。实际 Solitaire 候选对照中，原版出现
9 行灰色，修复后采样的顶部 16 行均为绿色。
