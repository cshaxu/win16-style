# M0 T25 S5 P12：实际程序 DPI 与可见标题采样

针对 [P10](M0-T25-S5-P10-real-app-regression.md) 和 [P11](M0-T25-S5-P11-solitaire-environment.md) 的 demo 最大化采样无效，探针观察到窗口外框 `-7,-7,1288,680`、采样点 `(69,9)`，而窗口 DC 裁剪区上边是 11；该点不可见，因此 `GetPixel` 返回 `CLR_INVALID`。探针改为将采样点限制在标题内可见裁剪区，并在不可见时仍返回无效，不把失败算通过。

另一处测试误判是探针坐标被自身 DPI 上下文虚拟化，却用目标的 144 DPI 推算标题高度：看到 19，错误期待 29。现在实际窗口测试临时采用目标窗口的 DPI 上下文并在结束时恢复。双位宽增量编译通过；受限环境外对 [P9](M0-T25-S5-P9-caption-command-order.md) 发布版测试：x86/x64 探针下 demo（144 DPI）和 Solitaire（96 DPI）均通过标题、菜单、激活消息、最大化/还原、移动和调整尺寸；x64 探针下旧版记事本（96 DPI）同样通过。所有目标均为自建实例并已退出，未切换桌面或发送真实键鼠。

修改仅限测试及其来源摘要，无产品二进制变化；两个发布目录仍为 P9。有限采样与程序消息不等于完整视觉、真实交互或其他 DPI 已验证；完整包矩阵和真实 Alt+Space/Escape 仍未验证。S5、T25 保持开放。无临时构建副本。
