# M0 T29 S25 托盘入口与控制台

继续 T29，使用 S25 执行用户要求的命令调整。发布包格式、主题发现及
启动后的目标接入机制沿用现有契约。

| 正式命令 | 实际行为 |
| --- | --- |
| run16s.exe | 打开托盘，初始保持原始样式。独占控制台在托盘注册后脱离。 |
| run16s.exe Win16 application.exe | 用 Win16 目录启动程序。GUI 成功后释放启动器独占控制台，保留共享控制台。 |
| run16s.exe Win2K application.exe | 采用相同的启动和控制台契约，由主题目录决定风格。 |
| run16s.exe --global | 公开参数已移除，返回用法和退出码 2。 |
| 两主题下的控制台目标 | 使用原有控制台，等待程序完成并原样返回退出码。 |

启动器保留 Console 子系统以维持 cmd 的等待和重定向。独占控制台在最初
创建时仍可能短暂出现。分支共用现有控制台识别。GUI 提权进程使用隐藏
启动请求，控制台目标保持正常显示。托盘提权由内部入口交接。独占控制台
路径在请求系统提升前脱离，子进程保持脱离。共享控制台路径按现有机制
附着和恢复诊断句柄。

生产修改 5 个 C／头文件，增加 37 行，删除 29 行。控制台所有权判定留在
启动层，成功托盘的释放点在注册后，控制器仍拥有原有消息循环。对照
源代码和测试中的公开旧参数，更新 13 个集成夹具为无参数调用。
两个既有诊断夹具补传 Win16 目录。更新对应来源摘要，原始图形未变。

## 实包交付

双位宽干净构建使用 C17、MinGW GCC、Ninja 和共享 ccache。ABI、
PE、公共组件边界及主题读回通过。x86、x64 编译分别用时 94.8、
112.3 秒。缓存计数变化为 2072 次命中、14 次未命中。
最终同快照七件先发布至项目 assets 和 O:/winnt，再测试已发布启动器。
最终正式包 SHA-256 与测试清单见[发布记录](../etc/release.json)。

首个候选在真实启动验证中发现托盘页已注册时，独占控制台仍可见。
最终包改为脱离，真实探针用 AttachConsole 确认启动器已无附着控制台，
退出错误 6。共享对照通过自建 cmd，托盘进程仍属于同一可见控制台。
两次均保持原始样式，清理自有进程后，托盘窗口退出。

实包 13 组针对性验证通过，另有真实托盘独占、共享控制台两组和
独立启动的 x86 CUI、x64 CUI、x64 GUI 三组通过。两宽 CUI 均等待目标、
有控制台窗口并传播退出码 42。GUI 目标无控制台，启动器先返回 0。
两宽提升单测覆盖控制台可见性、独占与共享托盘交接和取消。
实际 UAC 提示链未触发。未执行完整的产品测试矩阵。

初轮有一个既有旧程序拒绝测试夹具默认创建了私有桌面，随后已退出。
未切换输入桌面。该轮结果作废。发现两个既有测试缺少主题参数后，
仅独立重编测试夹具，从直接工作入口重跑，正式包未改。
两个诊断夹具均成功，只操作自建目标。未使用 computer-use 或物理输入。
