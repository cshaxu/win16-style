Their redraws made two `FillRect` calls over the 748x698 white parent background and one 75x30 WHITENESS `PatBlt`, plus two to four `StretchBlt` calls. These included a 75x30 memory bitmap and, for some visible states, subrectangles of a 520x720 32-bit theme bitmap drawn into that memory DC before a final transfer to the owned control's window DC. This identifies this particular application's drawing path; bitmap offsets, module addresses and colors are not a public or cross-version state contract.

Its measured blue pixels changed 1914 -> 0 -> 1914 for each input route, focus remained on the control for the keyboard test, capture returned to null, and `BM_GETCHECK` returned 0 in both visual states.
