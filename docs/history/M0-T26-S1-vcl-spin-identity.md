# T26 S1 VCL 微调控件身份识别

VCL `TSpinEdit`/`TSpinButton` 的线程、类、父子关系与模块身份检查已从 `win16-control/spin_identity` 移至 `lib-style/common/control_vcl_spin`，改用 `style_control_vcl_*` 名称并纳入公共控件库。该组件只判断满足既有条件的控件，不引用 Win16 字体、调色板、绘制或产品私有实现；Win16 附着和绘制路径使用公共接口，旧路径和符号已删除。规则是针对已见 VCL 形态的严格判定，不声称覆盖所有 VCL 版本。

双位宽增量构建及仅链接公共控件库的反例测试通过；自建启动器加载增量 DLL 后，双位宽实际 VCL 微调模型通过绘制、裁剪、重入、异常展开及移除，微调编辑框模型通过字体变化时保留按钮区域等检查。首次编译因头文件相对路径遗漏失败，修正后通过；临时包已清理。Win2000 尚未接入该识别，真实 Delphi 程序和正式发布包尚未验证。

补充独立消费者验证：不加载 Win16 渲染库，直接创建同模块的 `TSpinEdit`/`TSpinButton` 自建窗口，公共组件在 x86/x64 均识别该结构；更换父窗口后拒绝。它只证明本测试覆盖的现代 VCL 形态与父子关系，不代替真实 Delphi 程序测试。
