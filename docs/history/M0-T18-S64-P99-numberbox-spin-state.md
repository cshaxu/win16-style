# M0 T18 S64 P99: NumberBox spin state prototype

The P95 scratch-only observer was extended to track a synthetic left-down coordinate and switch its frame from raised to sunken only on the button under that point. With DelphiVCL4Python 1.0.7 at actual 144 DPI, both widths and compact/inline layouts showed raised edge samples `ffffff/a0a0a0` and sunken samples `696969/e3e3e3` for the clicked button, while its sibling remained raised. A direct click retained the native value/OnChange behavior and targets and launchers exited zero with empty owned jobs. These samples are system color values, not a universal appearance specification or a complete screenshot acceptance.

A synthetic cancel-mode comparison exercised both widths and layouts with and without the prototype: value stayed 72, no second OnChange was logged within the bounded wait, capture was released and imports restored. An initial drag-out test exposed a real prototype bug: it continued drawing the button sunken after the pointer moved away. The scratch observer was changed to track both down origin and current pointer, drawing sunken only while both fall in that button. The corrected prototype showed only raised frames in the post-down, pre-up drag-out interval and no second event in all four architecture/layout configurations. This is a behavioral witness for these samples, not a general reentrancy or mouse-tracking proof.

An initial drag-out-and-return test incorrectly expected a click; the P93 baseline also did not emit one. Repeating the two-width, two-layout baseline/prototype comparison showed the same no-second-event result and released capture in all eight; with the prototype, the observed frame did turn raised while outside and sunken again on return. The reason a returned synthetic gesture produced no event is not established and physical mouse behavior is not inferred. The proof that the newly drawn frame visually matches actual runtime state on every later asynchronous paint remains incomplete. The prototype still lacks a reliable content-neutral source ownership witness; other button, disabled, keyboard press, resize, clipping, destruction and application-draw negatives remain open. It is not production code and no product or binary changed. Both deployment directories remain on P93. T18/S64 remain open.
