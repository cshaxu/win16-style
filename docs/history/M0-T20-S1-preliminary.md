## 真实应用入口和旧文件框桥接原型（未交付）

共享冲突实验：x64 自有临时文件用本进程无共享句柄锁定时，现代系统在 FOS_SHAREAWARE 下派发 OnShareViolation，旧式 GetOpenFileName 发送 SHAREVISTRING；分别接受后两者返回结果。实验将现代 ACCEPT/REFUSE/DEFAULT 映射到旧式 SHAREVISTRING 响应，x64 的 ACCEPT、回调路径、结果与引用探针通过；x86、REFUSE、DEFAULT、网络共享、多监听者和异常尚未验证，现代标志未订阅事件仍回退系统。参见微软 [OnShareViolation](https://learn.microsoft.com/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifiledialogevents-onshareviolation) 与[旧式对话框通知](https://learn.microsoft.com/en-us/windows/win32/dlgbox/open-and-save-as-dialog-boxes)。

补充首次 REFUSE、第二次 ACCEPT：x64 系统对照及 x86/x64 实验旧布局均保持窗口、两次回调后一次 OnFileOk，路径和引用验证通过。该用例已加入双宽系统与发布回退包测试队列；DEFAULT、网络共享、多监听者、异常及实际包测试依旧未覆盖。

覆盖事件多监听者对照：两名监听者按顺序注册，第一个先 REFUSE、后 ACCEPT；x64 系统及实验中第二监听者不收到这两次 OnOverwrite，但最终 OnFileOk 两名监听者各收到一次，两个引用均释放。原临时探针沿用单监听者断言而退出 1，改成独立断言后系统和实验均退出 0；双宽系统/正式包回退用例已登记，其他监听者响应组合及 x86 实验尚未验证。

第一个监听者返回 S_OK/DEFAULT、第二个准备 ACCEPT 的 x64 系统对照发现系统仅调用第一个并显示系统确认；旧实验错误地调用第二个并绕过确认，原测试因此与系统不一致。修正实验的覆盖派发后，系统及实验各完成一次覆盖回调、系统确认与两个 OnFileOk，引用均归还；确认测试依赖本机英文界面。失败 HRESULT 的多监听者行为、共享事件是否相同、x86 和跨语言尚未验证，实验仍关闭。

第一个监听者返回 E_NOTIMPL 时，x64 临时系统/实验对照均继续调用第二监听者并接受；该临时探针沿用 DEFAULT 断言退出 1。改为独立断言后 x86 系统及实验通过，两个回调和引用正确；x86 实验的 S_OK/DEFAULT 也显示确认并通过。E_NOTIMPL 双宽系统及发布回退用例已登记，其他失败 HRESULT 和共享事件仍未证明。

第一个覆盖监听者返回 E_ACCESSDENIED 的 x64 临时及 x86 持久系统/实验对照也继续调用第二监听者，且 OnFileOk 和引用释放正常；对应双宽系统/发布回退包用例已登记。此结果只证明这两种 HRESULT，不推广到全部错误值，也不证明共享事件相同。

共享事件双监听者 DEFAULT 对照：首次实验错误地继续调用第二个并接受；系统仅调用第一个并显示共享警告，原对照因未处理警告超时，不能计作通过。修正实验为首次成功响应即停止派发；随后 x64 私有桌面探针自动关闭自有警告并取消对话框，系统和实验均只调用第一监听者、未调用 OnFileOk，两个引用恢复、退出 0。该测试为临时本机探针；失败 HRESULT、x86 和更广泛重入未覆盖。

补充 x86 系统和实验的共享 DEFAULT 对照均观察到同一警告和资源清理；x64 第一个监听者返回 E_NOTIMPL 时系统及实验都继续到第二个 ACCEPT 并返回文件。首次构造 E_NOTIMPL 探针时替换未生效，实际仍返回 S_OK/DEFAULT，退出 1；核对源码并修正替换后两者退出 0。该测试仍为临时探针，其他失败 HRESULT、网络文件及重入未覆盖。

多选事件研究：x64 系统对照的两次 OnFileOk 回调内 GetResults 均返回两个项目；临时探针仍含单选结果断言而退出 1，仅作此观察证据。实验已尝试复制旧式多选缓冲区供既有解析器构造回调结果和撤销清理；但复用现代对照的双引号预设文件名时旧对话框返回 0x8007000d、未显示，故该尝试尚无有效运行证明。应使用旧式真实列表多选来测试，不能视为已实现或发布。

现以旧式文件列表真实选中两个含空格文件：x86/x64 实验均在首次 OnFileOk 否决后再次调用，回调中 GetResults 各含两个项目，最终结果也包含两条正确路径且监听者引用归还。x64 加强回调内完整路径断言后再次通过；x86 加强版尚未重跑。取消、单项、快捷方式、异常、无短文件名和系统原生同等选择的完整矩阵仍未证明，实验继续关闭。

后续 x86 强化回调路径断言通过；x64 实验单项选择、取消、快捷方式跟随与保留各通过，回调及最终路径、取消无 OnFileOk、监听者引用均检查。以上仅为私有桌面实验，x86 各边界、系统原生等价选择、无短文件名、回调异常与实际包仍未覆盖。

x86 实验单项、取消、快捷方式跟随及保留补测通过。多选 OnSelectionChange 的 x86 普通文件与 x64 快捷方式实验取得有效当前项目；跟随模式观察到选择时为 .lnk、最终结果为目标。最初测试误把结果目标当成当前选择预期而退出 1，分开两类路径后实验通过；尚未用现代系统同等快捷方式选择对照，不能把该实验观察推广为系统契约。异常与实际包仍未覆盖。

现代系统 x64 快捷方式多选对照确认当前选择为 .lnk，而最终两个结果为目标文件；x86 系统含空格多选事件结果也通过。对照同时发现多选后 GetResult 返回 E_UNEXPECTED（0x8000ffff），无事件 x64 同样如此，而已发布桥接错误返回 E_FAIL（0x80004005）。现修正共享结果分支并增强精确错误码断言；x64 实验旧布局通过，已发布包负例按预期退出 1。该修复涉及默认产品代码，尚未完成双宽正式包验证和发布。
