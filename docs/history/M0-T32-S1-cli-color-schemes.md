# M0 T32 S1 命令行配色

启动参数接受目录或目录加冒号和配色标识。显式配色沿用托盘的资源和标识。
未指定配色时使用主题描述中的 ColorStyle；两种方式均继承描述的字号等设置。
主题描述只读。既有启动载荷和提升命令使用同一选择；自提升从会话的主题标识
恢复目录与配色，保留原来的目标参数。无参数托盘行为保持。

验证以双位宽普通原生窗口、错误诊断和提升请求参数为范围。
