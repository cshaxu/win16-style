# M0 T25 S4 P44：系统图标不覆盖菜单

P42 缩窄边框后，系统图标原生矩形高于 19 像素标题，重绘时覆盖菜单顶部三行。以 P43 发布包的 x64 窗口采样，该范围 60 个像素均非经典菜单面色；候选在 x86、x64 均为 0。现将图标区域限制在标题高度内，并按系统小图标尺寸居中；未改图标来源或系统菜单协议。测试窗口通过 `WM_NCACTIVATE` 触发重绘，范围是当前 96 DPI 样本。

纯 C17、MinGW GCC 16.1.0、Ninja、ccache 双位宽干净构建，源码快照清单 SHA-256 `4a8e38d1d7be08c4758344650da8d50b000995a9f6417df0144ef88a24587c11`。同批包最终 24 项直接影响路径串行回归通过、无跳过，包含双位宽图标、菜单、边框及启动；不是完整矩阵。已发布到 assets 根目录与 `O:/winnt`，与测试包摘要一致：
