# M0 T25 S4 P41：窗口边框几何基线

新增单窗口几何探针，测量普通顶层窗口的标题顶部、三边客户区距离、左边命中及系统图标／菜单栏的原生位置。在 P34 发布包、本机 96 DPI 的私有桌面分别运行 x86 和 x64：固定边框有菜单与无菜单均为 3 像素，左边命中 `HTBORDER`；可缩放边框两种情况均为 8 像素，左边命中 `HTLEFT`。x64 可缩放带菜单样本的系统图标从外框相对 `(8,8)` 开始，原生菜单栏从 `(8,31)` 开始。每种情况单独进程运行且正常退出。

最初将四种窗口放在同一探针进程中，四组数据均已输出，但驱动报告私有桌面未立即释放；该次不计通过。复查时 `Win16S-Dialog-10420-23125718` 仍可打开，持有者未确认，不能声称该桌面已释放。后改为每进程一个窗口，八个单独测量均通过。探针只记录基线，没有将当前 8 像素固化为期望的 Win2000 结果；没有产品二进制变化或重新发布。测试不覆盖真实鼠标、DPI 变化、最大化或修复后的行为；S4 和 T25 保持开放。
