# T26 S1 现代窗口外框生命周期审计

范围：`lib-style/win16-window-uwp/frame.c` 的完整函数与其调用的 `lib-style/uwp` 组件；不把源码迁移误认作真实 Win2000/UWP 支持。此处是逐函数局部审计，不能代替全仓覆盖。

| 入口或状态 | 现状和拟归属 | 验证和限制 |
| --- | --- | --- |
| `local`、`lookup` | 同线程身份已有 `lib-win32/style/window_identity`；子类查询依赖该宿主拥有的回调身份，可成为宿主内部机制。 | `frame.c` 的 `apply_actions`、`remove`、`surface` 均使用；真实宿主测试仍缺。 |
| `release`、`detach` | 引用计数、重入期间延迟释放、所有者/标题/表面子类及表面销毁是通用宿主生命周期；菜单状态、字体、菜单恢复及 Win16 控件状态清理由风格回调处理。拆分前须固定回调顺序和失败时资源所有权。 | 保持 `RemoveWindowSubclass` 失败时未脱离、同步消息重入以及表面捕获释放；当前真实分层窗口提交错误 5，不能以 mock 证明完整生命周期。 |

后续迁移应先建立无风格的宿主 API 和可运行的自建消费者，以验证安装、重入、销毁与失败回滚，再让现有 Win16 入口接入并移除原有重复；Win2000 现代窗口是否接入须按其产品范围决定，不能通过编译通过就声称支持。所有权保持调用者模块和状态直到所有子类回调返回；不把线程挂钩传播与样式宿主合并。

## 已抽离的宿主脱离生命周期

`lib-style/uwp/host.c` 现在负责所有者子类移除、脱离标记、标题子类移除、表面捕获释放/子类移除/销毁，以及回调重入期间的引用与延迟释放。调用方提供移除标题前后的风格清理和最终释放回调；Win16 现有 `frame.c` 真正使用该实现，菜单停止、Win16 菜单状态及字体释放仍在 Win16 回调，清理顺序保持。宿主安装、绘制、输入和菜单消息尚未抽离，此变更不代表其他风格已经实现现代外框。

两位宽的 `core-uwp-host` 使用自有原生窗口验证所有者子类移除失败、清理顺序、重入重复脱离、标题及表面移除和最后引用释放；`core-uwp-frame-hidden` 使用 Win16 实际外框入口验证三次应用/移除、标题销毁和所有者销毁。`core-uwp-frame --private-worker` 直接在现有桌面运行，不创建或切换私有桌面，x86/x64 在第 82 行由于真实分层表面更新返回错误 5 而失败；这不是通过项。首次公共测试缺少仓库既有子类导入库，两个进程均以 `0xc0000139` 无法启动，修正测试链接后重跑均通过。以上均为增量验证，尚未发布。

## 宿主安装事务

`style_uwp_host_start` 接收调用方已安装的所有者子类，统一安装标题子类、创建/安装表面子类、调用风格刷新以及失败回滚；同步创建时发生脱离会销毁新创建的表面。Win16 产品入口直接调用，保留所有者初始安装、Win16 字体/菜单状态以及所有权。双位宽 `core-uwp-host-start` 注入标题安装、表面创建、表面子类、刷新失败和创建重入，验证错误值、回滚顺序及资源释放；`core-uwp-host` 原生窗口测试和 `core-uwp-frame-hidden` 实际 Win16 外框入口双位宽重新通过。失败注入测试并非真实系统失败注入，隐藏窗口测试不涵盖可见表面提交；先前可见窗口错误 5 及未验证真实现代宿主的限制不变。本次为增量验证，尚未发布。

## 标题子窗口消息

标题子类现在由公共宿主持有：销毁时脱离，位置或显示变化时在原生处理之后调用风格刷新；窗口消息重入期间使用同一生命周期引用。Win16 的私有标题消息处理已删除。双位宽自建原生窗口测试验证显示消息刷新和刷新中重新脱离，保留释放顺序；Win16 隐藏外框的标题/所有者销毁及反复启停回归通过。真实 UWP/WinUI 可见窗口及表面提交仍未通过验证，以上是尚未发布的增量结果。

发布状态更新：上述增量代码已纳入[第十批候选](M0-T26-S1-shared-candidate-10.md)，发布及后续测试范围以该记录为准。

## 所有者子类安装

`style_uwp_host_start` 现负责所有者子类的安装，Win16 入口不再单独安装。所有者安装失败时，公共宿主标记脱离，不执行标题或表面脱离回调，调用方释放最后引用以销毁自身状态；其余安装失败继续使用已有的公共回滚。Win16 继续提供状态、风格绘制及宿主回调。双位宽增量测试覆盖所有者、标题、表面及刷新失败，创建和刷新中的重入脱离，以及隐藏窗口的重复应用/移除和销毁；通过。此项尚未干净构建或发布，真实可见宿主、分层表面提交及其他风格调用尚未证明。

所有者窗口的子类过程现由公共宿主持有：负责消息期间引用、销毁脱离、默认转发及位置、大小、显示、DPI、标题、主题和激活变化后的刷新。Win16 通过回调提供菜单消息和激活状态，不再持有第二份通用分派。公共自建窗口测试覆盖可处理消息、默认消息、刷新及脱离期间的生命周期；双位宽隐藏外框反复安装、移除和所有者/标题销毁回归通过。初次编译因缩进告警失败，修正后双位宽编译通过。此为未发布增量结果，不代表真实可见 UWP/WinUI 已验证。

发布状态更新：所有者安装和分派已纳入[第十四批候选](M0-T26-S1-shared-candidate-14.md)，该记录区分同快照静态测试与真实发布 DLL 测试。

## 表面子类生命周期

公共宿主现直接安装和移除表面子类，并负责回调期间保活、未处理消息的默认转发及表面销毁时脱离；调用方以消息回调提供绘制、命中和菜单行为。Win16 已使用公共子类并删除原有通用生命周期代码。双位宽增量构建及公共宿主、安装失败回滚、同步回调脱离、外部销毁和 Win16 隐藏窗口重复应用/移除测试通过。真实可见 UWP/WinUI 宿主及其他风格未验证；该次改动尚未发布。

## 表面输入事务

`style_uwp_input_message` 接管表面的鼠标捕获、按钮按下/悬停/释放和取消状态、边框拖动转发及鼠标事件路由。风格调用方提供命中几何、可按按钮和动作；Win16 的系统菜单、最大化及关闭规则仍在 Win16 回调，旧输入分派已删除。宿主持有回调期间引用，输入层检查脱离后不再执行动作。

双位宽增量构建通过；无 Win16 渲染库的公共自建窗口测试覆盖按钮、悬停、取消、双击、右击和刷新时脱离，公共宿主及 Win16 隐藏外框回归通过。测试以原生消息触发，不证明物理鼠标或真实可见 UWP/WinUI 应用；本次尚未发布，也未接入其他风格。
