# M0 T18 S64 P79: real disabled Delphi radio group

A task-local DelphiVCL4Python 1.0.7 sample set TRadioGroup.Enabled to false before showing the form. The current published x86/x64 DLLs were compared to the P75 package backed up by P77, using the existing isolated native observer, separate owned processes and a 144-DPI desktop. The observers reported exact DLL paths, disabled group windows and two TGroupButton children; the old group was not attached and the new group was attached in both widths. The frame's parent-client captures changed 616 RGB pixels per architecture; neither the title rectangle (8,0)-(104,25) nor the two observed child rectangles (8,26)-(248,116) changed in those parent captures. A parent-DC capture is not an independent child-window pixel capture and does not prove the complete child image is unchanged.

In all four runs, the native observer sent BM_CLICK to each disabled child and BM_GETCHECK remained `(1,0)` before, after and after the second click. This is synthetic message evidence for the disabled state, not physical mouse or keyboard input; the real enabled sample was tested separately in P72. Import observers reported restoration, the target process ended following WM_CLOSE, and the enclosing owned job was closed; this abbreviated driver did not check the target exit code or independently assert the job active count. Other Delphi versions, DPI, enable/disable transitions in the real runtime, and physical input remain unverified. The P77 product code and package are unchanged. Both destination directories were rehashed against the P77 tested package and all eight values matched.
