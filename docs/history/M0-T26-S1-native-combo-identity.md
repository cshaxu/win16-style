# T26 S1 原生下拉与日期控件识别

`lib-style/common/control_native_combo` 提供原生颜色下拉框和日期控件的身份、父窗口、模块、按钮几何及重入状态核验；这两项原在 `win16-control/native_combo_identity.c`。Win16 按钮绘制和实际窗口策略仍在风格层，Win16 产品及绘制直接调用公共核验。公共代码不引用风格私有头；Win2000 目前并未实现这两类控件绘制，也未宣称接入。

双位宽增量构建通过。自建原生 v6 控件测试验证两个正例以及 detached、父窗口、模块负例。首次未启用 v6 清单时，系统返回的颜色框 item 句柄为空、日期按钮矩形为空，正例失败；使用仓库已有 v6 控件清单后通过，未更改原有核验规则。分别使用自建启动器和真实增量 DLL 跑 Win16 VCL 颜色框及日期框，两种位宽的按钮像素、裁剪、交互、重入、异常及资源回归通过。测试没有创建或切换隔离桌面，未使用 computer-use；测试副本已清理。这是尚未发布的增量结果。

组合框内原生 EDIT 的类/模块与父子关系核验现也由公共组件提供；父组合框的资格由调用方回调决定，Win16 保留 VB 类名单和绘制策略。双位宽自建原生 v6 组合框测试覆盖真实子编辑框、错误父控件和空策略；使用自建 VB 运行时和增量 Win16 DLL 的双位宽产品测试验证组合框、编辑字体、重入及重新设定父窗口。未证明 Win2000 已使用此核验；增量改动尚未发布。

发布状态更新：上述增量代码已纳入[第十一批候选](M0-T26-S1-shared-candidate-11.md)，发布和后续测试范围以该记录为准。

旧式字体对话框中 owner-draw 组合框的控件 ID、父子关系和样式资格检查也已迁入公共控件组件；组合框类别判定由调用方提供，Win16 保留原分类策略。双位宽公共正负例、Win16 控件库独立链接，以及实际字体对话框 ANSI/Wide 确认和取消共八种组合均通过。此项尚未发布，未证明 Win2000 已使用该核验。
