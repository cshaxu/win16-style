# M0 T25 S4 P68：系统对话框和失活图标

对 [P62](M0-T25-S4-P62-caption-separator.md) 发布版，使用 `CreateDialogIndirectParamW` 创建真正的 `#32770`、`DS_MODALFRAME`、无标题及无专用图标对话框，在 x86 和 x64 分别观察标题左侧像素；均确认系统对话框类、系统菜单存在，且没有检测到误画图标。该测试加入包测试清单，实际单项通过；带专用图标的对话框及完整包矩阵未在本次验证。

在可见私有桌面使用两个自有普通窗口，程序依次切换激活，x86 和 x64 均确认标题活动/失活颜色变化，且切换前后图标区域均有 97 个非背景采样点。这证明样本图标在失活时仍可见，不证明所有图标的逐像素形状或真实鼠标焦点行为。新增验证只更改测试和来源摘要；产品二进制未变化，assets 与 `O:/winnt` 八文件摘要仍与 P62 相同。仅使用保留的 `build/.ninja` 增量构建，没有临时构建副本。S4、T25 保持开放。
