# M0 T18 S64 P69: bounded Delphi group-frame prototype

A scratch-only observer over the P68 self-owned DelphiVCL4Python 1.0.7 x86 and x64 samples at 144 DPI let the actual theme module draw the caption, then drew a one-pixel black frame over the group window DC while excluding the observed caption rectangle. With the default `GroupBox` caption, both 250x120 captures differed from their respective native group capture in 633 RGB pixels; the observed caption rectangle (8,0)-(87,25) and a separate central client rectangle (4,26)-(246,116) each had zero differing RGB pixels. Both owned samples closed and the observer restored its imports. These comparisons cover only the stated rectangles and captured repaint; they are not a guarantee for child controls or physical interaction.

An x64 caption `Settings and &Options` produced a wider observed rectangle (8,0)-(176,25), and the prototype excluded that observed rectangle rather than the default size. Its full pixel preservation and keyboard accelerator behavior were not independently compared. In an x86 empty-caption run, no text callback occurred and the frame prototype did not run, so that ordinary case remains native. The test prototype is not a product implementation and has not established a safe contract for empty text, reentrancy, clipping, dynamic changes, window-role transitions or other DPI and runtime versions.

A sample x86 stack captured while the theme module called `DrawTextExW` included UxTheme offsets `0x5ceca` and `0x61359`. On the tested system, the exported `DrawThemeTextEx` entry was at `0x612a0`; the caller stack is consistent with this route but does not by itself establish the full argument/return contract. The product currently hooks `DrawThemeText`, not `DrawThemeTextEx`. These offsets are diagnostic observations only, not a product identity or implementation mechanism.

No production or tracked test code, product resources or binaries changed. T18/S64 remain open; the group frame is not yet supported. User input, disabled controls, empty captions, detailed clip and repaint lifecycle, and actual package validation remain outstanding.
