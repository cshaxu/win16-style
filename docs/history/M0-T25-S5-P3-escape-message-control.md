# M0 T25 S5 P3：Escape 消息对照的有效性

遵照用户要求不使用隔离桌面，在当前桌面以自有窗口对照系统菜单：打开菜单后，分别向 owner 和菜单窗口投递 `WM_KEYDOWN/VK_ESCAPE`，并设置三秒定时器作为退出保护。套用 P70 样式和未套样式的原生 x64 窗口均未在定时器之前因该消息退出菜单；两种情况最终均由定时器结束。该实验不能作为真实 Escape 行为的有效替代，也不能据此认定样式实现有缺陷或已经通过。

实验性探针已撤除，重建了保留的 x64 增量测试目标；自有窗口和进程均已退出。本次无产品源码或二进制变化，无临时构建副本。[P1](M0-T25-S5-P1-system-menu-baseline.md) 的真实 Alt+Space/Escape 超时原因仍未确定；S5、T25 保持开放。
