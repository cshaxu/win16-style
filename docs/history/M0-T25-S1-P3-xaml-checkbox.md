# M0 T25 S1 P3：WinUI CheckBox 阶段包

在已有 WinUI Button 基础上加入默认样式来源的 CheckBox 模板及三态，按控件的
XamlRoot 映射窗口归属，允许同一 UI 线程多个附着宿主分别恢复；最后宿主退出时
停止共享会话。内部辅助窗口不再直接停止会话。未知控件归属保留其样式，非默认
样式来源不覆盖。此为阶段交付，S1 和 T25 保持开放。

GCC 16.1、Ninja、ccache 双位宽干净构建，来源、资源、ABI 和四文件包检查通过；
同批包13项聚焦回归全部通过、无跳过，干净树集合/适配器/会话双宽各三项通过。
同批包在自有 x64 记事本中分别验证动态 CheckBox 自动接入及双窗口按窗口恢复；
测试控件三态与焦点状态使用程序化对照。不是完整应用矩阵或真实键鼠、像素验证。

当前限制：单 UI 线程；旧版运行时或空 XamlRoot 无法确定归属时样式可能保留；
跨线程并发、应用自定义样式、视觉 DPI、真实输入和不同 WinUI 版本未全面验证。
手动验收未进行，未证明全部 WinUI 或 UWP 内部控件已支持。
