# M0 T25 S4 P6：标题按钮按下时保持经典配色

P4 实际鼠标按住最大化按钮时，系统内置跟踪循环绘制宿主浅灰色；增量测试观察到 252 个宿主面色像素。窗口附着器接管标题按钮捕获、按下、拖离及释放，并在按钮内释放后投递系统命令。它更新 `WM_GETTITLEBARINFOEX` 的按下状态；不声称完整 MSAA/UIA 事件已支持。

自建私有桌面的增量 x86/x64 测试实发鼠标：按住时经典灰各 362 像素、宿主面色 0；拖离取消、点击最大化及还原均通过，桌面与指针恢复。其后只对最小化状态回退和系统命令坐标做调整，因此该增量构建不等同于正式包测试。
