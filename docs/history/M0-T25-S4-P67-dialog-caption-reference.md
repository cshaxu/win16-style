# M0 T25 S4 P67：原版对话框与失活标题对照

用户提供的原版画面中，前景 About 窗口标题没有图标，文字靠左，只有关闭按钮；后方 Solitaire 失活后仍保留图标，标题呈灰色渐变。只读原版 `ntuser/rtl/winmgr.c` 的 `_HasCaptionIcon` 按窗口类型和专用图标判断：普通非工具窗口可有图标，类对话框窗口并非一律有或无图标；`kernel/caption.c` 仅在该条件成立时画图标。用户图中失活标题靠右一处采样为 `#BEBEBE`，而原版源码 `kernel/globals.c` 的默认失活渐变终点为 `#B5B5B5`；本实现使用后者。截图所用实际配色没有独立确认，不把这张图视为默认系统色的直接证明。

对 [P62](M0-T25-S4-P62-caption-separator.md) 发布版，新增无类图标、`WS_EX_DLGMODALFRAME`、空标题自有窗口探针，双位宽在标题左侧未观察到多画图标，两个测试均通过。该探针不等同真实 `#32770` About 对话框，也没有覆盖带专用图标的对话框。此前 [P63](M0-T25-S4-P63-window-activation.md) 验证了双位宽活动蓝色与失活灰色切换；它没有单独证明失活图标形状。探针入口加入包测试清单，但本次未运行完整包测试。

另外允许已有 `--dpi-aware` 单独运行常规标题探针：在本机 144 DPI 下 x86/x64 的标题、按钮命中、颜色、图标和变化断言通过，DPI 感知工具窗口检查亦通过。来源清单和包用例选择器自检通过；本次产品二进制未变，assets 和 `O:/winnt` 的八文件摘要与 P62 一致，无临时构建副本。S4、T25 保持开放。
