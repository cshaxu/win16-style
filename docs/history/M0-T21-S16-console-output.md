# M0 T21 S16：提权控制台输出

独立原生 UAC 对照中，提权进程附着父控制台后，Win32 控制台句柄存在，但 CRT `fwprintf(stderr,...)` 返回 0 且流错误非零；无提权附着对照可输出。真实 UAC 下重绑 `stderr` 至 `CONOUT$` 后，`fwprintf` 返回 22 且流错误为 0。产品因此只在全局提权子进程附着控制台后重绑该流，不改普通目标启动或重定向入口；绑定失败返回 9。修改为 `main.c` 增加 3 行，来源清单摘要同步更新。

纯 C、GCC、Ninja、ccache 同快照双宽干净构建通过；同批四文件的 22 项聚焦实际包回归通过且无跳过，包含双宽 UAC 单元及全局生命周期。来源和原资源门禁通过。真实 UAC 候选包冲突对照利用自有会话名占用阻止接管，程序在控制台输出错误 183、退出 10，驱动退出 0。此前相同对照两次超时（258）未计为通过；旧版本对照退出 10 但未捕获错误文本，不能只凭退出码证明原因。此对照不证明完整全局接管组合或所有控制台宿主行为，完整矩阵及物理输入未覆盖。
