# M0 T18 S64 P165: bounded lookup-list nonclient frame

The official [TDBLookupListBox](https://docwiki.embarcadero.com/Libraries/Alexandria/en/Vcl.DBCtrls.TDBLookupListBox) descends from [TDBLookupControl](https://docwiki.embarcadero.com/Libraries/Athens/en/Vcl.DBCtrls.TDBLookupControl), a custom control; it must not be assumed to be a native LISTBOX. The user authorized completing implementable paths with integration validation later. This change extends the existing grid nonclient renderer only to an exact Unicode `TDBLookupListBox`, owned by the application executable with a same-owner parent, same thread/process, WS_EX_CLIENTEDGE and valid queried scrollbar information. Unknown identities, missing border/scroll information and reparenting fall back. The renderer does not take over client drawing, selection or data binding. No ABI or original graphic resource changes.

The self-authored dual-width model creates an application-owned control with a same-owner parent, a known painted client and an independent message-level state value. Its comparison measured 2,736 changed nonclient pixels and zero changed client pixels after removing styling, and retained the state. Wrong-owner parent, missing border, unavailable scroll information and reparenting all remained native or retired. Previous P164 failed the new positive attachment on x86 and x64; the candidate passed. The model is not a Delphi runtime, and the state variable is not database binding. A public demonstration download redirected to login and did not supply an executable; see [sample search](M0-T18-S64-datalist-sample-search.md). No real TDBLookupListBox, ANSI version, callback, selection/data binding, unusual DPI or physical input was tested.

The clean same-snapshot GCC/Ninja/ccache x86/x64 build and ABI passed (`s64-lookup-list-p165`). The actual four-file package passed 22 focused tests in 15.43 seconds without skips (`s64-lookup-list-p165-test`), including both popup/list models, lookup popup, in-place edit, data combo, native superclass, VCL MDI and menu cancellation. This is not full integration. The same batch was published to assets and `O:\winnt\system32`; all eight hashes matched and both installed locations passed both width models (`s64-lookup-list-p165-publish`). M0/T18/S64 remain open.
