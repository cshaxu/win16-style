# M0 T25 S4 P1：标题渐变及状态

针对用户提供的纸牌窗口截图，对照只读 Windows 2000 源码修正标题栏渐变区间及默认活动、失活端点，并更新标题文字、图标和状态重绘。原版源码定位、摘要、像素数据及同进程私有桌面清理断言失败见 [S4 审计](M0-T25-S4-window-audit.md)。原版资源未复制。

同一源码快照 SHA-256 `27eded610d47be40acb710606ccd6a4a8996a48b53cc27f846f11d1c1fea5531` 使用 MinGW GCC 16.1.0、Ninja 和 ccache 4.13.6 完成 x86/x64 干净构建。隔离桌面重点包测试 32 项执行通过，覆盖两位宽普通及工具窗口、激活/失活渐变像素、图标和标题变化、窗口尺寸状态、启动及传播。物理鼠标、完整集成矩阵和用户视觉验收未测试；单一进程连续创建两种窗口曾遇到的私有桌面清理失败不计通过。普通沙箱的一次测试有 11 项因隔离桌面受限跳过，随后在允许桌面的环境重跑全部 32 项且无跳过。
