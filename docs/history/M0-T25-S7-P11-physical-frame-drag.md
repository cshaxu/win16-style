# M0 T25 S7 P11：真实鼠标移动和拉伸

扩展自有窗口探针，在当前桌面以真实鼠标分步拖动标题栏，再拖动右下角拉伸窗口；自动保存并恢复指针位置。使用已发布的 `O:/winnt/run16s.exe --2k`，x86 和 x64 均观察到窗口移动、尺寸增大及操作后的经典标题颜色，测试实例正常退出。探针只在自有窗口获得前台后发送输入；未获得前台返回 skip。

该测试是一次移动、一次拉伸及结束后的有限像素采样，不能证明连续交互中没有瞬时闪烁或残影，也不能推断其他 DPI 或实际应用。没有创建或切换隔离桌面。测试不进入自动包矩阵，避免自动测试意外操作用户鼠标。产品二进制未变，两处发布目录八文件摘要一致；S7、T25 保持开放。
