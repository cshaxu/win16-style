# T26 S1 菜单坐标公共化

Win16 `win16-window/menu_scope.c` 与 Win2000 `win2k-window/system_menu.c` 均将菜单屏幕坐标转为弹出窗口的窗口 DC 坐标，以支持 `WM_PRINT`。两处相同的客户区相对窗口原点计算现在由 `style_menu_client_offset` 统一提供；菜单行读取、缓冲提交、各自外观及作用域仍由各风格负责。普通客户区 DC 偏移为零，获取窗口/客户区位置失败仍使对应绘制无效。

增量 x86/x64 编译通过；公共测试在真实自建窗口验证窗口 DC 偏移、客户区零偏移和无效窗口失败。Win2000 `system-menu-visual win2k-paint` 在两位宽验证实际菜单 `WM_PRINT` 的选中行颜色；Win16 通过自有启动器与自建窗口在两位宽验证系统菜单打印样式和条目恢复。这些是增量包测试，不代表正式发布包或物理鼠标验收；不创建私有桌面。测试副本清理后，增量构建缓存保留。
