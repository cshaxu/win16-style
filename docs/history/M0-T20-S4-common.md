# M0 T20 S4：常用对话框与控件验证

## 范围

以 S3 P2 发布包及同源干净重建包为基线；按 S2 矩阵验证用户关心的普通文件
打开/保存、Shell 和 COM 文件夹、查找替换、字体颜色、Print/PrintDlgEx、
页面设置、demo 分类和滚动条。验收单位是入口及其有限正常输入、确认/取消、
选择结果及控件状态，不将所有标志组合、应用自绘或系统跨进程窗口当成已完成。

已知 S3 首次包测试中 `dialog-com-x86-folder-accept` 超时，候选与 P1 发布包
单独对照均超时；旧探针查找文件框列表/驱动器控件，而现行普通 COM 文件夹是
系统 Shell 树。此结构不匹配是核实到的事实，但是否为唯一超时原因尚未证明。
本 S 使用 `dialog-tree-*-com-*` 现行树探针，保留旧测试失败，不将其算通过；
旧测试的改写或移除要在收口时显式处置。

## 验证计划

双宽干净包及实包必选核心，按双宽和 A/W 选取代表性文件、Find/Replace、字体、
颜色、打印和文件夹测试；增加横纵滚动探针。物理输入及环境原因 skip 明列。
截图只代表采样时的绘制，不能独自证明完整操作或 DPI 兼容。

## 实际结果

`s4-common-final` 以 GCC/Ninja/ccache 干净构建双宽，来源、图形资源、治理及 ABI
通过；对应实际四文件包 `s4-common-focus` 40 项通过、零跳过，耗时约95秒。
其中包含 x86 ANSI 与 x64 Unicode 的打开/保存、COM 单选、Shell 文件夹、
Find/Replace、Font/Color、PageSetup、普通打印取消和 PrintDlgEx 当前页，
以及双宽窗口/列表/编辑框滚动探针；必选 demo、首次注入及传播也通过。

六个滚动探针均记录横纵 hover/leave 和拖动、零差异；它们是受控原生测试，
不扩展为全部应用、DPI 或用户物理输入。demo 探针验证九页、27个对话框按钮
布局、九个打开/取消和部分文件/目录结果；截图留在
`build/t20-package/s4-common-focus/demo-pair/`，可复验但不是完整手工验收。
其 GDI 计数初始63、预热177、最终177，只证明该观察区间稳定，不证明无泄漏。

该 S 无产品源码或二进制改动，未发布新文件；已部署 assets 与 O:/winnt 的
P2 四文件摘要逐项一致。干净重建的四文件摘要均与部署包不同，因此本次实际
包测试针对重建包，不能称为对部署字节的测试；P2 部署包自身的 32 项测试及
