# M0 T18 S64: Delphi data-aware sample discovery

The official tDBF project publishes [demo 1.3.6](https://sourceforge.net/projects/tdbf/files/TDbf%20Demo%20App/TDbf%20Demo%201.3.6/). Its `tdbfdemo136.zip`, fetched into the registered `build/t18-s64-vb-mask-survey` scratch via the download page's actual mirror URL, has SHA-256 `4c1df83d1e07243cc7315f1759c5d6217408fb0ef0a4c919213af436499ef176`. The ZIP includes source, Delphi form resources, a GPL COPYING file and example DBF files, but no executable. `demo/simple.pas` declares eight `TDBEdit`, one `TDBGrid` and three `TDBNavigator` controls; its form resource contains the corresponding classes. Other forms also contain `TDBGrid` and `TDBNavigator`. The sample is a lead for a realistic data-bound probe, not a runtime witness; it has not been executed, copied into product source or used as a dependency.

An initial download response and a direct mirror response were HTML, not ZIP archives; neither was executed. The actual archive was identified by its PK signature and inspected as a ZIP. No `dcc32.exe` or `dcc64.exe` command was present on PATH and the checked standard Embarcadero/Borland program directories were absent. This is not an exhaustive compiler search. Next find an author-provided executable or a legitimately available Delphi environment, then use only isolated copies of the included data and verify native EDIT forwarding, data binding and behavior before considering a class candidate. No third-party code has been imported; no product source or binary changed.
