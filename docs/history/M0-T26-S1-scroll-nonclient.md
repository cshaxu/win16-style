# T26 S1 非客户区滚动条呈现分派

`style_scroll_nonclient_paint` 在公共滚动条组件中根据窗口样式选择横向和纵向轴，使用调用方提供的 DC 或临时窗口 DC，再调用风格画笔；不包含 Win16 绘制或调色板。Win16 产品直接接入，原私有重复函数和类型已删除。Win2000 未接入此接口，也未因此实现滚动条外观。

x86/x64 增量构建通过。公共测试覆盖无轴、双轴、调用顺序、借用与临时 DC；使用自建启动器及增量 DLL 的真实控件目标在两个位宽通过横纵拖动的捕获、位置和释放，以及 VCL 滚动容器的裁剪、通知、重入和清理。该行为测试不检查屏幕像素，也不代表 Win2000 已实现滚动条。测试未创建或切换隔离桌面，临时副本已清理。源码清单和公共源码边界通过；本改动尚未干净构建或发布。

发布状态更新：改动已纳入[第十五批候选](M0-T26-S1-shared-candidate-15.md)，发布后测试及限制以该记录为准。
# 第十七批后的滚动条按键映射

将方向键、Page Up/Down、Home/End 到标准滚动命令的映射从 Win16 原生滚动条处理迁入公共 `style_scroll_key_command`；Win16 仍在原位置调用，禁用状态和其余消息处理保持原样。公共测试覆盖所有映射及不识别按键，x86、x64 增量构建和测试通过；正式启动器调用的双位宽 VCL 滚动控件夹具通过。此为增量验证，尚未发布，也不证明 Win2000 控件已接入。

补充实际控件路径：VCL 模型在水平与垂直滚动条上发送 Left、Up、Page Up、Page Down、Home、End，分别观察父窗口的滚动命令及 `SB_ENDSCROLL`；原有 Right、Down 验证保留。使用增量 DLL 和启动器的 x86/x64 运行均通过。该测试发送原生窗口消息，并不代表物理键盘验收。
