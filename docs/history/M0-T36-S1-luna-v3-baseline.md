# M0 T36 S1 Luna v3 基线复核

用户准入 MSStyles v3/v4 任务，并确认原版 XP Luna 的蓝、银灰、橄榄绿窗口标题实测通过。
已发布标题栏验收还包括 [T35 的双宽实窗记录](M0-T35-S1-luna-glyphs.md)。

- 以 T35 发布清单核对 `assets` 和 `O:/winnt` 两处正式七件以及两份 Luna 样本，
  摘要均相符。样本来源见 [T30 原版资源记录](M0-T30-S1-luna-source.md)。
- 增量重建 x86/x64 的 `core-style-msstyles-v3` 和 `luna-frame-target`。
  两宽各通过原版三配色与三字号的九个组合、标题及普通按钮图像读回、字号和配色负例、
  v4 拒绝及 4 位图像绘制。产品二进制摘要保持相同。
- `O:/winnt/run16s.exe` 实窗补测中，144 DPI 标题交互 5/6 通过。
  x86 银灰失败在标题按下后的窗口 DC 采样断言。
  同一轮外框和普通按钮组合 3/6 通过。x86 银灰的撤销前后像素差异断言失败，
  x86 橄榄绿与 x64 银灰的按下像素差异断言失败。
  先行探针另观测到 x86 银灰通过而 x86 橄榄绿在撤销像素断言失败。
  首轮暂保留为失败证据。

## 复验与收口

普通按钮改用同步 `WM_PRINTCLIENT` 直接采样客户区绘制，验证目标像素确实被覆盖，
同时用 `BM_GETSTATE` 核对按下和释放。自建探针窗统一放入可用工作区前层。
保留标题命中、鼠标状态和像素断言，以及普通按钮按下与撤销的像素差异断言。
只重建 x86、x64 探针，正式产品源码及交付二进制没有变化。

- 用 `O:/winnt` 的发布版复跑双宽三配色，144 DPI 下标题交互 6/6、外框与按钮 6/6。
- 用 `assets` 的同摘要发布版复跑，双宽三配色的 96/144 DPI 标题交互 12/12，
  144 DPI 外框与按钮 6/6。每种配色的按钮正常、按下和恢复像素摘要在双宽间一致，
  三配色的正常态摘要互异，撤销后的普通按钮摘要一致。
- 两轮合计 30/30。结合用户验收和双宽九变体读回，S1 已达到 XP Luna v3 的既有
  Win32 支持基线。原版 Vista、Win7 安装镜像已在本机媒体库定位，尚未提取和定版。

当前 v3 路径消费 Luna 的标题、外框和普通 Win32 按钮素材，其他控件可走原生路径。
本轮证据范围为 XP SP3 Luna。其他 v3 主题、完整 XP 控件集及 UWP/WinUI 的 Luna
外框尚未验收。后续 Aero 工作以 [T36 实施顺序](../proposals/msstyles-v3-v4.md) 为准。
