# M0 T25 S5 P11：Solitaire 启动环境对照

[P10](M0-T25-S5-P10-real-app-regression.md) 的 623 可在受限环境中原生重现；受限环境外，同一路径 `D:/programs/misc/sol.exe` 原生启动并保持运行，测试随后仅关闭自有实例。使用 `O:/winnt/run16s.exe --2k --wait D:/programs/misc/sol.exe` 在同一环境直接启动，按父 PID 和映像路径确认新建 Solitaire，随后关闭该实例及启动器。故不能将受限环境中的 623 作为应用或样式本身无法启动的证据，也不推断该错误更深层原因。
