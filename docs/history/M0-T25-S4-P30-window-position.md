# M0 T25 S4 P30：实际程序单次位置与尺寸变化

以 P28 发布包及自建私有桌面进程，分别启动旧版 32 位记事本、32 位扫雷和本项目 64 位 demo。每个程序使用一次 `SetWindowPos` 改变位置；记事本和 demo 支持调整尺寸，同时各改变一次尺寸，扫雷不支持调整尺寸，标记不适用。三者均观察到位置变化，适用的两者观察到尺寸变化，变化后标题区域可读到经典色，窗口随后正常退出。

这是程序调用造成的位置与尺寸变化，不是用户鼠标拖动、连续缩放、闪烁测量或原版逐像素比较；桌面合成和用户视觉验收仍未验证。测试使用 64 位自建探针，产品样本跨 32／64 位；探针本身双位宽均已编译。外部程序只供本机可选验证，不是构建、运行或自动回归依赖。

本交付扩充自建探针及审计，不改变产品二进制；S4、T25 继续开放。
