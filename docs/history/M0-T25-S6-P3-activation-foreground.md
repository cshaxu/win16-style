# M0 T25 S6 P3：线程激活与系统前台

在当前桌面对 [S5 P9](M0-T25-S5-P9-caption-command-order.md) 发布版运行现有双窗口激活探针：x86/x64、窗口 96 和 144 DPI 四项最初均显示线程活动窗口切换成功，但两窗口标题采样均灰色并返回失败。探针只检查全局前台窗口是否存在，没有检查它是否为测试窗口，因此该结果不能直接判定产品失活/激活绘制异常。

加入前台身份记录后，一次 x64 测试实际获得前台且颜色通过；随后的受限及受限环境外双位宽四项均报告 `first=0 second=0`，即测试窗口没有获得系统前台，均明确 skip，不计通过。探针在两个目标未分别成为前台时返回 77；测试窗口取得前台而颜色错误仍返回失败。初始四次失败和无法取得前台的后续结果均保留，未声称修复产品或完成真实焦点矩阵。[S4 P63](M0-T25-S4-P63-window-activation.md)的先前有限同线程真实激活证据保持。

双位宽增量构建通过；96 DPI 下连续尺寸和最大化/还原四项回归通过。没有使用隔离桌面或发送真实键鼠；产品二进制未变、两处发布包仍为 S5 P9。跨进程焦点、其他 DPI、完整包矩阵和用户视觉验收仍待验证，S6、T25 保持开放。无临时构建副本。
