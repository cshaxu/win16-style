# M0 T25 S7 P5：实际记事本、demo 与样式恢复边界

对 [S5 P9](M0-T25-S5-P9-caption-command-order.md) 发布版，受限环境外以 x86/x64 自有探针分别启动旧版 `O:/windows/notepad.exe`（96 DPI）及已发布的 64 位 `O:/winnt/demo.exe`（144 DPI）；四项均通过窗口附着、标题与菜单命中、活动/失活消息采样、最大化/还原及程序移动/尺寸变化，测试实例正常退出。这是程序消息和有限像素采样，不证明真实鼠标、键盘、完整视觉或其他应用/显示器。

对照 S7 方案中的样式恢复：`src/lib-win32/win2k-window/frame.h` 只提供 `win2k_frame_attach`，`ntw2ks.def` 没有窗口样式移除导出，产品当前也没有 Win2000 运行中移除入口。窗口销毁、DIB/DC 恢复和最大化后的 `SC_RESTORE` 均不能当作窗口样式恢复。当前普通 `--2k` 随进程结束而结束，不支持据此推断运行中可逆或全局切换；此缺口进入 TODO 和最终审计，未计通过。

本次没有产品源码或二进制变化，两处发布包仍为 P9。未使用隔离桌面，真实拖拽、真实 Alt+Space/Escape、完整包矩阵和用户视觉验收仍未完成；S7、T25 保持开放，无临时构建副本。
