# M0 T29 S22 公共对话框路线

以 S21 P1 为运行基线。原有 Win32 A/W、COM、Shell、打印、页面设置及颜色等
公共框能力继续按 T20、T28 S3 和 T29 S14 的验收边界执行。

| 路线 | 当前可观测实现 | 迁移接收者 |
| --- | --- | --- |
| Win32 A/W 打开、保存 | `file_dialogs.c` 将策略分别接到旧布局控制器、Explorer 文件调用观察或原 API。 | 公共控制器消费文件布局和观察能力。 |
| COM 打开、保存、目录 | `com_dialogs.c` 的 `dialog_route` 将年代值转换为原生、经典或 Explorer 路线，保留多选、回调和原生回退。 | COM 控制器继续拥有调用、回写、资源和回退。 |
| Shell A/W 目录 | `folder_dialogs.c` 按年代值选择既有经典树或原生调用。 | 独立目录能力，保留筛选回调和 PIDL。 |
| 打印、页面设置 | `window_titles.c` 在 A/W 和扩展入口按年代值选择监视和布局。 | 公共打印、页面设置及窗口观察机制。 |
| 颜色、字体、查找、替换 | 检查现有 scoped chrome 和应用自定义模板。颜色选择器的色样边框仍有硬编码画刷。 | 主题呈现与公开参数约束分别交由现有绘制和适配层。 |
| 全局与普通启动 | `file_dialogs.c` 读取当前主题，缺失策略时从 family 推断；全局初始化 Explorer 对话框时可能换用固定 Win2K 样式。 | 从选定主题分开解析路线和呈现，验证其余场景原生回退。 |

先冻结各路线的启动与全局行为，再收敛主题字段和适配。逐项保留 ABI、调用方
数据、已有模板与兼容回退，以同一运行件的双位宽原生、默认主题和混搭主题
对照为验证基准。

## 文件、目录和打印路线

记录 9 的三个路线字段已分别解释为文件布局、目录机制和打印机制。
Win32 A/W、COM、Shell 及打印入口消费各自字段。缺省策略由主题加载器
归一化。旧主题和旧独立夹具沿用既有推断。窗口适配器仍由记录首字节描述，
与三个路线字段分开。此批保持主题格式和四个字段的整数编码。

x86、x64 中性运行时与主题读回测试已增量构建。两宽运行格式负例和模型读回，
共四次通过。重新生成的四个主题文件与 S21 发布版逐字节一致。三份混搭主题
分别跑 COM 文件、目录及 PrintDlgEx，双位宽 18 组全部通过，包括 ANSI 与
Unicode 打印对照，无打印机跳过。没有发布 S22，测试包已清理。

文件观察器和打印资源仍见固定 Win2K 回退。后续须从当前主题读取布局度量和
实际模板，并由选定主题应用对话框外框。当前混搭测试证明路由生效及取消，
还需用像素、参数回写和真实资源装载覆盖上述差异。

## 当前主题的度量与打印模板

文件、标准对话框和打印从当前线程作用域、活动全局选择或启动主题读取度量。
两配套主题均携带三份 General 模板。打印从同一个主题读取度量和实际模板，
旧主题缺本路线模板时走既有桥接和原生回退。未设置主题身份的旧独立兼容
夹具仍沿用原先资源路径，两个默认主题的对话框路线保持。

双位宽增量构建及主题读回通过。两份 Win16 混搭主题在固定 600×380
工作区模型中只改变紧凑宽度门槛，分别得到紧凑与原生布局。x86、x64
均验证线程作用域切到内置主题编号并恢复先前度量。实际文件窗口的四次
对照均可取消，本桌面两种模式都没有 Places 栏，因此未获得该项视觉差异。

另用四次实际 PrintDlgEx A/W 窗口验证，只有当前混搭主题携带的模板文字
`Current` 出现在紧凑 General 页，取消动作和 HRESULT 均正确。三件运行
文件摘要一致，临时目录已删除。18 组既有混搭路线回归仍通过。尚未发布。
文件观察器的外框仍需移除固定 Win2K 路由，打印模板 ID 仍是既有资源合同。

## Explorer 对话框外框

COM Explorer、Win32 文件观察器和已走原生初始化观察的标准对话框共用一个
外框入口。普通启动按当前主题的窗口适配器应用，活动全局会话继续交由原有
生命周期，并把选定主题原样传入。中性 DLL 从自身定位主题目录。

双位宽中性和兼容构建通过。18 组混搭路线回归再通过。另对照 S21 P1、
当前混搭和默认 Win2000，共六次。S21 的混搭框虽能从 `WM_PRINT` 读到浅蓝
色 `f0c8a4`，仍由旧 Win2000 外框适配器持有。当前混搭保留 Explorer
文件布局和相同浅蓝色，由选定的 Win16 适配器持有。两宽均正常取消，
默认 Win2000 的 Explorer 路线也通过。临时目录清理完成。

经典文件路线的混搭外框、标准颜色／字体／查找声明及实际全局会话的混搭
对照仍待补齐。本次只运行普通启动及自有窗口。

## 颜色、字体和查找／替换路线

新增 CLASSIC_STYLE 1.18 可选记录 21。颜色、字体、查找／替换各自选择
原生 API、兼容装饰或标准布局观察。两种中性启动方式共用标准对话框入口，
旧主题由加载器独立补全各字段。既有记录 9 的字节保持原样。

双位宽增量构建及主题独立读回通过。26 组混搭回归通过，其中新加的八组
覆盖两套互补声明下的 32 次 A/W 原生调用。原生颜色和查找／替换进入
系统路线，保持取消、通知、动作及销毁。字体原生路线仍可能经通用窗口创建
附着外框。本机两宽的原生字体客户区为 427×445，标准观察路线为 425×439，
两者正常取消。默认 Win2000 的颜色、字体、查找、替换回归也通过。

Win16 三种默认夹具在两宽的既有兼容 DLL 附着断言上均失败。以 S21 发布版
对照，退出码和相应标记一致。颜色格像素、字体选项和下拉、查找与关闭通知
均与基线一致，尚需中性运行时的独立外框及查找编辑边框观测。临时目录已清理。
颜色格边框的主题颜色、经典文件混搭外框和实际全局会话仍待验证或迁移。

## 颜色格取色与反向混搭

颜色格边框复用共享边线绘制，并取当前对话框已经加载的 `SysMetrics.WINDOWFRAME`。
使用中性运行时的实际标题背景检查补齐颜色与字体夹具。双位宽八次原生调用
通过，四次 A/W 调用只换主题后，普通格和自定义格的边框都从 `000000`
变为 `9d6731`。色格内容、键盘焦点、取消和非目标 DrawEdge 保持原样。

经典布局调用作用域按主题外框能力选择观察器。双位宽 COM 反向混搭确认
经典布局仍在，并观察到 Win2000 外框。重新跑 26 组混搭矩阵全部通过。
既有全局端到端夹具要求私有桌面，本轮禁用该验证路径。当前证据覆盖普通启动
和自有窗口，实际全局托盘与 Win16 查找编辑框的独立像素继续单列。

## P1 构建、发布与验证

纯 C17 的 x86、x64 干净构建通过。同一源码快照完成主题独立读回、
原图资源检查、PE 检查、进程及样式库边界检查和 13 项治理门禁负例。
先将七件候选发布到项目 assets 与 O:/winnt，再启动实际包回归。独立比对
候选与两处安装，七件 SHA-256 均一致，两处的四件旧样式 DLL 均已退役。

同快照的双位宽会话判定通过，验证会话身份、同样式匹配、拒绝错误会话号及
拒绝旧协议。该夹具只操作自己的进程身份和会话数据。管理员托盘混搭实测
仍单列为未覆盖项。

发布后聚焦实包 37/37 通过，含八项固定门禁，无跳过。双位宽用例覆盖
A/W 文件选择、短缓冲区、颜色和字体、查找和替换、打印和页面设置、
PrintDlgEx 及 COM Explorer。混搭对照还覆盖独立路线、原生回退和按主题读取
打印模板。原生颜色格边线通过独立绘制探针。

安装版 Shell A/W 各测双宽取消与回写。Win16 的四次通过树接入断言。
Win2000 的四次均显示原生目录树且正确取消或回写，夹具在要求直接树接入的
断言处退出 1。采用已核对摘要的 S21 运行件，在临时目录原样复现此差异。
安装版 Win16 的四个控制台夹具额外输出终端模块身份不匹配 1306，目录用例
退出 0。临时基线目录未出现该诊断，终端分支未完成同环境对照。

Win16 查找／替换各两种主题、两种位宽共八次功能通过。只改 Edit.BORDERCOLOR
后，离屏非客户区和客户区仍未观察到新色，S21 同条件结果一致。历史附着
标记仍依赖已退役 DLL，不能验证当前编辑边框。主包矩阵的 Win2000 查找窗
附着和关闭已通过。两处补充临时运行目录曾遇到 DLL 短时占用，测试结束后
已清理，未终止用户进程。

实际管理员托盘、原生 Places 可见栏、Win16 查找编辑框换色像素继续留作
未验证项。它们不计进聚焦矩阵的 37 个通过。
