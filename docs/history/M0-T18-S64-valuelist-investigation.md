# M0 T18 S64: Delphi TValueListEditor investigation

The [author's Delphi XE example](https://mrxray.on.coocan.jp/Delphi/plSamples/056_TValueListEditor_Button.htm) provides a source-and-binary archive SHA-256 `a330700855ee5698da8eb5b1e2b35cf0dd25bf28ddca8cc3c4c5e3adfbed7dbc`. The inspected `01-01_Basic/Project1.exe` is x86, SHA-256 `5c50d9eac287ddddfc2682060d67fd1fb10a13180ef960ae50c18594597f2b7f`; its form constructs a `TValueListEditor` with an ellipsis editor, and the source's button event only opens a message box. The sample and its original files remain solely in `build/t18-s64-vcl-value-survey`; no sample code or artwork has been incorporated into the project. The displayed sample initially failed to observe with error 193 because the probe driver was x64 and its hook DLL x86; the corrected matching x86 driver succeeds.

Both bare and P128-styled isolated jobs exited zero after normal close. The P128 process loaded `assets/ntw16s32.dll` SHA-256 `6492f9b51b05f8bf490b4d7fd87ca47acfb059a4d42a8aee1127b28ef91ce757`. Its root attached; application-owned `TValueListEditor` (`style=54010000`, `ex=00000200`, no visible scrollbar) and its `TInplaceEditList` child (`style=540000c4`) did not. The right-hand ellipsis button is part of that child rather than a separate Button HWND. Its modern appearance was visible in the native screenshot.

A scratch-only x86 hook recorded that the same application module calls `DrawThemeBackground` on the child DC for a 17×20 right-edge rectangle, button theme part 1, state 1. A correlated `OpenThemeData` call identified the theme handle as `button`. A restricted experimental overlay reused the project's existing button-face painter after native rendering; normal and experimental 250×241 same-sized captures differed by 323 pixels, all within the 17×20 button bounds. The sample still painted its own ellipsis. This cross-instance image comparison is preliminary and is not a substitute for a same-window before/after comparison.

An owned-thread probe synthesized a click and automatically closed only the modal dialog produced by the sample. P128 and the experiment each produced one dialog, retained the text `A-100` and released capture; both jobs exited zero. The experimental DLL SHA-256 is `48e14bc6a707f9551122c7181066d6f707006f4f1c14e11520b44784b32e0325`. Neither observation proves other edit modes, theme states, focus/keyboard, selection, reparenting, DPI, clip, exception handling or resource lifetime. The unscoped scratch overlay is not an admitted production change: a production design must establish same-window paint and owner identity, role/geometry, theme lifetime, state semantics and safe fallback, then verify both widths, real application and a clean actual package. M0/T18/S64 remain open.
