## 链接负例

实际 Ninja 链接行显示双宽 DLL 直接使用带 `STYLE_THEME_EXTERNAL_ONLY`
的 `classic_theme.c.obj`。公共归档仍供开发工具和兼容夹具复用。用各架构
CMake 记录的 `nm --defined-only` 检查 O:/winnt 正式三运行件，分别枚举
17,054、18,519、11,849 个定义符号，外部目录及活动主题入口存在，以下七
项旧实现定义均未命中：内置映射、两种预设加载入口、旧供给家族判断、旧控件
配方、两处年代专属现代绘制入口。该检查与 S23 的源文件预处理及旧归档退出
证据互补。P14 对 P13 正式产物重新按实际 Ninja 链接命令定位、预处理 69 个直接编译单元，旧年代选择标识仍为零命中，两宽链接均未使用旧控件归档。
