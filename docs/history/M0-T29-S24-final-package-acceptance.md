修正 [夹具](../../tests/lib-win32-style/appearance/win2000/window/modern_frame.c)，
将原操作作为拒绝用例，再验证正确的目录撤销及表面清除。仅增量重编两宽该夹具，
产品和已发布主题未改动。复现时复制七件，另复制 `Win2K` 主题目录并改目录名。
其 `CLASSIC_STYLE` 的记录 1 把按钮组右侧边距改成 30，记录 10 把按钮来源设为

三代测试首次运行 Win16 8/8 通过，Win2K 在首个组合中退出。夹具原先只查询
完整客户区提供者，无法观察 Win2K 的原生客户区提供者。修改
[矩阵](../../tests/integration/propagate_basic.c)和[自有目标](../../tests/integration/propagate_target.c)，
每代必须恰有一个提供者接管窗口，控件由相同提供者接管。矩阵核对选定主题对应
的实际提供者。原本的 Win16 默认命令仍适用，传入最后一项 `Win2K` 可复跑第二主题。

x86 外部主题独立夹具首次因 exe 同目录缺主题副本返回 `1812`。与已发布主题
同目录复测后，三次应用、单次移除、标题与宿主销毁均通过。

Win16 菜单的同会话旧版对照先通过，随后比较正式启动对照中的线程活动窗口、
线程焦点及前台窗口。两宽中，线程活动窗口和焦点都归测试目标，前台窗口仍非
目标。对同一自有窗口发送 `WM_NCACTIVATE` 后立即取样和再重绘取样，旧版和
正式包均按两种状态绘出 `ffffff` 与 `f0c8a4`。无需重新附着、提升权限或修改产品。
[永久夹具](../../tests/ntw16s-dll/win16_style_menu_cancel.c)以实际启动载荷装入主题，
保留已附着的测试窗口；原生菜单对照窗口明确撤销附着。激活前后分别验色，
再验证局部重绘裁剪、完整重绘与取消后焦点、捕获、菜单项和阴影恢复。
双位宽正式包和旧版各通过两种 DPI 上下文的 15 个场景，共 4 次运行。
[实包计划](../../tools/Test-Package.ps1)登记两宽正式菜单和 Win2K 三代传播。

七个 VCL 测试源改为查询已发布的中性模块名，避免把旧 DLL `GetModuleHandle`
失败误判为产品缺陷。控件字体的协议以正式单控件探针验证，旧全量字体夹具会
对启动时已附着的同一窗口重复安装。字体试验复制一份完整包，只在两个改名目录
分别修改与移除 `CLASSIC_STYLE` 记录 30。三份运行件保持原摘要。

菜单列距改用正式菜单路径对照。旧 `win2k-paint` 在已主题化的弹出窗上再次
直接调用静态绘制器，像素由后者覆盖，双宽均得到默认系统选区色。正式
`win2k-live` 与 Win16 `native-string` 的 8 项外部列距对照通过。

正式入口会在创建窗口时接管。旧字体矩阵在读取原生基线前先撤销测试窗上的自动
附着，再运行各显式安装和字体所有权检查。标准按钮通过正式入口直接验证已附着
窗口，并通过消息检查正常、默认、按下、禁用、焦点、Enter 与默认命令切换。
两宽进度夹具使用当前正式模块，保留旧兼容用法。测试消息都只发送给自有窗口。

三份 `RT_DIALOG` 201–203 从正式 Win2K `.msstyles` 读取，分别与 `79dc7c2e`
资源逐字节相同（748／1100／1100 字节）。两份正式运行库均没有这三份模板。
仅改临时主题 `CLASSIC_STYLE` 记录 8 的打印最小宽度为 4096，双宽 A/W
均观察到框架仍附着、紧凑页出现且取消契约相同。普通确认和大页 Apply 返回
三个副本和两段页码，x64 两种编码均返回并释放 `PD_RETURNDC` 设备上下文。
未提交打印作业。x86 打印上下文与定制页、域打印机沿用历史验收限制。

只改临时主题 `RT_STRING` 第 38 块的标题 ID 601 或菜单 ID 603。Win16 的
菜单变体同时将 `CLASSIC_STYLE` 记录 36 从 System 位图改为逻辑字体。正式
Win16 `WM_PRINT` 和 Win2K `WM_NCPAINT`／窗口 DC 各采样激活与非激活标题。
标题字体变化只改变标题字形，菜单字体变化只改变系统菜单行字形。菜单项目身份、
类型、数据、选中状态和选区色保持。两个位宽测得相同像素结果。

另替换 `VARIANT/NORMAL` 的两种标题状态填色与文字色。Win16 读到纯色
`144261`、`791724`；Win2K 读到 `1b4f6f`→`49a3c6` 及
`862a28`→`d7a245` 的渐变样点。移除 `Window` 所用的 `sysmetrics` 标准
标题字体属性后，字形切换到宿主回退，两个状态的背景均保持原值。
在另一份 Win16 临时主题只改 `TMT_WINDOWFRAME` 为 `#225563`，两宽每种
激活态均在左上外缘采到 233 个目标色像素，标题字形和填色不变。每次标题探针
结束前检查附着撤销。以上只操作同摘要的临时运行件和自有窗，主题副本已清理。

Win16 两个临时变体分别交换外部 `IMAGE` 501／504 与 507／508，或调整
`CLASSIC_STYLE` 记录 1 的左右边距为 8／12。图形变体不改变三个按钮命中位置，
系统按钮的普通像素和最小化钮的普通、按下像素改变。间距变体在 144 DPI 将三处命中左缘
从 6／346／375 移到 18／328／357，按钮图像保持。两宽所有变体均捕获并派发
原生命令。最小化验证命令抵达，最大化与还原同时验证实际窗口状态。定位还原钮
使用最大化后重新计算的命中区，探针不移动真实指针。移除可调整/最小化/最大化
窗口能力后仅留系统按钮，移除 `WS_SYSMENU` 后三个按钮均无命中。

正式 Win16 两宽 `file-dialog-target` 核对路径、文件名偏移、筛选器及写回。
`print-dialog-target` 的普通打印／页面设置均测到框架、初始化和干净取消，
经典打印确认与 PrintDlgEx 取消亦通过。Rebar 在同一 144 DPI 下的抓手矩形为
`0,1,9,27`，默认与应用自定义颜色样本分别为 `c782be044a666271` 和
`8e349685245ece0b`，每个样本的无样式及正式 Win16 像素相同。

17,054、18,519、11,849 个定义符号，外部目录及活动主题入口存在，以下七

证据互补。
