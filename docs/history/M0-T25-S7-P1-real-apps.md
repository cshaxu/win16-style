# M0 T25 S7 P1：实际扫雷、Solitaire 与传播

对 [S5 P9](M0-T25-S5-P9-caption-command-order.md) 发布版，受限环境外通过 x86/x64 自有探针分别启动 `D:/programs/misc/winmine.exe` 和 `D:/programs/misc/sol.exe`，四项均观察到窗口标题、菜单命中与打开、程序消息下活动/失活颜色及位置变化后标题；Solitaire 另外通过消息触发最大化、还原和尺寸变化。扫雷窗口未提供最大化或可缩放样式，这些操作不适用，不计通过。所有由测试创建的实例均退出。

扫雷关于对话框的双位宽探针均观察到对话框附着、主窗口禁用与菜单灰字，但窗口未获前台，活动/失活颜色按探针契约两项均 skip，不计通过。自有目标的四种父子位宽组合均报告 Win2000 载荷传播；双位宽 Win16 公开 ABI 检查通过。传播测试证明载荷路径，不替代真实应用交互；ABI 检查不证明完整 Win16 外观。

没有使用隔离桌面或真实键鼠；这些测试不证明整幅画面无闪烁、真实拖拽、真实 Alt+Space/Escape、其他 DPI 或全部应用。仅使用保留的增量构建目标，无临时构建副本；产品二进制未变，两处发布包保持 P9。S7、T25 保持开放。
