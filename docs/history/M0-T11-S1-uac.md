## Cause and minimal implementation

中完整性原生CreateProcess对双宽requireAdministrator fixture均返回740、无目标；
旧发布启动器退出5。新原生集成驱动对旧实现实际判失败exit1，不是只测试驱动逻辑。

普通路径保留；仅740且令牌未提升时，经ShellExecuteEx(runas)重启本启动器。
高权限副本先验证真实提升令牌并阻止递归，继续原挂起创建/注入/恢复事务；不直接
runas目标而漏掉DLL。绝对目标固定，原始参数尾/CWD/等待策略交接；系统重建提升
环境和控制台，不跨权限复制环境/标准句柄。无请求IPC、项目服务、helper产物或
DLL导出变化。启动器新增asInvoker manifest。其他创建错误及DLL子孙CreateProcess
不自动请求UAC。说明及原生入口见[UAC方法](../etc/operations/UAC.md)。

## Verification boundaries

两宽生产elevation.c原生自动测试各8例：请求字段、参数/CWD/等待、取消1223、
拒绝5、无handle6、失败无错误码31、实际子cmd退出73、超长拒绝与句柄平衡。
它不冒充安全桌面用户操作。中权限--elevated实测退出9/error5，无权限提升。

最终LF候选完成真实系统runas路径：高完整性12288、实际绝对DLL/PE位宽、窗口
附着及正常显示经典标题、空/空格/末尾反斜杠参数、含空格CWD、Windows新环境、
目标退出73及带样式的自有子进程。另系统授权高驱动6/6：双宽Console/GUI等待73，
双宽GUI默认异步返回0；目标自己的完成标记及原生截图仍被检查。共7个根目标和
7个同宽子孙。GUI异步未独立读取最终目标退出码，不用源return73冒称观测值。
未记录安全桌面物理输入；系统授权API实际成功和高令牌/目标状态分别有原生证据。

未覆盖：另一个管理员账户的凭据输入、该账户网络映射盘、真实安全桌面取消点击、
任意受保护目标、下游任意ShellExecute提权、物理输入及高权限任意DPI。fixture实际
逻辑DPI96。取消处理自动通过不等于真实UI取消验收，标准用户跨账户不计通过。
