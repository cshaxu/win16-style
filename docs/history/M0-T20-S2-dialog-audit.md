# M0 T20 S2：公共对话框入口与回退审计

## 范围与判定

基线为用户使用的 P295 四文件，源码提交 `68d50a1`；S1 收口见
[M0 T20 S1](M0-T20-S1-closure.md)。本表的覆盖单位是“入口及常见调用契约”，
不是标志位笛卡尔积，也不认为模块已加载等于控件已绘制。

- **旧式转接**：真实系统旧布局被调用；不代表全部标志都可映射。
- **接入样式**：窗口创建作用域或控件绘制被处理；不代表全部子控件及变体都已验收。
- **原生回退**：保持系统调用、布局或其自身语义；仍可能按独立的窗口样式作用域处理。
- **已知错误**：实际对照出现错误行为；不能当成安全回退。
- **未知**：没有足够证据。历史通过来自不同阶段，非 P295 完整矩阵通过声明。

## Demo 与执行优先级

demo 对话框页登记 27 个按钮：打开 7、保存 4、文件夹 4、查找/替换/字体/颜色 4、
打印/页面设置 4、消息及其他 4；入口存在不代表其每个功能已通过。强制保留现代
文件对话框通过项目公开 API 主动请求，其余应用不具有隐式例外。

优先顺序：S3 先止损 Shell 筛选及可低成本安全处理的 COM 错误；S4 检查常用
文件、文件夹、控件滚动、Find/Replace 和打印页面；S5 集中验收并按用户要求停在
T20 收口前。COM 自定义/事件、罕见参数、全设备/DPI 与虚拟命名空间维持低优先级。

S1 最后 P295 选定实际包回归 36 项通过、零跳过；初次并发 run 的 demo 对话框关闭
超时仍有效，重试通过不能证明根因。P295 原生屏幕及物理输入覆盖以原记录为准。
本审计不将先前 951 个登记测试全部作为剩余工作。

## S2 验证与交付

`build/t20-package/s2-audit-final` 从 S2 源码快照以 GCC、Ninja、ccache 干净
构建 x86/x64，来源、图形资源、治理及 ABI 门禁通过。对应实际四文件包
`s2-audit-focus` 24 项通过、无跳过，包括 demo、首次注入/传播及双宽有代表性的
Find/Replace、Font/Color、PageSetup、普通/扩展打印取消及文件夹无效输入。
这不是 951 项全量测试，也不是物理输入或所有参数验收。
