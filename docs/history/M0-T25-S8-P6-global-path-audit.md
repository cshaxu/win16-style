# M0 T25 S8 P6：全局风格切换接入审计

## 现有路径

`run16s-exe/tray_controller.c` 只有一个 Win16 开关和一个 worker；`run16s-exe/global.c` 创建会话、分别加载双位宽 `ntw16s`、安装观察钩子、启动管理器，并以会话消息通知应用及移除。`ntw16s-dll/global/attach.c`、`remote.c` 和 `hook.c` 的模块、导出、会话与附着路径均绑定 Win16；其中有身份校验及目标范围策略，不能仅改 DLL 文件名。

`ntw2ks-dll/dllmain.c` 明确拒绝全局会话，传播的 active 回调目前始终为真；`ntw2ks-dll/controls.c` 的启动期钩子按原有路径处理新建窗口与标准控件。`win2k-window/frame.c` 为窗口附着子类并禁用 DWM 非客户区绘制，但没有对应的运行中移除；控件的 `SetWindowTheme` 状态也未记录恢复。现有 Win16 移除只恢复能够观察到的 DWM 开关状态，Windows 不提供原政策精确查询，不能承诺完全还原原政策。启动期已提交的函数钩子生命周期也不能称为物理卸载。

## 实施顺序与验证

1. 建立 Win2000 的窗口和控件附着所有权及撤销路径，处理窗口创建中、销毁中和重复操作；先用自有双位宽窗口验证独立应用与恢复，包括 DWM 可观察状态、尺寸、子控件及重入。不能将 `SC_RESTORE` 或关闭窗口称为样式恢复。
2. 在已有全局会话和目标发现流程上明确风格身份，让双位宽目标接入、后续窗口及传播遵循所选风格；对现有路径、导出、身份校验和目标策略逐项改造，保留普通 `run16s` 行为。分别验证已运行和新建目标；停用与卸载分开记录。
3. 托盘改为两项互斥可取消选择和原有 Exit；切换先完成旧风格停止与尽力恢复，再启动目标风格，失败时不能显示错误勾选状态。验证重复操作、切换失败、停止中的竞态和双位宽；不以菜单状态代替实际附着和恢复。
4. 按仓库规范执行纯 C 双位宽构建、同批八文件发布后测试、提交推送与远端复核；不创建或切换隔离桌面，不改变安全设置。真实桌面或权限受限的测试如实列 skip，保留用户要求的资源及清理。

本次为实现前审计，未更改产品或宣称 Win2000 全局模式可用；S8 保持开放。S9 的样式去重及下一个 T 的目录与通用接入重组不由本次审计视作完成。
