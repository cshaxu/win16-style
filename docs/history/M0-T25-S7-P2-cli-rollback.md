# M0 T25 S7 P2：启动失败回滚与 Win16 回归

扩展现有 CLI 回滚测试，使同一个测试同时覆盖默认 Win16 和 `--2k`；不复制第二套测试。对 [S5 P9](M0-T25-S5-P9-caption-command-order.md) 发布包的临时副本，分别在 x86/x64 目标上测试所选样式 DLL 缺失、错误位宽和损坏，两种样式共十二项均返回预期错误且目标入口标记未出现。默认 Win16 的 32/64 位命令行输入输出与退出码四项通过。Win2000 的临时副本测试曾单独先行验证六项，随后统一后的测试全量复测通过；所有临时副本已清理。
