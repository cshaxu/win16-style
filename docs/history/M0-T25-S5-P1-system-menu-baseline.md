# M0 T25 S5 P1：系统菜单基线与桌面约束

S4 的有限技术范围已在 [S4 P73](M0-T25-S4-P73-closure.md) 收口，用户视觉验收仍待 T25 最终验收。S5 检查普通 Win32 标题按钮及系统菜单，原版/已有实现范围和双位宽命令、禁用按钮的结果分别见 [S4 P65](M0-T25-S4-P65-system-commands.md)、[S4 P72](M0-T25-S4-P72-disabled-buttons.md)。

尝试以自有窗口在可见私有桌面使用真实 Alt+Space、Escape：原生未套样式的 x64 对照报告菜单打开、关闭均成功；套用 P70 样式的 x64 测试等待超时，无法确认根因或是否为产品缺陷。一次 x86 尝试因当时输入桌面不是普通桌面而未切换，未执行测试。用户随后明确要求不再使用隔离桌面；已确认自有探针进程退出，并撤除本次未完成的键盘探针，不再采用隔离桌面。此项未计通过，后续需在不切换桌面、不妨碍用户操作的条件下调查。

在当前桌面以自有窗口、程序消息验证 P70 发布版，x86/x64 系统菜单均打开并绘制经典选中色，结束后自有窗口退出；该检查不证明真实键盘行为。产品二进制未更改，assets 与 `O:/winnt` 摘要与 [P70](M0-T25-S4-P70-inactive-menu.md) 一致；使用 `build/.ninja`，无本次临时构建副本。S5、T25 保持开放。
