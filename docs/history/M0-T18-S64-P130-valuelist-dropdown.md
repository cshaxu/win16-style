The real x86 Delphi XE sample and the observed popup behavior are in [the investigation](M0-T18-S64-valuelist-investigation.md). The in-place editor's pick-list button uses the `COMBOBOX` theme, so P129's BUTTON-only path left it modern.

The implementation tracks the COMBOBOX theme handle with the existing open/close epoch and alias safeguards. Only during the already-witnessed same-window editor paint does it inspect a COMBOBOX theme ticket, preserving the normal path for unrelated theme calls. For the observed enabled normal state and exact right-edge geometry it reuses the existing button face and the original project 7×9 combo-arrow resource, preserving the DC clip. Unwitnessed, hot, pressed, disabled, unsuitable geometry and other theme states fall back to native drawing. No public export, new hook, product file or original graphic was introduced.
