# M0 T25 S4 P65：标题命令与系统菜单检查

使用 [P62](M0-T25-S4-P62-caption-separator.md) 的 `O:/winnt/run16s.exe --2k`，自建 x86 和 x64 普通窗口在各自私有桌面测试。`--buttons` 两种位宽均报告 `max=1 restore=1 min=1 close=1`；`win2k-switch` 两种位宽均观察到系统菜单打开、项目状态和应用数据保持、两个选中项目的经典蓝色。它们通过程序消息与菜单状态驱动，不等同真实键鼠、全部菜单自定义方式或完整 S5 验收。

仅增量构建 `build/.ninja` 内的自有测试程序，没有修改产品或发布新二进制；发布目录与项目 assets 的八文件摘要仍须以 P62 交付为准。S4、T25 保持开放。
