# M0 T25 S5 P13：Solitaire 对话框与失活主窗口

按用户提供的 Windows 2000 Solitaire 参考场景，在当前桌面通过 [P9](M0-T25-S5-P9-caption-command-order.md) 发布版启动自有 Solitaire 实例并打开关于对话框。x86/x64 探针均确认对话框已附着、位于前台、主窗口禁用；对话框标题采样蓝色，主窗口标题灰色，主窗口菜单测得灰字且未测到黑字。测试进程均正常退出，不使用隔离桌面或真实键鼠。

探针新增该可选真实样本的颜色检查；找不到窗口是失败，窗口不在前台为 skip，不冒称通过。仅在本机 96 DPI、单个颜色点和上述样本范围内有证据，不能证明逐像素一致或覆盖所有对话框。双位宽增量编译通过。产品二进制不变，无新发布；S5、T25 保持开放，真实 Alt+Space/Escape、完整包矩阵和用户视觉验收仍未完成。无临时构建副本。
