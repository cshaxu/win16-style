# M0 T18 S64 P126: month-calendar selected date

The real x86 Delphi XE sample and safe observation boundary are documented in [the prior investigation](M0-T18-S64-monthcalendar-investigation.md). Its system SysMonthCal32 painter draws an unfocused or focused selected-cell background and then the cell text on the same DC. In the observed Windows theme, the background states were `MCGCB_SELECTEDNOTFOCUSED` or `MCGCB_SELECTED` and the following MC_GRIDCELL text used state 6 with black theme text. Hover produced a different background/text state pair; today combined with selection also used a different background state.

The implementation replaces only the verified enabled selection background with the existing palette's light blue, immediately before the matching native text call. It requires a fresh same-window paint witness, matching system caller, theme, DC, cell/text geometry and black theme text; explicit clipping is preserved and the native text call, font, theme, application colors and layout remain unchanged. Disabled, hovered, today-combined and other unverified states retain native appearance. No new hook, public export or product file was added.

With the actual package at 96 DPI, the real sample's public grid information identified one selected cell. Both focused and unfocused comparisons showed 459 changed pixels within that cell, 512 in the previously implemented arrow rectangles and zero elsewhere. Disabled and synthetic-hover comparisons had zero selected-cell changes, 512 arrow changes and zero elsewhere. All four owned jobs were emptied by forced termination, because the sample's normal close handler writes global locale settings; this is not normal-shutdown evidence. Physical input, other themes, DPI, versions and full T18 integration remain unverified.

Self-owned x86/x64 models preserved the selected date, native minimum size, application color state and theme; ordinary non-today selection changed 465 pixels, while selected-today and disabled controls retained their native selection. Every comparison retained 512 changed arrow pixels and zero outside the public regions. P125 failed the new selection assertion in both widths. The C17 MinGW GCC/Ninja/ccache clean dual-width build, ABI and original-resource gates passed; the actual four-file package passed 29 focused cases in 22.71 seconds without skips. Both assets and O:/winnt/system32 matched its hashes and passed x86/x64 installed models. The calendar title, date font and other unverified visual states remain outside this limited change. M0/T18/S64 remain open.
