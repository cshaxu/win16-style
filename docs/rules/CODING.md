# Coding Rules

产品及新增测试源码采用 C17；目标工具链为 MinGW-w64 GCC + Ninja + ccache，
不使用 C++ 或 MSVC。MSYS2 可提供构建环境，产品不得依赖 msys-2.0.dll。
GCC 警告作为错误，显式处理 x86/x64 指针宽度、
调用约定、导出名及结构尺寸。公开 ABI 版本可检查，不能依赖私有布局猜测。
既有 C++/MSVC 实现是待迁移历史基线；迁移须保持异常清理、注入和传播契约，
双位宽 GCC 构建与回归通过前不得宣称符合新基线。

保留导入源码的声明及格式，机械移动与行为修改可分别审查；已有文件移动
使用 git mv。禁止构建时修改/转换导入源码，禁止源码树中的对象和编译产物。
Win32 调用明确 A/W 契约；清理路径保留原始错误，不吞掉安装失败。
不以 Sleep、轮询、全局设置或 demo 自行着色掩盖注入与窗口生命周期问题。

测试针对公开契约和真实生产路径，按所有者放置；跨位宽链使用双位宽测试
fixture，不能增加 x86 demo 作为第五产品。故障注入与观测工具放 tests/tools，
不在 demo 用户流程里增加测试开关。运行结果明确成功、失败、跳过与未覆盖。
