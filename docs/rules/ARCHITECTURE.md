# Architecture Rules

- 只允许目标架构中定义的三组件四产物；测试辅助程序不属于产品包。
- 构建、链接、运行和验收不读取兄弟仓库、已安装 NTVDM 或固定个人路径。
- renderer 只有一个实现；demo 不调用或链接任何样式/注入接口。
- 原生进程调用保留参数与生命周期语义，传播不依赖 broker、RPC 或常驻服务。
- 仅注入本次启动树新建的目标，不做全局 hook 或既有进程扫描。
- HWND、字体、DC、trampoline、DLL 引用与创建句柄必须有唯一明确所有者。
- 失败不恢复半安装目标，不终止已交付进程；对外接口不暴露组件私有状态。
- loader-lock 中禁止等待、RPC、线程创建、GUI/GDI 操作和 LoadLibrary。
- 新的跨位宽机制、第三方实现或公开 ABI 变化先在活动包中记录并核准范围。
