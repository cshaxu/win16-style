# 字体与原生布局兼容

用户截图显示sol.exe Options字体裁切/重叠。当前统一System16拉伸20粗体替换
控件字体而未重排对话框，破坏原布局。采用原生字体精确保留：标准控件使用应用
原字体及后续WM_SETFONT，包含NULL默认字体；绘制和输入/列表tab度量同源。
不改控件位置尺寸、对话框单位或应用自绘文字。标题与菜单分开拥有按窗口DPI
创建的宿主经典字体，不再把20像素compat字体作为默认。原资源五头及声明不变。

仅S1：双宽原生度量/实际对话框/字体改变/卸载/资源寿命探针、旧DLL负例、core
回归、同包测试及双位置发布。既有font_acquire/release保留ABI3兼容，实际 renderer
不用该固定20像素入口。所有权由GUI线程/window保留，不引入全局设置或新产品。
