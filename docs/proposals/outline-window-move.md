# Win3.x 局部轮廓拖动

## 请求与状态

用户因实际拖动卡顿明确要求追加T16独立S原样撤回。T16 S2已完成恢复包交付并收口，
产品源码/测试已恢复T15原生移动；不继续优化，不将本方案重新排队。
S1原始研究/功能验证仅作历史，不代表当前支持；最新状态见[CURRENT](../states/CURRENT.md)，
撤回记录见[T16 S2](../history/M0-T16-S2-outline-withdrawal.md)。

以下为已撤回方案的历史目标，不能作为当前实现能力。

## 目标和保留边界

仅对加载ntw16s且已附着样式的受支持窗口启用：用户拖动时，真实窗口留在原位，
只更新经典移动轮廓；松开后一次性提交位置，取消则保持原位。
未挂钩/未附着窗口遵循原系统行为。不调用SPI_SETDRAGFULLWINDOWS修改全系统
设置，也不在拖动前后临时切换该设置。不得为本任务引入全局hook或扫描注入。

在现有DLL窗口交互模块实现，保持纯C17/MinGW GCC/Ninja/ccache、三组件四产物、
唯一renderer及现有CLI；原图形资源和来源声明逐字节保留，现有标题、字体、菜单、
滚动条与控件外观不变。边框缩放不是已经承诺完成的范围，先核实原实现再决定
是否作为有明确边界的后续S；不得把只完成移动称为已完成全部移动/缩放适配。

## 原始实现研究为实现前置

1. 定位可合法研究的Win3.x原始USER、GDI及对应VGA显示驱动等二进制，记录
   系统版本、文件路径/来源、SHA、显示模式/分辨率；Win3.0/3.1及驱动差异不得混用。
   无法取得或无法分析时记录缺口，不能用现代Windows效果或截图猜测替代。
2. 通过只读反汇编/调用跟踪及可复现实验，定位真实移动模态循环及轮廓绘制链。
   验证是否使用反色/XOR、具体ROP、笔刷图案、线宽、矩形边界、角部、图案原点、
   擦除/重画顺序和光标偏移；上述均为待证项，不能预先认定某种画法正确。
3. 区分USER交互策略、GDI栅格操作与VGA驱动输出的责任，记录模块/段偏移、
   调用关系、关键参数和实际帧证据；将原像素到现代DPI的映射明确记录。
4. 用户附件codex-clipboard-39577b47-ec7b-42a8-a5c0-319ac9927f1b.png作为
   外观线索；其中杂点、残影、黄色横线是否属于捕获/模拟显示问题尚未证实，
   不能照搬为目标效果，也不能仅凭单张缩放截图宣称忠实复现。
5. 提炼可审查的行为/栅格规范和测试oracle后再实现；遵循
   [来源策略](../etc/operations/source-policy.md)，先审查许可和来源，不提交未经
   授权的系统二进制，不将原二进制或兄弟仓库变为产品构建、运行或核心测试依赖。

## 候选实施分解

阶段顺序不等于预分配S编号，正式准入时按规则分配，必要时继续拆分。

- 原始实现研究与可复现规范：冻结目标版本及有限支持面、绘制链/像素证据，
  明确现代等价实现和不一致处，不先锁定覆盖窗口或现代DrawFocusRect方案。
- DLL局部移动适配：审核标题命中、SC_MOVE及键盘入口，保证GUI线程所有权、
  消息泵和重入安全；根据已验证依据实现轮廓预览、位置提交及取消，明确
  WM_ENTERSIZEMOVE/WM_MOVING/WM_EXITSIZEMOVE和定位消息的应用语义。
- 生命周期与兼容交付：覆盖捕获丢失、失活、销毁、退出中断、重复拖动、
  多屏/DPI、工作区与应用位置约束。最大化拖出、吸附、MDI、特殊自绘拖动逐项
  记录支持或回退；不能默默破坏现有行为或扩大为任意窗口兼容。

## 验证和交付条件

使用纯C原生探针，不用computer-use，不把测试交给用户。双宽裸/挂钩对照证明：
拖动中真实窗口矩形不变、轮廓随指针移动、松开仅最终提交、Esc不改变原位置、
反复绘制/擦除无残留且捕获/资源释放正确。截图必须包含拖动中和提交/取消后的
正常窗口；与原二进制独立取得的像素/图案/几何证据对照，不让生成器自证正确。
验证未接入程序及系统拖动设置保持，旧包负例可检出，现有标题/字体/菜单/
滚动条与首次注入、双宽传播回归保持；失败、跳过和未覆盖项明确记录。

每个产品S按[执行规范](../rules/EXECUTION.md)完成双宽干净构建、同批四文件
实际包测试；binary change发布到assets根目录及O:/winnt/system32，摘要一致，
提交推送及实际远端复核后收口。全任务另做支持矩阵审计；没有原始实现依据
或只做近似外观时不得宣称忠实Win3.x实现完成。


## 撤回状态

S1的功能/像素测试未覆盖连续更新流畅性，实测屏幕读回及DwmFlush造成明显延迟。
用户选择整体撤回；来源研究/历史证据保留，新增模块、拦截和测试均删除。
不再作为已启用功能，发布/复核事实由S2及CURRENT接收。
