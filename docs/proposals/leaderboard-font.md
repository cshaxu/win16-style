# 多语言控件字体保护

用户截图中的英雄榜字体缩小，经[只读调查](../history/M0-Td-S10-leaderboard-font.md)
确认是中文字体被仅覆盖CP1252的System位图变体替换。用户随后批准统一多语言保护，
不限于中文特例，执行状态由CURRENT管理。

原字体实际字符集非ANSI，或文本无法无损往返CP1252时，整个控件保留应用原HFONT，
让原生路径负责字体链接/回退，不按系统UI语言猜字体。匹配西文继续原System变体。
字体/文字修改重判；列表、下拉检查全部项目及编辑字段，输入/替换/撤销/组合完成
后重查；读取失败/超预算保守原字体。保留控件矩形及已确认的标题/菜单策略。

纯C双宽回归动态加载实际DLL，比较字形像素/advance/墨迹及HFONT，覆盖8种脚本、
混合文本和更新、内层EDIT观察重入、卸载与资源。旧DLL作为应失败负例。
三组件四产物、ABI及六份原图形头/声明保持，按规范干净构建/实际包/双发布/远端复核。

实现、真实扫雷对照及有限覆盖见[交付记录](../history/M0-T13-S1-multilingual-font.md)。
任务scratch为build/t13-font及build/t13-package，提炼证据后由本S回收；稳定cache保留。
