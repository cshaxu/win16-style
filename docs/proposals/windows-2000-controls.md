# T27 Windows 2000 常用控件

## 准入与目标

用户准入原建议队列第二项，并授权自行设定目标持续执行。M0固定，T27从S1开始，活动状态由CURRENT维护。目标是现有Win3.x已支持的常用Win32/框架控件范围内，形成依据Win2000源码、原资源和真实图像的Win2000呈现；沿用T26三层、唯一接入/生命周期/协议实现，不复制Win16机制或改变其风格。

parity指逐项对照当前Win3.x的实际支持及保留边界，不表示所有参数、应用自绘、外部OCX或XAML客户区都已支持。现有Win2000关闭视觉主题仅是基线，不能算独立控件呈现完成。本T不扩展公共对话框/菜单、UWP/WinUI客户区或新主题格式，不为旧的接入126/DWM恢复债务改权限/安全策略。

## 先冻结依据，再实现

每个控件/状态记录：当前Win3.x实际入口与协议、Win2000原文件/函数/固定提交和摘要、原资源来源、可核实真实图像、几何/色值/状态规则、实现与共同根、原生及实际包验证和缺口。不得从Windows 11关闭主题的外观、自己生成的图或Win3.x字形推断Win2000原版。截图只核对其可见状态，不从一张图推导所有按下/禁用行为；未找到的状态由源码确认并标记图像缺口。

本机用户指定源码只读参考：O:/repos.external/Win2000SRC，固定提交fd809a81098565b33f52d0f65925159de8f4c337，实际内容另存SHA。包名称不代替独立版本/完整性或许可证明。先从原控制/绘图/资源构造确认需要什么；不凭空制作所谓原版bitmap。涉及导入的每个原资源/代码需单列出处、摘要、原声明与适配，不能由项目MIT重新授权；来源仓库不成为构建/运行/测试依赖。

## 验证与资源纪律

Win2000源码/资源和真实图像是独立依据；实现自绘结果不反过来当原版golden。96DPI原尺寸先核验边缘层、色值、glyph/文字位置，再做144/192等当前适用DPI及普通/aware组合。保留应用字体/颜色/图像、输入/通知/几何、失败回退及native unwind合同，关注回调重入/销毁/移除和GDI/句柄回收。原生类与VB/VCL/OCX真实样本、模型、原生保留、缺失/skip分开报告。

不使用computer-use或创建/切换私有桌面；采用用户已授权的自有有界当前桌面原生探针。测试结束先归档必要证据，再立即清理不再需要的scratch/临时包，稳定缓存保留。每完整能力批次或约30分钟复核一次ROI与推进效率；不为既有环境失败无限深挖。
