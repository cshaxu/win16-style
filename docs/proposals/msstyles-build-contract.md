# T29 S2 主题源、构建产物与运行时契约

## 构建交付

每种风格有一套可编辑主题源。一次构建至少各生成一份 `.msstyles` 和一份 `.theme`，并提供描述中实际引用的资源。标准视觉属性、项目扩展与描述索引均从同一个主题源生成，避免两份手填配置分叉。x86 和 x64 消费相同主题字节。

| 产物 | 合规门槛 |
| --- | --- |
| `Win16.msstyles`、`Win2000.msstyles` | 生成真实的 MSStyles PE 资源容器。首批以已实测的版本 4 容器为目标。标准资源与记录必须能由独立解析器识别并读取指定类、部件、状态、度量、图像和变体。只有 PE/扩展名可识别、或者只有本项目自己的解码器能回读，均不足以过关。 |
| `Win16.theme`、`Win2000.theme` | 按 Windows 的主题描述语法生成，含显示名称及 VisualStyles 的 Path、ColorStyle、Size。Path 指向同批真实文件，所声明的配色及尺寸必须可在主题文件中找到。发布配置不得包含开发机源码或中间目录。 |
| 引用资源 | 若主题源选择图标、壁纸、声音等外部内容，生成清单并核对文件和来源，引用与所选发布配置一起验证。原始栅格及声明按已有来源门禁检查。 |
| `.themepack` | 若要另外分发 Windows CAB 主题包，按该格式单独验证内容和引用。以现有两种风格及所需文件为本次最低交付范围，最终包契约登记是否提供此附加分发物。 |

标准格式验证与系统加载测试分别记录。发布的目标是格式和引用合规，同时由项目运行时只读消费数据。Windows 系统主题的签名、安装和全桌面应用属于另外的能力；本任务的样本验证不修改系统主题、注册表、系统文件或安全策略。[Microsoft Theme File Format](https://learn.microsoft.com/en-us/windows/win32/controls/themesfileformat-overview)

## 已完成的只读对照

本机 `C:/Windows/Resources/Themes/aero.theme` 的 SHA-256 为 `9dcb7383396a3b0a4d13ce0bc887baf457107db5e4f2b27da2393045f253e9c4`。在 VisualStyles 段实际读到 `Path=%ResourceDir%\Themes\Aero\Aero.msstyles`、`ColorStyle=NormalColor`、`Size=NormalSize`。解析资源目录后目标文件存在；这两个变体名与 S1 实际读取的 `VMAP` 一致。源读取只检查文件和字段，未应用主题。[S1 格式与部件证据](../history/M0-T29-S1-msstyles-audit.md)

## 编译、互操作及回归判据

1. 同源重复构建比较 SHA-256；同时从两份分别暂存的完整产物验证副本不会引用构建目录。Windows 兼容路径以实际部署配置测试，项目自己的相对路径解析不得冒充 Windows 路径兼容。
2. 用独立方式读取标准记录并对比预期属性值及图像摘要。再用项目读取器验证扩展的版本、边界和语义。验证标准视图在忽略扩展时依然完整可读。S3 记录独立解析器的精确版本和验证范围。拒绝截断、越界、未知必需版本、断链和无效变体。
3. S4 将两种主题的标题栏、按钮和滚动条接到实际布局、绘制与命中验证。格式正确与经典像素对等分别验收。
4. S11 冻结最后发布清单。若按独立文件布局分发，保留两 EXE、基础及样式运行时各一对 DLL，再加入两 `.msstyles` 和两 `.theme`，基础合计十件，外部资源另按实际引用计算。S11 之前以现有 P45 八件为正式交付基线。

## 扩展数据边界

标准类、部件、状态和属性先进入标准资源。本项目额外数据使用独立有版本资源，扩展只有经项目读入后才有含义。以下是 S1 的 13 个按年代计单元的初始字段边界。具体字段类型与 ABI 待 S2 收口冻结。

| 项目 | 适用 | 数据内容 |
| --- | --- | --- |
| 标题按钮组 | 两种 | 角色、顺序、边侧、组内间隔 |
| 标题布局变体 | 两种 | 状态要求及对应布局配置，运行时计算实际矩形 |
| 滚动条极值 | 两种 | 特殊厚度、极短区域的度量参数 |
| 历史文件及目录框布局 | 两种 | 模板角色、资源引用和几何 |
| 查找与色板几何 | 两种 | 按角色记录压缩、展开的具体度量 |
| Win16 System 位图字体 | Win16 | 保留来源的字形与 advance 数据 |
| Win16 弹窗菜单列 | Win16 | 列距及留白 |
| Win2000 扩展打印 General 页 | Win2000 | 紧凑、标准、大版布局模板及资源角色 |

主题扩展提供常量和布局配置。应用 API 调用、消息、所有权和回退仍由现有运行时执行。兼容导出按本机源码、已发布二进制和实际消费者逐项处置，S2 继续完成 44 个导出入口及 113 个审计单元的迁移接收者与验收映射。
