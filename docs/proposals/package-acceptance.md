# 独立包与 M0 产品验收

状态：用户授权自动准入M0 T6，活动S和基线以CURRENT为准。固定 M0；[前置任务](native-demo.md)须交付并关闭。
共同来源与验收矩阵见[导入总览](native-style-import.md)，顺序见[QUEUE](../states/QUEUE.md)。

## 任务边界与完成条件

| 项 | 工作包 |
| --- | --- |
| 责任/前置 | 根集成、打包与交付；依赖前五个任务交付并关闭，所有失败均修复或有明确不影响需求的接收处置 |
| 范围 | 独立源码构建与四文件同批发布；干净本地树且无兄弟项目依赖；按用户最新要求将有变化的四文件部署至assets根目录和O:/winnt/system32，运行仍从自身包目录定位DLL |
| 交付 | run16s.exe、ntw16s32.dll、ntw16s64.dll、demo.exe；逐文件 SHA-256、PE 架构与导入/导出核验；构建/使用/限制说明和来源声明 |
| 自动复验 | 运行[共同总览](native-style-import.md)的完整八类验收矩阵，核对注册用例与实际执行、失败/跳过/未覆盖清单；不把一次 smoke 或旧项目结果视为全回归 |
| 交互探针 | 用户要求不用computer-use、自己用探针；原生探针复验标题/菜单/控件、焦点/捕获、键盘消息、窗口状态及实际DPI；隔离剪贴板单列结果；不宣称物理输入 |
| 全任务审计 | 原始目标 -> 各已交付任务的实际提交 -> 生产路径/状态所有者 -> 证据 -> 未解决项接收者逐项映射；确认三组件四产物及无外部运行依赖 |
| 退出 | 所有目标均有证据，用户要求的原生探针验收及其边界记录完成，包与源码同批且哈希可复核，清理任务 scratch，提交推送并进行实际 diff/commit 复核后才关闭 T |
| 停止条件 | 混包、隐含源/服务依赖、必要用例未执行或探针存在未处置失败时，状态停在对应已验证边界，不宣称全任务或 M0 产品完成 |

用户最新要求以原生探针自行验收，不用computer-use，不再以整套人工操作作为关闭前提。
探针、截图与真实物理输入必须区分，权限限制及未覆盖环境明确记录；不能虚报通过。
发现超出已冻结需求的改进转 TODO/QUEUE，不能借审计无限扩张任务。

T2 的[核心完成审计](../history/M0-T2-completion.md)交接私有桌面验证边界：
本任务按用户最新要求以原生探针补齐焦点/捕获/菜单、实际DPI/字体及干净无sibling重建，
不将 T2 的 WM_PRINT 或 CP1252 本机字体结果直接升级为全产品通过。

## 本 T 的候选 S 划分

- S1：四文件同批打包、PE/哈希/声明和独立重建
- S2：完整自动矩阵及原资源恢复；已交付，用户确认视觉一致，未完物理项转S4
- S3：用户插入的启动器任务；GUI方案被否决，保留Console、按目标子系统默认等待及新四文件闭环
- S4：继续原生交互探针、实际DPI/隔离剪贴板及新版包验收（用户最新要求取代人工验收）
- S5：本任务审计、跨任务覆盖及 M0 产品完成审计

这些 S 只属于本 T，准入后从本 T 的 S1 开始；其他 T 各自重新从 S1 开始。
每个 S 的 P 为完整验证交付，不预分配 P 数量。T 关闭前须逐项对照本任务目标、
全部 S 的实际提交、相关回归、未解决项接收者与退出条件，不能由单个 S 替代。
