# 公共 Win32 基础组件

用户要求在不修改隔壁的前提下，制作两项目将来可共用的纯 C 组件。先对照各项目实际接口、语义和许可；共享是目标，只有在隔壁实际适配及回归后才能声称已共用。

1. process-image：提取本项目 PE 文件校验和进程位宽查询；隔壁当前以 SEC_IMAGE 查询，错误和拒绝边界不同，先保留各自语义，不直接宣称等价。
2. process-launch：调查命令行、进程句柄与启动辅助，将产品等待和失败策略留给调用方。
3. module-import：调查模块导入表查询和受控修改，将具体 hook 所有权留给调用方。
4. security/elevation 和 console：调查通用提权查询、调用及控制台句柄辅助，将全局模式策略留给调用方。

依顺序在活动 T 内分 S，实现与产品调用方均需双宽测试和四文件交付；组件必须无产品私有头、无隔壁构建依赖。每项验收按实际覆盖报告，不把新名称当成双方行为一致的证据。
